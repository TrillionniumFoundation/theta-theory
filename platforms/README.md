# θ-Theory platforms

Every load-bearing theorem in the v5 series must declare one platform ID from
`platform-registry.yaml`. Platform IDs prevent results proved on different systems from
being silently composed into one same-system theorem.

The physical flagship candidate is the specular no-eclipse open-billiard platform.
The four-branch moving-seam and similarity Lorentz platforms are retained as distinct
benchmarks with narrower roles.
