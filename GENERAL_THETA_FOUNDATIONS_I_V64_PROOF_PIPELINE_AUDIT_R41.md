## 4. Detailed proof audit: complete configurations and the lower bound

### 4.1 Computational convention

The model reads public parameters `N,L` and then exactly `N` commands in one pass. A consumed command cannot be revisited. There is no private free clock, input-dependent output-tape storage, or uncharged address. Randomness is fresh, and a retained seed is part of the configuration. Every returned randomized matrix must be legal; correctness is required for its expectation.

This convention is strong enough for the lower theorem and explicit enough to prevent the old real-advice ambiguity. The theorem correctly separates two statements:

1. a representation-free lower bound in terms of the number of complete private configurations; and
2. a machine-convention corollary for one fixed finite program with `s` writable bits.

The second statement would be false or meaningless if a different uncharged finite-control program were allowed for each `N,L`. The “fixed finite program” phrase is therefore essential.

### 4.2 Boundary reduction

At boundary `t`, define the state set as all possible complete private configurations. Given one configuration and the next command, integrate the algorithm's internal random evolution until the next command boundary. Almost-sure termination gives a probability row of total mass one. The fixed parameters and public boundary index may enter this row; this only enlarges the comparison class.

The Markov property follows from completeness of the configuration. Input already consumed and random bits no longer stored are inaccessible. A private address or control mode that affects the future is part of the configuration by definition.

At the terminal boundary, condition on the complete configuration and average the randomized legal output. The density-matrix set is compact and convex, so the conditional mean is legal. The resulting decoder reproduces the algorithm's mean output exactly. No samplewise approximation is inferred.

This reduction is correct and is the crucial bridge from an actual computational model to the earlier width theorem.

### 4.3 Explicit configuration obstruction

For the no-idle six-rotation experiment, v62 gives

```text
# {positive cuts of width <= k}
 <= 1 + 6 log(12 k)
    + 648 pi^2 [(1-zeta)/zeta] k,
```

with `zeta=1-sqrt(2) epsilon` for the unit-amplitude density-matrix task. If all `N` positive boundaries have width at most `k=2^B`, this becomes the stated finite inequality.

At zero error, the exact endpoint theorem gives width `5^N` at the terminal cut and hence `B >= N log_2 5`. For `epsilon=2^(-L)<=1/4`, the positive-error inequality simplifies to

```text
N <= C0 + C1 log k + C2 epsilon k.
```

If the logarithmic term is small, the linear-in-`epsilon k` term must carry order `N`; otherwise `log k` is already order `N`. Therefore

```text
log_2 k >= c min{N, log_2(N/epsilon)} - O(1).
```

The two explicit words in the proof show `k>=2`, so the additive constant can be absorbed uniformly over the bounded exceptional range. Since `k<=2^B`, the configuration lower bound follows.

There is no hidden time bound, deterministic-state assumption, or exact-output assumption.

### 4.4 From configurations to conventional space

For a fixed machine convention with a fixed finite program, `s` work bits, and a fixed number of heads, the number of complete configurations is at most a polynomial in `s` times `2^(O(s))`. Hence `log k=O(s+1)`. Combining this upper count with the configuration lower bound gives the same asymptotic work-space lower order.

This argument counts addresses and control information. It should not be generalized to a nonuniform family in which the finite control itself encodes arbitrary `N,L`-dependent information for free.

## 5. Detailed proof audit: the upper integer algorithm

### 5.1 Rational rotations and grid mode

Each Bloch rotation is `A_a=M_a/5`, where `M_a` is a fixed integer matrix and `M_a^T M_a=25 I`. At precision `b`, the state is `v=n/2^b`. The update computes `z=M_a n` and replaces each coordinate by signed truncation of `z_i/5` toward zero.

This is exactly coordinatewise `T_b(A_a v)`. It is not multiplication by an approximate matrix and does not accumulate matrix-description error.

### 5.2 Legality

Signed truncation weakly decreases every absolute coordinate. Therefore

```text
||T_b(x)|| <= ||x||.
```

Since each `A_a` is orthogonal, the unit-ball invariant is preserved at every prefix. For a Bloch vector, unit-ball membership is exactly legality of the associated qubit density matrix.

Floor division on negative integers and nearest rounding do not have this property. The code uses an explicit `toward_zero` operation and the regression suite pins witnesses for both wrong alternatives.

### 5.3 Error

Every coordinate changes by less than `2^(-b)`, so one grid step contributes at most `sqrt(3)2^(-b)` Euclidean error. Orthogonality preserves the previous discrepancy. By induction,

```text
||v_t-x_t|| <= t sqrt(3) 2^(-b).
```

The density-matrix Frobenius norm is the Bloch Euclidean norm divided by `sqrt(2)`. Choosing

```text
b=L+ceil(log_2 N)+2
```

gives strict endpoint error below `2^(-L)`.

### 5.4 Exact mode

When the grid precision is at least `N`, the program stores exact integer numerators and denominator `5^t`. Orthogonality gives `||n||=5^t`, so all numerators and the denominator have `O(t)` bits. The algorithm retains no command history.

The exact branch supplies zero error in `O(N)` space. Choosing the cheaper branch gives the minimum of exact and approximate precision scales.

### 5.5 Scratch and input handling

Fixed matrix coefficients make each temporary sum only a constant-factor larger than the maintained integer. A constant number of buffers suffices. Multiplication by fixed small integers, addition, and division by five are elementary digit operations using linear bit space and time in the current precision.

The parser stores `N`, scans `L` with saturation at `N`, and stores a command counter. A huge precision header is not converted into a huge integer. The actual header length affects reading time, not asymptotic writable storage.

### 5.6 Output

For `v=n/d`, the program emits the rational matrix

```text
(1/(2d)) [[d+n_3, n_1-i n_2],
          [n_1+i n_2, d-n_3]].
```

The unit-ball invariant implies positive semidefiniteness. The output is numerical and does not physically prepare a quantum state. Hexadecimal in the reference CLI is a constant-radix presentation of the binary integers used in the theorem.

## 6. Detailed audit: v62 arbitrary drift and no-idle occupation

### 6.1 Covariance of the potential

The smoothing kernel is rotation covariant, and the relative entropy against round measure is invariant under orthogonal rotations. Therefore a fixed physical filler word can rotate the entire direction law without changing the entropy potential. This is the mechanism that removes the identity/return requirement from the quantitative occupation theorem.

### 6.2 One random spectral step plus deterministic filler

Between selected narrow cuts, the external test distribution chooses one actual command from the declared spectral law and then uses a fixed command word to fill the remaining gap. The random command is independent of the prior hidden state. The filler may have arbitrary physical product and arbitrary hidden processing.

Conditioning on the incoming label produces a weighted family of old centroid directions. After the random command and hidden transition, vector summation gives the new conditional centroids. For each outgoing label,

```text
sum weights * ||old_rotated_direction-new_direction||^2
  = 2(total incoming scalar mass - norm of vector sum).
```

Summing over labels identifies the right side with lost total centroid mass. This yields a Wasserstein coupling from the rotated old directional law to the new one. Zero centroids and tiny label probabilities cause no division problem because directions are weighted by centroid norm and zero terms are omitted.

### 6.3 Entropy budget

At a width-`k` cut, the smoothed direction density is supported in at most `k` caps. The all-direction cap estimate makes every orbitwise cap union have invariant occupancy at most one half when the smoothing radius is chosen on the scale `k^(-1/p)`. The full action gap then forces a fixed entropy loss.

Transport continuity can restore entropy only in proportion to the square root of the centroid-mass loss divided by the smoothing radius. Total lost centroid mass over all selected gaps is at most the terminal deficit. Summing and applying Cauchy--Schwarz yields the stated occupation budget.

The proof uses no hidden-state return, no stationary rows, and no bound on intervening widths.

### 6.4 Explicit LPS constants

For the six norm-five rotations on `S^2`, a chordal cap of radius `h<=1` has normalized area `h^2/4`. The exact one-step Koopman norm is `sqrt(5)/3`; hence the squared contraction is `5/9`. Taking `h=k^(-1/2)` gives cap occupancy at most `1/4` and entropy defect `1/3`. The spherical kernel constants lead to

```text
1 + 6 log(12 k)
  + 648 pi^2 [(1-zeta)/zeta] k.
```

The coarse constants used later are valid and deliberately nonoptimal.

### 6.5 Exact coset profile

The projective LPS rotations freely generate a rank-three free group. The first-axis seed is fixed exactly by the cyclic subgroup generated by the first rotation. Its orbit is therefore a right-coset space.

A shortest representative of a nontrivial right coset cannot end in the first generator or its inverse. There are `4*5^(ell-1)` shortest representatives of length `ell>=1`; hence the coset ball through radius `t` has size `5^t`. Shorter cosets can be reached at exactly time `t` by first applying powers of the stabilizer generator and then the shortest representative in the chronological convention.

Extreme legal outputs force disjoint hidden supports, giving the simultaneous exact cut profile. Denominator-five separation gives the robust horizon-dependent interval.

## 7. Detailed audit: v63 exponential accuracy crossover

### 7.1 Logarithmic entropy defect

If `T f=sum a_j f_j`, convexity and the identity for mixture entropy give

```text
H(f)-H(Tf)=sum a_j D(f_j || Tf).
```

Monotonicity from KL divergence to Rényi divergence of order one half gives a lower bound by affinities. A weighted Cauchy--Schwarz step converts the average affinity into `||T sqrt(f)||_2`. If the support has invariant occupancy at most `theta` and `T` contracts the orthogonal complement to invariants by `kappa`, then

```text
||T sqrt(f)||_2^2 <= kappa^2+(1-kappa^2)theta.
```

Therefore the entropy loss is at least the negative logarithm of this quantity. The proof does not require a positive lower bound on `f`.

### 7.2 Nonbacktracking radial norm

For a symmetric `2r`-letter alphabet, set `q=2r-1`. The normalized average over reduced words of length `b` satisfies the standard free-tree radial recurrence. Chebyshev control of the corresponding polynomial on the Ramanujan interval gives

```text
||P_b-Pi||^2 <= eta_b=(b+a_q)^2 q^(-b).
```

The length-two coefficient and the distinction from an i.i.d. word average are correctly handled. The inherited regression contains negative controls for both.

### 7.3 Block entropy budget

Choose the smoothing scale so that the cap-union occupancy is of order `eta_b`. The logarithmic entropy defect per selected gap is then

```text
b log q - O(log b).
```

The transport cost is proportional to `eta_b^(-1/p)` times the square root of total centroid loss, and the loss retains the small error factor. The initial entropy range and the finite number of incomplete blocks are tracked.

Inverting the resulting inequality and choosing `b` of order `sqrt(N log N)` gives two lower alternatives: the exact formal-word scale `q^N` and the accuracy scale `((N+1)/epsilon)^(p/2)`, both up to the common subexponential loss.

### 7.4 Upper bound and interpretation

Formal reduced-word storage gives the exact `O(q^N)` upper bound even if physical relations identify some products. The inner-hull construction gives the polynomial accuracy upper bound. Taking the smaller yields the matching exponential rate.

The theorem does not determine an asymptotic equivalent or the optimal subexponential correction. It should be described as an exponent-level crossover theorem, not a uniformly sharp multiplicative law.

## 8. Detailed audit: causal tail capacity and strong converse

### 8.1 Tail capacity

For a finite nonhomogeneous hidden process, let `B_i` be disjoint positive-probability events in the observation tail. Conditional probabilities of `B_i` given the observed/hidden filtration converge to their indicators by martingale convergence. At any sufficiently late width-`k` cut, each `B_i` requires a positive-probability hidden label on which its future conditional probability exceeds one half. Disjointness makes these labels distinct. Hence there can be at most `k` such events.

The proof uses tail events, not arbitrary distinguishable finite prefixes.

### 8.2 Product-law strong converse

If `n>k` distinct i.i.d. block laws could all be approximated within a fixed TV error below one by one common `k`-state nonhomogeneous hidden instrument for every block length, compactness would produce one infinite instrument with that error on every finite marginal. Empirical-frequency tail events distinguish the `n` product laws and retain positive probability under the approximants. Mixing their initial rows gives more than `k` disjoint positive-probability tail events, contradicting tail capacity.

### 8.3 Diagnostic cycle and occupation

Finite future-response types can be separated by one common finite itinerary. Repeating probes amplifies all pairwise differences. Taking a suitable power returns every response type to itself, so repeated diagnostic blocks are i.i.d. conditional on the type.

If a clocked causal realization had too many width-`k` cuts, select sufficiently separated cuts and retain only the diagnostic-block outputs. Composite transition/emission kernels between selected cuts form a nonhomogeneous `k`-state hidden instrument. Whole-transcript correctness passes to the retained block marginal. The product-law strong converse gives the occupation bound.

This proves eventual response-quotient cardinality for every TV error below one. It does not model disturbance, quantum instruments, or arbitrary online outputs.

- strict-cutpoint language equivalence rather than full numerical vector output;

- no requirement to approximate every final density matrix in Frobenius norm; and
- different use of acceptance suffixes and prepare--test families.

They therefore do not subsume v64. But they are too close in topic and date to omit. A proper comparison should identify which parts of the v64 lower obstruction are genuinely unavailable under strict-cutpoint semantics, and whether the Chen--Wu prepare--test/VC or sign-rank techniques give alternative bounds for any scalar projection of the present experiment.
