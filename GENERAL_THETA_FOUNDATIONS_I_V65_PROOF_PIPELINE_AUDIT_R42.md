## 4. Detailed proof audit: positive rounding

### 4.1 Definition of the grid approximation

The map `Q_B` truncates the first `d-1` diagonal entries and all independent upper-triangular real and imaginary entries toward zero on the `1/B` grid. Hermitian symmetry is restored, and the last diagonal entry is chosen to make the trace exactly one.

The last diagonal entry may leave the scalar interval `[0,1]`; no claim that `Q_B` itself is positive is made.

### 4.2 Frobenius and operator error

Let `E=Q_B(rho)-rho`. The first `d-1` diagonal errors contribute less than `(d-1)/B^2`; the final diagonal contributes at most `(d-1)^2/B^2`; and the two Hermitian copies of all independent complex off-diagonal errors contribute at most `2d(d-1)/B^2`. Hence

```text
||E||_F^2 <= 3d(d-1)/B^2.
```

Since `sqrt(3d(d-1))<=2d` for `d>=2`,

```text
||E||_op <= ||E||_F <= 2d/B.
```

### 4.3 Positivity repair

Because `rho>=0`, Weyl's elementary perturbation bound implies

```text
Q_B(rho) + (2d/B) I >= 0.
```

The trace of this matrix is `1+2d^2/B`. Multiplying numerator and denominator by `B` gives the fixed-denominator formula

```text
R_B(rho) = [B Q_B(rho)+2d I]/[B+2d^2].
```

This is positive and has trace one.

### 4.4 Trace-norm error

With `eta=2d/B`,

```text
R_B(rho)-rho = [E + eta(I-d rho)]/[1+d eta].
```

The proof uses

```text
||E||_1 <= d ||E||_op <= 2d^2/B,
||I-d rho||_1 <= 2d.
```

The second estimate is safe because both `I` and `d rho` are positive of trace `d`. The resulting error is at most `6d^2/B`. Division by `1+d eta` is discarded in the upper bound, so there is additional slack.

### 4.5 Gaussian-integer implementation

For positive integer numerator `P` with trace `z`, every entry satisfies

```text
|P_ij| <= sqrt(P_ii P_jj) <= z.
```

Each independent rounded numerator is a signed integer quotient of `B` times an entry component by `z`. The final diagonal enforces exact trace. The scalar buffer adds the fixed integer `2d` to each diagonal.

Fixed dimension implies a constant number of buffers. Long division uses linear scratch in the operand length. No floating eigenvalue computation is used.

### 4.6 Counterexample to naive truncation

The rank-one rational matrix

```text
(1/13) [[4,6],[6,9]]
```

has a trace-preserving `B=3` coordinate truncation with negative determinant. This is a valid and useful witness that the diagonal repair is not cosmetic.

### 4.7 Boundary of the claim

`R_B` is not affine and not a completely positive map. It is a classical numerical operation on a stored density matrix. Nothing in the later argument requires physical implementability of this map.

## 5. Detailed proof audit: branch contraction and path error

### 5.1 Instrument contraction

Let `X=X_+-X_-` be the Jordan decomposition of a Hermitian matrix. Positivity of every branch gives

```text
||Phi_y(X)||_1 <= tr Phi_y(X_+ + X_-).
```

Summing outcomes and using trace preservation of the total instrument yields

```text
sum_y ||Phi_y(X)||_1 <= tr(X_++X_-)=||X||_1.
```

The proof does not require `tr X=0`. This matters because true and simulated history blocks may have different masses.

### 5.2 Homogeneous repair of a positive branch

For positive `X` with positive trace, define

```text
Rbar_B(X)=tr(X) R_B(X/tr X).
```

It preserves branch mass and has error at most `delta_B tr X`. A positive trace-zero matrix is zero, so the zero branch is defined without normalization.

### 5.3 True and simulated history blocks

For a public history `h` and command law `pi(a|h)`, the true and simulated next blocks are

```text
A_(hay)    = pi(a|h) Phi_(a,y)(A_h),
Ahat_(hay) = pi(a|h) Rbar_B(Phi_(a,y)(Ahat_h)).
```

This is exactly the law of the executable simulator: its outcome probability is the trace of the approximate branch, and its conditional stored state is the repaired normalized branch.

### 5.4 One-step recursion

Insert and subtract `pi Phi_(a,y)(Ahat_h)`. Contraction controls the propagated old error. Homogeneous repair contributes at most

```text
delta_B pi(a|h) tr Phi_(a,y)(Ahat_h).
```

Summing `a,y` for one history gives `delta_B tr Ahat_h`; summing histories gives `delta_B` because the approximate direct-sum state has total trace one.

Therefore

```text
D_(t+1) <= D_t + delta_B.
```

Initial rounding gives `D_0<=delta_B`, and hence

```text
D_t <= (t+1)delta_B.
```

The choice of `B` makes this at most `2^-L` for every prefix.

### 5.5 Adaptation

The controller's next-command distribution is a function of the shared public history. Conditional on a private controller seed, it is deterministic or has a fixed law `pi`. The bound is independent of that seed, so integration preserves it.

No step requires correctness conditioned on a history of tiny probability. The proof stays at the subnormalized block level throughout.

### 5.6 Transcript and terminal measurements

Taking traces of block differences bounds the `l1` distance of transcript probabilities, so transcript total variation is at most `D_t/2`. Appending a common terminal instrument is another positive trace-preserving direct-sum map and cannot increase the norm.

The theorem does not cover a distinct terminal operation chosen from the simulator's private state or an arbitrary external entangled reference.

### 5.7 Rare and zero outcomes

A zero branch has zero integer trace and is never sampled. A nonzero branch may have arbitrarily small relative weight; the rejection sampler still samples it exactly. The error proof charges its repair cost in proportion to its mass, so no outcome floor is required.

There is deliberately no theorem on the normalized conditional state after every rare observed history.

## 6. Detailed proof audit: exact rational sampling and space

### 6.1 Exact branch masses

For stored numerator `P`, define

```text
S_y = sum_r M_(a,y,r) P M_(a,y,r)^*.
```

Every `S_y` is positive Gaussian integral, and

```text
sum_y tr S_y = q^2 tr P
```

by the exact Kraus completeness identity. These traces are valid integer interval lengths.

### 6.2 Uniform integer sampling

Let `T=sum_y tr S_y` and `ell=ceil(log_2 T)`. Uniform `ell`-bit words are rejected when at least `T`; accepted words are uniform on `[0,T)`. Cumulative branch intervals give exactly the desired rational outcome law.

Acceptance probability is `T/2^ell>1/2` unless `T` is a power of two. When `T=1`, zero bits suffice. A single positive branch is returned without consulting the bit source.

### 6.3 Worst-case storage versus expected time

Each trial stores only one `ell`-bit integer and fixed cumulative data. Rejected words and the number of previous trials are discarded. Therefore storage is bounded in every execution, while termination and running time are almost sure/expected rather than worst-case.

### 6.4 Approximate mode

At precision `B`, the repaired numerator always has trace

```text
m=B+2d^2.
```

Thus the state denominator is fixed across the entire history. Branch products have at most two precision lengths plus fixed-input coefficient lengths. A fixed number of matrices, traces, intervals, division buffers, and one sample integer suffice.

### 6.5 Exact mode

In exact mode the program stores the selected unnormalized branch numerator. The omitted physical scalar factor `q^{-2t}` is common and cancels both from conditional states and next-step branch probabilities. Positive trace satisfies

```text
1 <= tr P <= z_0 q^(2t).
```

Every entry modulus is at most `tr P`. Stored and temporary integers therefore have `O_input(t+1)` bits.

### 6.6 Mode selection

The approximate precision is

```text
b = L + ceil(log_2(6d^2(N+1))).
```

Grid mode is used only when this is cheaper than exact linear storage. `L` is scanned with saturation at `N`, so an arbitrarily long precision string is consumed without being represented as an arbitrarily large integer. A binary command counter charges the horizon.

### 6.7 Output

The final numerical matrix is emitted as signed fixed-radix integer entries and one common denominator. This is a numerical density matrix, not physical quantum-state preparation and not a sampled classical encoding whose TV distance is compared to another string encoding.

## 7. Detailed proof audit: sharp matrix-output space

### 7.1 Centering the density-matrix set

Let `c=I/d` and `r_d=sqrt((d-1)/d)`. For every density matrix `D`,

```text
||D-c||_F^2 = tr(D^2)-1/d <= r_d^2.
```

Pure states attain equality. Thus the normalized pure target orbit lies on the unit sphere and all normalized legal decoders lie in its ambient unit ball.

### 7.2 Boundary reduction in arbitrary fixed dimension

A randomized one-pass algorithm with at most `k` complete configurations at a boundary induces a stochastic row by integrating all almost-surely terminating private computation and fresh randomness. At the terminal boundary, conditional means remain in `D_d` by convexity.

The induced rows may depend on public `N,L,t`. This makes the stochastic comparison model at least as permissive as the algorithm.

### 7.3 Reuse of the return-free occupation theorem

The v62 proof uses the decoder geometry only through the bound `||D_i||<=1` after normalization. Therefore it applies to the whole normalized density-matrix set, not merely the original orbit hull.

Mean Frobenius error `epsilon` becomes normalized error `epsilon/r_d`. For `epsilon<=1/4` and fixed `d`, residual amplitude stays uniformly positive. The finite occupation budget becomes

```text
N <= C0 + C1 log k + C2 epsilon k^(2/p).
```

### 7.4 Configuration-count dichotomy

Either the logarithmic term is order `N`, giving exponentially many configurations, or

```text
k^(2/p) >= c N/epsilon.
```

Taking logarithms at `epsilon=2^-L` gives

```text
log_2 k >= c min{N,L+log_2(N+1)} - C'.
```

Because the minimum diverges uniformly in `L>=2` as `N` grows, the additive constant can be absorbed after a fixed-data-dependent horizon.

### 7.5 Fixed-program work-space translation

For one fixed finite program and machine convention, `s` writable bits yield at most

```text
C(s+1)^a 2^(b s)
```

complete configurations, with constants depending on the program. Hence the configuration lower bound gives the same work-space order.

This is not a uniform lower bound over arbitrary program descriptions whose finite control may grow freely with `N,L`. The manuscript explicitly allows a program-dependent threshold and constants.

### 7.6 Upper theorem

Treat every unitary command as a one-outcome rational channel. The positive channel simulator gives deterministic pointwise trace-norm error, which dominates Frobenius error. No spectral constant or stochastic orbit-hull table is used by the upper construction.

### 7.7 Explicit rational `SU(d)` alphabet

Adjacent-coordinate rational `SU(2)` blocks and their inverses generate `SU(d)` by the torus and Lie-bracket argument. Algebraic-entry density permits an imported full group spectral gap. Peter-Weyl transfers the regular-representation estimate to the conjugation action off all invariant functions. The traceless conjugation representation has no fixed vectors.

The least-orbit theorem gives the all-direction exponent `2(d-1)`. This yields explicit fixed-dimensional examples. No dimension-uniform or numerical gap constant is claimed.

### 7.8 Instrument sharpness

When an instrument family contains the unitary subsystem, a deterministic controller may restrict to those commands. Singleton outcomes eliminate transcript randomness, and the classical-quantum error implies the numerical matrix mean condition. The matrix lower theorem follows.

No lower bound is thereby obtained for a transcript-only simulator or for a noisy instrument family with no such unitary subsystem.

## 8. Detailed proof audit: strict cutpoints and numerical calibration

### 8.1 Attenuation automaton

The construction retains each old transition with mass `beta` and sends the remaining mass to accepting/rejecting absorbing states in proportions `lambda` and `1-lambda`. After `t` letters, old mass is `beta^t` and absorbed accepting mass is `lambda(1-beta^t)`. Therefore

```text
f_beta(w)=lambda+beta^|w|(f(w)-lambda).
```

The sign relative to `lambda` is unchanged, while numerical deviation from `f` can approach the full original margin.

### 8.2 Trace approximation and effects

For density matrices `rho,sigma` and an effect `0<=E<=I`, the traceless Hermitian difference has positive and negative parts of equal trace. The effect value differs by at most half the trace norm. Hence numerical approximation preserves a threshold only when the error is smaller than the threshold margin.

### 8.3 Priority implication

Strict-cutpoint state simulation, calibrated full-matrix approximation, positive label width, and finite writable bit-space are distinct resources. Sign-pattern lower bounds do not automatically yield centroid-amplitude lower bounds, and the latter do not constrain unrestricted strict-cutpoint language simulation.

The manuscript's current version-sensitive comparison with Chen--Wu is therefore mathematically relevant. It remains an author-side comparison, not independent priority clearance.

## 9. Code audit: `instrument_streaming.py`

### 9.1 Arithmetic representation

Gaussian integers are represented by integer pairs. Matrix addition, multiplication, adjoint, trace, and fixed-dimensional products are exact. No floating point appears in physical updates or legality decisions.

### 9.2 PSD validation

The specification parser uses a fraction-free Schur-complement recursion. A negative pivot rejects; a zero pivot requires a zero row and column; a positive pivot produces the scaled Schur complement. For exact Hermitian integer inputs in fixed dimension, this is a valid PSD test.

This parser validation is not part of the per-step algorithmic theorem; the physical input is fixed before `N,L` vary.

### 9.3 Positive rounding implementation

`round_density` exactly implements the theorem:

- signed division toward zero;
- exact trace through the last diagonal;
- Hermitian reflection;
- addition of `2d` to every diagonal; and
- denominator equal to the resulting trace `B+2d^2`.

### 9.4 Exact sampling

`uniform_below` rejects values outside `[0,T)` without retaining trial count. `draw` skips zero intervals and short-circuits a unique positive outcome without consuming bits. Invalid bit sources, totals, and negative weights are rejected.

### 9.5 Fixed specification validation

The parser checks:

- fixed dimension and positive denominator;
- positive nonzero initial numerator;
- one-character nonspace ASCII commands;
- nonempty outcome and Kraus lists;
- exact Gaussian-integer entries; and
- exact Kraus completeness for every command.

A zero outcome is represented by a nonempty list containing an explicit zero Kraus matrix.

### 9.6 State update

Branch numerators are computed exactly. Their traces are used as integer weights. The chosen positive branch is either retained exactly or repaired to the fixed denominator. The mass invariant is checked at runtime.

### 9.7 Input handling

`N` is read exactly. `L` is read with saturation at `N`. Commands are consumed once, public outcomes are emitted immediately, and exact command count is checked. Unknown and non-ASCII commands are rejected.

### 9.8 Reference-machine limitation

The program uses `os.urandom` to supply practical bits. It does not certify operating-system entropy or literal CPython heap usage. The theorem instead specifies ideal fresh fair bits and binary integer storage.

I found no obvious mismatch between the written recurrence and the reference implementation.
