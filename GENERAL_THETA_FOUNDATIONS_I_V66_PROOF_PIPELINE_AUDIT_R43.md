## 4. Detailed proof audit: rational Choi repair

### 4.1 Tensor convention

The Choi blocks are

```text
J_y = Sum_(i,j) |i><j| tensor Phi_y(|i><j|).
```

The input factor is first and the matrix is unnormalized. Complete positivity is equivalent to `J_y>=0`. Joint trace preservation is

```text
Sum_y Tr_output J_y = I_input.
```

The total Choi trace is `d`. Every dimension factor in the repair proof should be checked against this convention rather than a trace-one normalized channel state.

### 4.2 Complete-norm estimate

For the lower bound, applying `id_d tensor Lambda` to `|Omega><Omega|/d` gives `J(Lambda)/d`.

For the upper bound, any unit vectors in `C^r tensor C^d` can be written as `(A tensor I)Omega` and `(B tensor I)Omega` with Hilbert--Schmidt norm one. Their operator norms are at most one. Therefore a rank-one input maps to

```text
(A tensor I_n) J(Lambda) (B^* tensor I_n)
```

and has trace norm at most `||J(Lambda)||_1`. Decomposing an arbitrary trace-class input into rank-one singular-vector terms gives the same induced bound. This is independent of `r`.

The outcome-retaining channel has direct-sum Choi blocks, so its Choi trace norm is the sum of block trace norms.

### 4.3 Coordinate-to-operator estimate

Let `N=dn`. A Hermitian coordinate error with every independent real coordinate at most `1/B` satisfies

```text
||E_y||_F <= 2N/B,
||E_y||_op <= 2N/B.
```

The constant is deliberately loose. It safely covers diagonal errors and both real/imaginary off-diagonal coordinates with their Hermitian copies.

For Hermitian `E`,

```text
|<v,Tr_n(E)v>|
 <= Sum_alpha |<v tensor e_alpha,E(v tensor e_alpha)>|
 <= n ||E||_op.
```

Thus

```text
||R||_op <= 2 m n^2 d/B.
```

### 4.4 Residual repair

Only the first outcome and first output coordinate receive the residual:

```text
Q_1 = T_1 + R tensor |e_1><e_1|,
Q_y = T_y, y>1.
```

The choice is conventional. Its only purpose is exact joint partial-trace repair. For every outcome,

```text
||Q_y-J_y||_op <= c/B,
c = 2 n d(1+m n).
```

### 4.5 Positive integer buffer

Since `J_y>=0` and `Q_y-J_y >= -(c/B)I`,

```text
B Q_y + c I >= 0.
```

The numerator has Gaussian-integer entries. Summing output partial traces gives

```text
Sum_y Tr_n(B Q_y + c I_(dn))
 = B I_d + m n c I_d
 = D I_d.
```

After dividing by `D`, the blocks form a genuine instrument, including when some original outcomes vanish.

### 4.6 Error decomposition

Let `F_y=Q_y-J_y`. Then

```text
D(Jtilde_y-J_y)=B F_y+cI-m n c J_y.
```

The first sum is bounded by `m d n c` because `||F_y||_1<=dn c/B`. The second is exactly `m d n c`. The third is

```text
m n c Sum_y tr J_y = m n c d.
```

These are the same quantity. Division by `D` yields `3mndc/D`. The diamond estimate follows from the preceding lemma.

### 4.7 Description length

Every diagonal numerator entry is nonnegative. For each input basis vector, summing all output diagonal entries and outcomes gives `D`, so each diagonal is at most `D`. Positive semidefiniteness gives `|a_ij|<=D`. The common denominator and all entries therefore need `O(log(D+1))` bits. Multiplying by the number of complex matrix coordinates gives the explicit description bound.

### 4.8 Scope of the grid promise

The theorem assumes a certified coordinate error relative to a valid target instrument. An arbitrary floating estimate is not a premise. The implementation's public generic repair routine checks output legality but cannot infer the approximation promise without the target. The `compile_exact` route supplies it by exact directed rational division.

A dyadic grid does not imply a dyadic repaired denominator. The output denominator is `B+mnc`.

### 4.9 Zero outcomes

The generic identity buffer can assign small positive mass to a zero block. This is charged in the diamond error. If a zero outcome is known and must remain exact, it should be removed before repair and restored afterwards, with `m` counting only repaired outcomes.

## 5. Detailed proof audit: adaptive use and stopping

### 5.1 Common tester interface

The tester may:

- hold arbitrary finite-dimensional quantum memory;
- start entangled with the instrument input;
- apply arbitrary channels and finite-outcome measurements between uses;
- select the next classical command from public history and measured memory; and
- retain the full stopped history and memory.

It may not query a coherent superposition of classical commands. The same tester is run in both compared experiments.

### 5.2 One-slot hybrid

In adjacent hybrids, the state before the replaced slot is identical. The public classical registers decompose it into positive quantum blocks indexed by command and history. On each block, the outcome-retaining instrument difference has trace norm at most `delta_t` times the block trace. These traces sum to one.

All later operations in the hybrid pair are the same quantum channels. Complete trace-norm contraction preserves the one-slot error. Summation over slots gives the additive bound.

### 5.3 Bounded public stopping

Introduce a public halt flag. Once set, the tester applies identity evolution to the halted block and preserves its history/memory until the common terminal time `N`. A stopping rule based on public history is then simply part of the tester. No conditional accuracy claim on a rare stopping history is used.

### 5.4 Numerical meaning

This theorem compares two genuine quantum instruments. It does not construct a classical physical device that acts on an unknown entangled state. A specified joint system can be numerically simulated only after its full rational joint description and dimension are supplied and charged.

## 6. Detailed proof audit: posterior conversion

For each history block,

```text
A_h=p_h rho_h,
B_h=q_h sigma_h,
e_h=||A_h-B_h||_1.
```

Trace contraction gives `|p_h-q_h|<=e_h`. Then

```text
p_h ||rho_h-sigma_h||_1
 <= ||p_h rho_h-q_h sigma_h||_1
    + ||q_h sigma_h-p_h sigma_h||_1
 <= e_h+|q_h-p_h|
 <= 2e_h.
```

If `q_h=0`, choose any `sigma_h`; the inequality still holds. Summation gives the true-law mean bound. Markov gives the tail estimate. For an event, sum the positive blocks first, apply the same inequality, and divide by the true event probability.

The factor `2` is intrinsic to this elementary conversion. Small global block error can coexist with trace distance two on a very rare posterior. The regression suite includes this counterexample.

## 7. Detailed proof audit: variable-description streaming

### 7.1 Valid input

A command instrument has positive Gaussian-integer Choi blocks `C_(a,y)` of order `d^2` and denominator `D_a`, satisfying

```text
Sum_y Tr_d C_(a,y)=D_a I_d.
```

The initial matrix is a positive nonzero Gaussian-integer numerator. Every explicit bit in dimensions, delimiters, names, entries, and denominators contributes to the description length `S`.

### 7.2 Integral branch action

The branch numerator is

```text
S_(alpha,beta)=Sum_(i,j) C_(i alpha,j beta) P_(i,j).
```

This is `D_a Phi_(a,y)(P)` in the declared Choi convention. Complete positivity makes it positive. Taking traces and using the partial-trace identity gives

```text
Sum_y tr S_(a,y)=D_a tr P.
```

The branch probability is the exact integer ratio

```text
tr S_(a,y)/(D_a tr P).
```

The normalized next state is `S/tr S` on a positive-mass branch.

### 7.3 Exact mode

The simulator retains the selected numerator `P_t` without normalizing it. The omitted product of command denominators and prior scalar masses is common to all calculations where it matters and cancels in branch probabilities and normalized output.

Since every branch trace is at most the summed trace,

```text
tr P_t <= z_0 D_*^t.
```

Positivity bounds every entry modulus by the trace. Thus a constant number of `d by d` integer matrices use `O(d^2(ell_0+tH))` bits up to index and scratch factors.

### 7.4 Grid mode

Set `B=2^b`. The stored repaired density numerator has fixed trace `B+2d^2`. Applying the rational instrument gives exact integer branch matrices and weights. Sample one branch according to those weights, normalize it conceptually, and apply the inherited positive repair back to the fixed denominator.

The actual branch law is calculated from the approximate stored state. No exact-state oracle is used. The pathwise comparison works with subnormalized blocks and therefore includes the induced outcome-distribution discrepancy.

### 7.5 Error recursion

At initialization the repaired state error is at most `6d^2/B`. At each use, the direct-sum instrument contracts the sum of trace norms of Hermitian block differences. Repairing the chosen simulated branches adds at most `6d^2/B` times total simulated branch mass, which is one for live histories and at most one after stopping.

Hence

```text
D_t <= (t+1)6d^2/B.
```

The selected precision makes this at most `2^(-L)` for every prefix `t<=N`. A common stopped process is obtained by freezing halted blocks.

### 7.6 Mode choice

Define

```text
Q=ell_0+NH,
b=L+ceil(log_2(6d^2(N+1))),
u=min(Q,b).
```

Exact mode is chosen when `Q<=b`, grid mode otherwise. This ensures state precision cost `u` up to dimension and denominator overhead. It is not a claim that the switch minimizes every concrete input's peak memory.

### 7.7 Space accounting

Each Choi numerator entry has modulus at most `D_a`; positivity and the partial-trace identity give this bound. Multiplying one Choi entry by one state entry uses lengths `H` and `u+O(log d)`. Summing `d^2` terms adds `O(log d)` bits.

A constant number of matrices, traces, indices, division buffers, and one rejection word suffice. The outcome list can be scanned more than once, so all branch matrices need not coexist in memory. The full description is retained and charged as `S`.

### 7.8 Rejection sampling

For total integer mass `T`, draw `ceil(log_2 T)` fair bits and reject values at least `T`. Acceptance probability exceeds one half unless `T` is a power of two, where it is one. The expected number of attempts is below two.

No unbounded attempt counter or rejected word is retained, so trial storage is uniformly bounded. Runtime and fair-bit use are expected, not worst-case. A single positive branch consumes no random bits.

### 7.9 Parameter parsing

The precision request is scanned with saturation at `Q`. Once exact mode is forced, the exact larger value is irrelevant. The entire parameter digit stream still costs preprocessing time in its actual length. A binary command counter charges the public horizon check.

### 7.10 Output

The final numerical state is emitted as signed binary/hexadecimal Gaussian-integer entries and a common positive denominator. No decimal conversion, eigenvalue calculation, Kraus factorization, or physical quantum preparation is included.

## 8. Variable-dimensional PSD validation

### 8.1 Exact criterion

The parser first checks Hermitian symmetry. For a positive pivot, it applies the rational Schur complement. For a zero pivot, positivity requires the entire row and column to vanish, after which they may be removed. A negative pivot rejects.

This is an exact congruence-based PSD criterion.

### 8.2 Operand growth

After each elimination, fractions are reduced. Every remaining entry can be represented as a ratio of minors of the original rational matrix. Hadamard's determinant bound limits the bit length of those minors by a polynomial in the matrix dimension and original entry lengths.

Therefore validation has polynomial bit time and polynomial workspace in the explicit input size `S`. The theorem does not give an optimized exponent and does not claim the validation workspace matches the subsequent streaming bound.

### 8.3 Code detail

The implementation does not search for a nonzero diagonal pivot. This is harmless for PSD recognition: if the leading diagonal is zero in a PSD matrix, its row and column are zero, and the implementation removes them. The manuscript's reference to pivot permutation can be simplified.

### 9.2 Index convention

The most dangerous implementation error is inserting a transpose or conjugation on `P_(i,j)` in the Choi contraction. The code uses the direct coefficient formula. The test suite constructs Choi matrices from supplied Kraus operators and verifies equality branch by branch.

### 9.3 CP versus positivity

The suite includes the ordinary transposition map: it is positive and trace preserving, but its Choi matrix is not positive. This negative control correctly prevents the inherited weaker positive-instrument argument from being mistaken for complete positivity.

### 9.4 External references

Finite tests apply original and compiled instruments to entangled system-reference inputs, including an unbalanced entangled vector, and compare exact rational block norms. An adaptive tree retains a reference and inserts common joint tester unitaries, with some branches stopped and frozen.

These tests are effective convention and implementation regressions. They do not prove the arbitrary-reference theorem by enumeration.

### 9.5 Posterior warning

A rare branch with true and simulated normalized states at trace distance two but total mass `1/1024` is retained as a negative control. This pins the distinction between small global history error and pointwise normalized posterior accuracy.

### 9.6 Randomness and interpreter scope

The CLI's OS source is not a formal ideal-randomness certificate. The exact tests can supply deterministic bit functions. CPython heap behavior is not a proof of the mathematical bit-space theorem. The code and documentation state both limitations.

Naik--Zartab--Gisin--Banik, arXiv:2501.15807v2, consider a known qubit input on one side, an unknown or externally entangled system on the other, and arbitrary joint measurements. They prove that a perfect qubit channel cannot be simulated by any finite-round finite classical messaging protocol in that generic model. They also give finite-resource simulation for noisy depolarizing channels, with cost growing as noise vanishes.

This is not an antecedent for the integer Choi repair formula. It is a directly relevant operational boundary. Revision 66's instrument-description theorem remains consistent with the no-go result because it outputs a **quantum instrument description** and assumes the instrument itself remains available as a genuine quantum operation in the adaptive comparison. Its numerical streamer simulates a specified matrix trajectory; it does not act physically on unknown entangled input.

The revised paper should state this comparison explicitly. Otherwise readers may overinterpret “reference stable” and “classical numerical program” as a physical classical channel simulator.

### 12.3 Channel learning versus deterministic descriptions

Current channel-learning work in diamond distance studies query/sample complexity for an unknown channel. Revision 66 begins from a supplied certified rational description or certified coordinate approximation. Its finite net is a deterministic covering/encoding statement, not a learning theorem. A theorem-level comparison should say this explicitly, especially when discussing dimension and accuracy dependence.
