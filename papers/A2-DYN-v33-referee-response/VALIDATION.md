`tools/verify_v33.py` checks the exact baseline tree and every baseline hash, all 68 core inclusions, retention of all 887 inherited mathematical labels, byte identity of the 66 inherited core and 71 inherited Python files, unchanged bibliography, all five main-text replacements, complete ordinary-source hashes and the qualification workflow hash. Remote execution additionally requires the exact v32 report blob. The baseline v32 verifier is run separately before the new verifier.

The new finite diagnostic uses a four-state deterministic suspension with unequal roofs and explicit initial/terminal cell partitions. It compares direct forward evolution with the independent interval-overlap calculation at 147 targets, checks 252 source translation bounds, 24 curvature endpoint measures, 12 all-label Fourier tail cases, and 18 positive convolution/inversion identities. It checks the five rational central exponents, analytic margins and physical covariance Jacobian. Negative controls detect loss of an initial cell offset, a wrong age-transform sign and confusion between a second-derivative measure and an `L1` second derivative. This periodic finite model is not claimed mixing and cannot prove the Gaussian theorem.

Normal and optimized outputs must agree byte-for-byte. Six retained geometry/inversion diagnostics also run. Native TeX runs without shell escape until references stabilize; undefined references, package/LaTeX warnings, missing glyphs and overfull boxes fail the build. The rendering step extracts exact PDF text, records metadata and renders the new proof interval plus introductory pages.

The dynamic `evidence/build-receipt.json` records the checked-out SHA, workflow event SHA, run ID/attempt, clean source, paper tree, source hashes and PDF/log hashes. No static file predeclares a future run successful. Local validation without a Git checkout or without the newly fetched controlling report is marked as such; remote qualification requires both. Finite algebra, compilation and rendering are not mathematical proof certification or independent human review.
