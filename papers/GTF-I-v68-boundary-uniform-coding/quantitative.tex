\begin{abstract}
We determine joint horizon--accuracy laws for reusable descriptions of
quantum instruments. For $m$-outcome instruments from $M_d$ to $M_n$
with a fixed positive Choi margin, the optimal length is
$(s/2)\log_2N+s\log_2(1/\delta)+O(1)$, where
$s=d^2(mn^2-1)$; the remainder is uniform for all $N\ge1$ and
$0<\delta\le1/32$. The error is the unhalved final-state trace norm
against arbitrary common adaptive quantum testers, including references,
feedback and bounded public stopping. For input-erasing preparation
instruments with output rank bounds $r_y$, the same law holds without
a positive margin, with $s$ replaced by
$v=\sum_y r_y(2n-r_y)-1$. A rational triangular-factor code attains
the latter law, preserves zero outcomes and never increases an output
rank. It uses exact rational comparisons and integer square roots,
without representing algebraic factors. A local binary test supplies
the matching converses. The single-use intrinsic Choi
entropy and reference-stable compiler form the preliminary results. Description length, numerical workspace,
unknown-channel learning and physical classical simulation remain
distinct tasks; dimension-dependent constants are not optimized.
\end{abstract}
\maketitle
\noindent\textit{Operational interfaces.}
Description compilation returns a mathematical quantum instrument;
numerical streaming processes fully specified matrix data. Neither is a
physical classical device acting on an unknown quantum input, and
neither is merely a transcript-only simulation task. The new code lengths
charge the reusable description, with fixed public dimensions, rank bounds where applicable, horizon and error.
All joint-state errors
are unhalved trace norms; transcript total variation is half the classical
block trace norm.
