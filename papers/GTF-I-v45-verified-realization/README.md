## New result

On the actual invariant seed span, let L be the closed normal subgroup generated by differences `U_a^(-1)U_b` of the finite orthogonal command alphabet. Then

```
sup_N W_(N,0) < infinity   if and only if   L is finite.
```

If L is infinite, width tends to infinity at every fixed error below the explicit activated threshold. For symmetric coordinate seeds the sufficient threshold is `epsilon<rho/(2D)`. The proof covers arbitrary hidden states, arbitrary epoch-dependent stochastic rows, disconnected and noncommuting actions, and redesign at every horizon. No spectral gap or Diophantine hypothesis is assumed. A common deterministic drift can be absorbed by the horizon decoder and must not be mistaken for memory demand.

All finite planar rotation alphabets are consequently classified for boundedness: exactly the alphabets with rational angle differences have bounded width. Growth rates in all other cases are not determined by this criterion. For matrices and seeds in a specified real number field, exact normal-conjugation enumeration and a proved finite-group order bound give a terminating boundedness decision. This is a decidability theorem, not a practical general implementation or a spectral-gap oracle.

The exact full-continuation flag formulation, the one-sided packet/enclosure comparison, the metric and Liouville proofs, and the finite-bit compiler remain. Classical cones, signed Hankel theory, HMM factorization and matrix-group algorithms are explicitly credited. Revision 44's profile comparison and finite-bit results are inherited, not counted as new v45 discoveries.
