# Resource ledger — Revision 72

The new invariant counts a reusable classical description of a supplied mathematical quantum instrument. Public data are the fixed input/output dimensions, ordered outcome labels, conditional rank bounds, N, requested unhalved tolerance, schema and any fixed orthogonal recovery subspaces. Uniform remainders are fixed-dimensional; the half-dimensional full-range results also fix delta_*<2.

Charged fields are the flag permutation, b=d(d-1) signed flag digits, and every row factor mask, anchor/sign and integer body. The expanded common-denominator Choi representation is not the payload. Its rational size is bounded separately by the construction. Encoder input storage, temporary arithmetic, input bit length, runtime and decoded-matrix storage are not claimed to equal the optimal description length.

The target encoder is exact for rational matrix data. Real targets are handled by the mathematical exact-real chart/factor construction; there is no claim of finite access to arbitrary unspecified reals. The direct flag implementation avoids normalized algebraic vectors and exhaustive unitary-net search; this does not convert description optimality into a growing-dimensional runtime claim.

An N-slot common programme may use one state per row per slot. That is a quantum comparison in the proof, not a claim about physical sample usage or universal processor hardware. The model is neither unknown-device learning nor finite-classical-message simulation of unknown entangled inputs. The structural companion's classical repeatable probes are a separate interface. All earlier resource distinctions remain intact.
