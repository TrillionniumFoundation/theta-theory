# Revision 71 resource ledger

The primary resource is a reusable supplied-data description. Fixed public dimensions, input measurement basis, output labels, rank bounds, horizon N and tolerance delta do not count as payload. Conditional row pivot masks and fixed-length integer bodies do. The compressed length is the sum of the inherited row bounds and has coefficient V/2 for log N and V for log(1/delta).

The exact encoder can use arbitrary rational intermediate arithmetic. Expanded Choi blocks have dimension dn, a common denominator given by the least common multiple of the row normalizers, and separately charged storage. Neither encoder workspace, decoder workspace, total source-data length nor mutable streaming memory is identified with compressed length.

The metric makes at most N uses of the same instrument, against arbitrary common finite-reference adaptive quantum testers. It is an unhalved final-state trace norm. A conditional-row programme with up to dN states is a proof comparison, not extra calls and not a physical classical simulator. The measured input result is private to the common processor, except for the actual declared output flags.

The common tomography experiment is a lower-bound witness with an explicitly counted finite sample budget. It does not turn the supplied-description theorem into an optimal learning theorem. At delta=2 the covering problem collapses to one centre; constants depend on the fixed cap delta_*<2. No coherent full-error or dimension-uniform law is asserted.

All earlier numerical streaming, hidden-label width, coherent tensor description and repeatable-probe resources retain their separate definitions and hypotheses in the complete edition.
