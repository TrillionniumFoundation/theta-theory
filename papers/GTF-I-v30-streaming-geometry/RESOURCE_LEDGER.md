# Resource ledger — revision 30

All new exact counts refer to known primitive probabilities, atomic stochastic rows and a declared finite clock unless an alternative is stated explicitly. A persistent random seed is not free. Program/table description length and running time are not counted by retained-state width.

| Result | Charged states and retained information | Excluded inference |
|---|---|---|
| Coherent rank saturation | Every interface cut, including mandated action/report buffers; component generators satisfy one common shifted continuation law | Separate cut factorizations are not automatically compatible; autonomous reused rows require extra equalities |
| Checkpoint query complexity | All input-dependent information and past random choices pass through one query-state label | Upstream memory is unrestricted only in K_n, not in W_n |
| Reservoir | t+1 labels after t bits, including state zero; fresh replacement coin has no persistent copy | The vectors are read-only decoder descriptions, not stored real vectors |
| Hadamard | m labels throughout; redrawn index is represented only by the new label | Peak n+1 at m=n+1 does not imply the minimal t+1 width at every early cut |
| Block streaming | At most floor(n/ell) codeword labels and ell raw bits; compression overwrites a block at an explicit epoch | No free full input, codebook selector or hidden copy of a compressed block |
| Final query | One externally supplied atomic j followed by a sampled binary output, at most two terminal states | A buffered or bitwise query interface can require extra states |
| Generative PRFA comparison | Phase-tagged acquisition states plus n(n+1) query-buffer states and one terminator | External-input peak counts are not reported as total generative-automaton size |
| Approximate channel | Uniform row-TV defect at every input/query; effective signal (eta-2 epsilon)_+ | Exact one-query law does not give an independent joint n-output law |
| Repeated sensor consumer | Fresh installation at each round, or an explicit conditional row-defect hypothesis | No reuse of one unrefreshed label is assumed to preserve independence |
| Retained physical results | The v29 supporting volume keeps exact known-target atomic rows and acquired-calibration approximate guarantees separate | The collision twelve-state result remains fixed-clock, not arbitrary feedback scheduling |

Rational rows admit exact variable-length coin sampling in principle. Such a sampler is a different machine: its workspace and time have not been silently folded into the atomic counts. Hadamard existence is assumed only at a specified order, with the Sylvester sequence proved explicitly; no general Hadamard conjecture is used.
