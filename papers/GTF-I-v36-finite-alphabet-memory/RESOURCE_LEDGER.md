A complex or vector readout combines decoder columns in a proof; it does not request simultaneous independent answers. Private coins do not persist outside the register. A distribution over deterministic tables is not a free persistent shared seed. Fixed common rows do not mean one unchanged decoder for all N. Label bits exclude table description and construction; neither the atomic nor the compiled theorem is a uniform-space claim.

The selected-cut positive factorization embeds in a complete machine with unbounded other cuts. Raw suffix retention after l symbols uses at most (d+1)|A|^l labels in that proof. It is not the small-width global construction.
