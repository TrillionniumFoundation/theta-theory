# Actual local source-content execution

`receipt.json` is the compact JSON serialization of the actual v34 validator receipt. It retains every original field, including null checkout/run identifiers, command arguments, exit codes, output digests, source manifests and diagnostics. Compact serialization changes whitespace, not the record.

The full local command logs and final TeX log are included in the separately delivered `A2_v34_local_execution.zip` (SHA-256 `b22402a2402014367cfa56535b0f85c86ba1c674b392e9a2d4a17ef31581def6`). Their per-file digests are in the receipt. This repository entry does not assert that those historical local log filenames are generated by the hosted runner. The current workflow archives its own actual logs, receipt, PDF and source package against its own triggering SHA.

The execution built only the current one-article journal package, checked the complete historical tree, and reran the selected retained suites. It did not rebuild the sixteen historical documents, execute a physical sensor or certify a continuum proof.
