\subsection{Checkpoint and common-filter criteria}
\begin{definition}[Risk criteria]\label{def:monomial-risks-v24}
Fix a known calibration $a$ and the positive experiment above.
Let $\mathbb P_N^a$ be the law obtained by independent uniform commands
and the actual conditional report probabilities, with the latent
parameter drawn from $\mu$. Its checkpoint marginal is
$\mathbb P_n^a$. It is not the command law conditioned on a selected
report word. The set $\mathcal H_n$ consists of all admitted prefixes.

For an encoder $E$ with at most $M$ labels and a decoder $D$, let
\[
 r_n(h;E,D)=\mathbb E_{\rm code}\left[
  \frac1{s_n^{\rm q}}\sum_{j=1}^{s_n^{\rm q}}
       \bigl(D(E(h),j)-p_{n,j}^a(h)\bigr)^2\right],
 \qquad p_{n,j}^a(h)=\mu(P_hH_{n,j}).
\]
The expectation averages independent coding randomness at fixed
history; the query is revealed only after encoding. Decoder values
lie in $[0,1]$. Clipping to this interval cannot increase squared loss.
The two checkpoint optima are separate infima:
\begin{equation}\label{eq:monomial-checkpoint-risks-v24}
 \begin{split}
 \overline R_{M;n,m}^{a}
   &=\inf_{(E,D)}\int r_n(h;E,D)\,\mathbb P_n^a(\dd h),\\
 R_{M;n,m}^{a,\max}
   &=\inf_{(E,D)}\sup_{h\in\mathcal H_n}r_n(h;E,D),
 \qquad m=N-n.
 \end{split}
\end{equation}
Let $\mathcal F_M$ be the common causal filters of
Definition~\ref{def:finite-state}. Their checkpoint risks $r_n(h;F)$
are defined by the same expression with the retained state produced
by $F$. Define
\begin{equation}\label{eq:monomial-causal-risks-v24}
 \begin{split}
 \mathfrak R_{M,N}^{a,\mathrm{av}}
   &=\inf_{F\in\mathcal F_M}\max_{1\le n<N}
       \int r_n(h;F)\,\mathbb P_n^a(\dd h),\\
 \mathfrak R_{M,N}^{a,\max}
   &=\inf_{F\in\mathcal F_M}\max_{1\le n<N}
       \sup_{h\in\mathcal H_n}r_n(h;F).
 \end{split}
\end{equation}
In particular, the filter infimum lies outside the checkpoint maximum,
and the coding expectation lies inside the worst-history supremum.
One filter is required for all checkpoints. The common law specifies
compatible checkpoint marginals; in a physical run only the selected
checkpoint and its one future query are executed.
\end{definition}
