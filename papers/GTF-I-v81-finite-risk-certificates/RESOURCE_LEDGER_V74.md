# Revision 74 resource ledger

The mathematical task is supplied-description compilation for ordered unbiased binary qubit measurements. The encoder receives x; neither x nor its visibility is learned through queries.

The charged persistent reusable description is one codebook index. Public resources are N, requested unhalved error, and the fixed disk/ball interface dimension. Visibility and direction are both target coordinates included in the index. At erasure, direction has no identifiable meaning and a single decoded zero word represents the measurement.

Separate, not part of payload: input rational coefficient lengths; canonical JSON envelope; O(B) radial table and bounded cache; exact arithmetic buffers; encoder time; expanded rational Choi matrices; proof programme bits/copies; quantum tester memory and reference dimensions; physical implementation resources. No free visibility, phase or chart digit is hidden in the public header.

The old v73 resource ledger remains valid for its explicitly public-visibility theorem. The older streaming workspace theorem is a different interface and is not silently transferred to this codec.

Upper codes return mathematical CP/TP instruments. They do not implement a finite-classical-resource simulator for unknown quantum inputs. Lower testers may depend on a known pair; they do not constitute one global estimator for the codebook. Lower covering centres are arbitrary legal memoryless instruments; upper centres are in the target family.
