## Reproduction

Use Python 3.12 and a TeX installation providing `pdflatex`, `amsart`, AMS packages, `mathtools` and `hyperref`, plus Poppler (`pdfinfo`, `pdftotext`, `pdftoppm`). From this article directory in a clean checkout:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
bash build.sh
```

It does not run the historical repository-wide gate. The dedicated branch workflow is mirrored under `ci/` and records its executed checkout SHA and outcome.

