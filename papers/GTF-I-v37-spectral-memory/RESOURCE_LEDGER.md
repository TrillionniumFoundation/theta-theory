# Resource ledger — v37

| Item | Convention |
|---|---|
| Atomic memory | Maximum number of available labels at declared macro cuts; state alphabets and rows may vary by layer and horizon. |
| External information | One seed, one command per slot, one final coordinate query. The latest command is consumed in its row. No retained transcript, random seed or adaptive schedule is free. |
| Nonuniform program | Epoch, horizon, row tables, generation, lookup, arithmetic and exact atomic random sampling are not charged. This is not total branching-program size or uniform space. |
| Proof-side smoothing | The Gaussian, conditional centroids and densities exist only in the analysis; no such vector or noise source is supplied to the machine. |
| Spectral hypothesis | Norm gap on the full mean-zero sphere L2 space. Matrix eigenvalues in the defining representation are insufficient. |
| Exact upper | Common command rows, horizon-dependent label set and final decoder; rational sparse rows exist for rational data. |
| Separate cut | d+1 when identity is available and d*rho<1; other cuts in the isolated optimization are uncapped. |
| Padded sampler | Exactly (L-1)b private fair bits per macro update. Old label/input/tree/relation/bit progress and selected output during padding are all counted. No private timing leakage or free microstep clock. |
| Sampler replacement | Old label is released after selecting the new leaf. Two independent K-label registers are not held together. |
| Padded cost | O(K(b+1)) labels for fixed alphabets and sparsity. Read-only threshold tables remain free. Fixed-error approximation, not exact irrational sampling. |
| Quantum resource | Dimension-two qubit with seed reset, fixed unitary commands and one final Pauli measurement; no claim about minimum stationary entropy. |
| Comparison units | Explicit example: Theta(N) atomic labels, log2 N+O(1) label bits, one qubit. Compiled bits have an additional O(log log N) upper allowance. |

A fixed-word correctness requirement licenses an independent proof-side command law. It does not identify proof-side distributions with optimized adaptive experimental policies. Actual terminal error and an accumulated local-deficiency upper certificate remain different quantities.
