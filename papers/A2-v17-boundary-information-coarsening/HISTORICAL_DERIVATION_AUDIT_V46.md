## New noncircular dependency chain

`finite cell masses + mesh + known H_(m+1)` → interior L¹ → interior C^m → anchored action jet → finite Bellman contact recursion → anchored support jet → bounded-strip continuation → complete support images → finite Bézout incidence rotation → root-frame displacement cochain → marked Euclidean lattice and representatives.

The finite histogram-to-table bound uses only true realizable candidates in the quantified class. No arbitrary noisy polynomial is assumed to define a valid convex billiard. Statistical reconstruction is formulated first as a confidence set of such candidates. The measurable approximate selector uses a nonnegative excess residual, so different gap and histogram tolerances are not inadvertently interchanged.

The unknown order-n graph term is isolated only after the smooth finite-jet filtration is established. The Bellman remainder at order n uses V through order n-2 and lower action/graph jets. The stationary-value error from the missing order n-1 term is order 2n-2. The graph-to-support calculation has the analogous cancellation. This is why no unobserved order n+1 graph derivative enters the finite algorithm.

## What the new result does not assume as an answer

The class supplies an analytic strip and forward bounds, not the inverse modulus, Fourier phases, recovered support images, the Euclidean lattice, or registration. A finite asymmetry witness supplies indices and a positive lower bound, not the measured coefficients. The Bézout formula uses no branch choice of a complex argument. Classical continuation has severe conditioning and is not presented as a new continuation principle.

The original qualitative C²-relative genericity result and the new bounded-holomorphic quantitative class have different topologies. An analytic radius cannot be supplied by a C² neighborhood. Calibration and the retained reconstruction transcript are also different objects; the new result is not an unmarked discovery theorem and does not retroactively erase the original position sensor.
