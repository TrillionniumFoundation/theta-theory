Audit date: 2026-09-22. This is a bounded source audit, not a certification of originality.

## Newly checked general determinantal comparison

Anne Frühbis-Krüger and Matthias Zach, *Determinantal Singularities*, arXiv:2106.04855v1 (2021), official source https://arxiv.org/abs/2106.04855 and PDF https://arxiv.org/pdf/2106.04855.

The following are explicitly treated as classical input in the manuscript: invertible changes of matrix presentation (Lemma 1.3); the kernel/image description of tangent spaces to rank strata (Remark 1.18); the local smaller-matrix model (Section 1.3.2, equation (13)); transversality/essential nonsingularity (Definition 2.11, Proposition 2.12). The text was inspected. The web screenshot attempts for pages 12–13 returned fetch errors; no successful visual audit of that external PDF is claimed.

The Stacks Project, Section 15.8, Tags 07Z8 and 07ZA, official sources https://stacks.math.columbia.edu/tag/07Z8 and https://stacks.math.columbia.edu/tag/07ZA: presentation independence and base change of Fitting ideals. Tag 031R is retained for reducedness via R0 + S1.

These references prevent the intrinsic normal derivative, Schur elimination, generic determinant model or Fitting base change from being represented as new mathematics. The new hyperplane theorem instead computes a particular natural family's entire failure support, coranks, regular locus, saturation, associated-point set and growing nilpotency lower bound. Whether every one of these family-specific statements is historically new still requires a full nearest-literature priority assessment.
