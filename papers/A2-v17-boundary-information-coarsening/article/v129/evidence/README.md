# v129 evidence directory

Generated build products are intentionally not copied from v128.

Running `build.sh` regenerates the exact K3, corank-two, stratified-rank-two,
boundary-atlas, and generic-boundary certificates, compiles the self-contained
v129 article, and writes `BUILD_RECEIPT.json`.

The receipt separates scripts actually executed, exact algebraic identities
checked by those scripts, and structural proofs that remain mathematical source
arguments rather than machine-certified claims.
