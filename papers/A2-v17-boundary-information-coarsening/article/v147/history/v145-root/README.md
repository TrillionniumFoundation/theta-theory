## What changed

The new curve-supported theorem reconstructs every complex quadratic pencil from an unmarked order-d neighbourhood over a projective curve with nontrivial right projective bundle. In particular one Schubert line suffices, with the same smallest uniform order d=n^2+2n-4. The inverse is not reduced to a framed Pluecker encoding or one unmarked Artinian slice.

The fixed-spectrum proof now has exact original Ohta theorem/page citations, an isolated classical lemma, an independent dimension calculation, and an explicit O/SO component argument. The applications manuscript includes both requested critical-scheme proof clarifications: a constant prime-field point in the finite-flat argument and the Hessian chain rule in the nonreduced critical quotient.
