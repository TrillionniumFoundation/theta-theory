\section{Marked objects and their equivalences}\label{sec:categories}
Time is a marked coordinate throughout. A residual germ is the feasible image of
$R(x,t)=O(x)-o(t)$, together with $t>0$, its limiting observation, and a positive
quadratic metric on observation increments. A source equivalence is a germ of a
homeomorphism of feasible sets over time which preserves $O$. It preserves the
residual image, whether or not the source coordinates are regular. An observation
coordinate change with derivative $T\in\mathrm{GL}_m(\R)$ transports
\[
 (E,H,\mathcal C(E))\longmapsto
 (TE,T^{-\mathsf T}HT^{-1},T\mathcal C(E)T^{\mathsf T}).
\]
Thus the numerical metric cost is unchanged. Replacing $t$ by $s^a$ is a change
of marking, not an equivalence preserving the numerical contact order.

For a finite-map presentation the fast map $F$ is additionally marked. Fast
coordinate differentiation means differentiation in $F$, not in an arbitrary
source chart. The derivative certificates below are invariants of this marked
presentation and transported tubes. The residual set that they construct is an
invariant of the observation germ without this additional presentation.

An endpoint object consists of a labelled retained cone $X=\R_+^k$ and the
function $G:X\to\R$. A representation is a positive matrix
\begin{equation}\label{eq:intro-profile}
 Q=\begin{pmatrix}A&B\\B^{\mathsf T}&C\end{pmatrix}>0,
 \qquad G_Q(x)=\min_{z\in\R_+^e}(x,z)^{\mathsf T}Q(x,z).
\end{equation}
Its fibre means \emph{all} positive representations inducing the same labelled
function. Positive diagonal changes and permutations of $z$ always preserve
that function. They need not exhaust its fibre on a nonvisible stratum. Retained
coordinate changes are stated separately and are not silently divided out.
A minimal distance representation uses $L\in\mathrm{GL}_e(\R)$,
$T\in\R^{e\times k}$ and $K=L\R_+^e$ in the ambient space $\R^e$.
The equivalence $(T,K)\sim(OT,OK)$ uses $O\in\mathrm O(e)$.
Embeddings in larger ambient spaces are not included in this minimal category.

Finally a labelled statistical quotient is the Gaussian experiment
$\{N(Qv,Q):v\in\mathcal K\}$. Statistical equivalence means Markov kernels in
both directions preserving each parameter label. Theorem~\ref{thm:experiment}
identifies its equivalence class with $Q$ in the fixed retained coordinates.
The dual tensor $R=Q^{-1}$ determines the same matrix object, but a value query
$u^{\mathsf T}Ru$ is not a value query $v^{\mathsf T}Qv$. All query statements
below specify which of these two oracles is supplied. None is a sample-count
statement. These distinctions fix the meaning of ``intrinsic'' in each result.
