Verify an actual marked-boundary A2-DYN CI ZIP and its complete frozen source.
The verifier does not execute archive code or extract archive files. All
inputs are explicit. A successful result refers only to the observed exact
run/head. This is a new recovery adaptation of the published B verifier, not a
recovery of the lost pre-maintenance C helper. The actual CI environment is
Python 3.11.

options:

  --article ARTICLE
  --archive ARCHIVE
  --tested-commit TESTED_COMMIT
  --tested-article-tree TESTED_ARTICLE_TREE
  --tested-root-tree TESTED_ROOT_TREE
  --workflow WORKFLOW
  --expected-identities EXPECTED_IDENTITIES
  --manifest MANIFEST
  --reference-build REFERENCE_BUILD
                        Final local mathematical-checks.json/native-
                        typeset.json directory
  --reference-source REFERENCE_SOURCE
                        Separate final local source-checks.json, if not in
                        reference-build
  --reference-history REFERENCE_HISTORY
