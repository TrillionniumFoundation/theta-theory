## Concrete lessons used in the revision

The old C1 text writes a joint expression using the old state while describing conditioning of the next state. The new saturated reconstruction instead defines the old state, action, new quotient and generated report in one joint kernel, and displays the likelihood ratio at both times. Domination of the report alone does not become domination of all hidden-state laws.

The old A4 coupling proof promotes summable variations to exponential variation. No such implication is used here: the certified tree theorem assumes the actual energy contraction constants, and the generic filter theorem assumes actual contraction. The exact compatible-partition theorem requires neither assumption.

Modern A1's common failure report is essential. The new observed-history likelihood sums over unobserved raw cells before posterior conditioning. A separate failure encoder for each raw cell would implement a different experiment. The scalarized criterion is kept distinct from a maximum criterion for a privately randomized controller.

Modern A2 distinguishes physical unjittered counts from proof-only randomization, and local Gaussian comparison from global or unknown-mark sufficiency. The new terminal spectrum uses the same target family and the same parameter-independent kernels. The historical Sinai chain is not replaced by this statistical protocol.
