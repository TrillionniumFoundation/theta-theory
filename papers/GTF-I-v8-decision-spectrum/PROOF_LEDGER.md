## Proof inspection corrections made before publication

1. Product-topology closure of an infinite risk-vector set is not identified with uniform task regret; the displayed infimum/supremum order remains authoritative.
2. Saturated parameter sufficiency is not extended to a latent-target loss without its joint conditional-law condition.
3. Minimax law-presentation uses a single unknown-parameter task. It is not a collection of point-prior tasks that would disclose the law.
4. Gaussian terminal cardinality excludes an uncharged public side channel; only fresh private randomization is allowed in that theorem.
5. A1 finite-command scalarization is not substituted for its distinct maximum-over-checkpoints objective or continuous-command acquisition geometry.
6. Certified energies need all contiguous factors, not just isolated suffix values: arbitrary relative approximations can otherwise break the executable tree.
