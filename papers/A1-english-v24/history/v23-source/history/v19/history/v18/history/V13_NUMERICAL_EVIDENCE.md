# Executed evidence and its scope — v13

The evidence is generated by `python3 validate.py`; JSON receipts contain exact
rational values, not only rounded summaries. Tests are executable diagnostics,
not formal mathematical verification or a substitute for peer review.

## Request defects, before and after

`V12_CONTRACT_FAULTS_REPRODUCED.json` records the unchanged, blob-verified v12
baseline: four nominal controls, four accepted false precision brackets, and two
accepted truncated horizons. Original modules are hash-checked before and after.
In a full repository run, `V12_ORIGINAL_REFEREE_RERUN.json` records a separate
execution of the original referee's unchanged script.

The v13 suite retains the exact known radius `1/(8M)` for the interval fixture.
Both adaptive call sites reject coarse bits, misleading precision metadata,
rescaled misleading metadata, wrong query values/counts, and nonvacuous collapsed
transitions. Both reject shorter and padded horizons, false state counts and
multi-query permutations. External schema, error-budget and input-name controls
are included. The checker accepts a construction-equivalent internal change
when the final table is genuinely correct; it does not claim to detect changes
to unused internal audit data.

The ported v12 suite has 26,158 assertions, with the original source retained.
V10 and v11 author suites retain 7,904 and 8,207 assertions. V13 adds 12,944
assertions, including the new physical and lower-identity diagnostics. The
combined count is 55,213; historical mutation-reproduction assertions and the
original referee script are additional, separately reported controls.

## One numerical name, one physical program per budget

The common formal moment table has accuracy `delta=1/67108864` and remains fixed
at every scale. The finite positive detector has exponent set `{0,1,2+gap}`.
Two models have `gap=0` and opposite small prior tilts, and two have uniform priors
and gaps `+/-delta/4`. Entry discrepancies and exact physical evaluations are
recorded for all four. The stated family lies in the envelope between one half
and three halves of the uniform reference measure.

Acquisition has two fixed commands, four reports, N=3 and T=2. At each budget
M=1,2,4 a single robust compilation is performed; its identical program is run
on all four models. All 64 full histories and all checkpoint query labels are
executed in each case (768 complete paths in total). The physical future probes
are explicitly implemented by rejection coordinates in the admitted eta=1/8
cube. A coefficient/positivity calculation gives a valid raw update bound; the
common advice floor is fixed analytically before reading the returned program.

The common raw quotient bound gives floor
`rho=1451520/1943011333`, approximately `0.00074705`. An independent exact
finite-set covering oracle checks every bracket for every model. The final
mesh exponents are 8, 9 and 10 for M=1,2,4; all these runs stop by the radius
condition. Their final brackets are respectively `[25/512,29/256]`,
`[93/4096,109/2048]`, and `[69/8192,85/4096]`. The maximum actual query errors
across models are approximately `0.00359829`, `0.00171923`, and `0.00067922`.
The JSON includes exact errors and all previous scales.

This finite N=3 experiment crosses an additive equality but does not test the
N=5 anisotropic resource phases or enumerate the full continuum command cube.
The independent exact cover oracle is exhaustive for the finite sets only.
The mathematical N=5 noisy-intersection conclusion has a separate complete proof.

## Reproducibility boundaries

No claim is made to exhaustively test every old referee suite or all program
mutations. Input-oracle accuracy remains external. Compilation uses only the
frozen numerical name, while all physical truth calculations stay offline.
The running `Machine` retains one index, unchanged from v12. Validation output
states its exact source commit and PDF hash; assertions are not an editorial
acceptance criterion.
