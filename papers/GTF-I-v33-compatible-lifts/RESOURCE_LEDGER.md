# Resource ledger — Revision 33

| Task | Persistent resource | Free structure and exact boundary |
|---|---|---|
| W_N, fixed length | Available hidden labels at every cut; peak max K_t | External epoch, fixed known tables, atomic stochastic rows; one query only at length N |
| V_N, vector state | Same count, with a vector and intertwining identity at each state | Subclass of W_N, not a model reduction for all hidden machines |
| Compatible lift | Ambient simplex coordinates plus stochastic map/decoder extendibility | Static facet size alone is insufficient; no global efficient search claim |
| A_N, anytime autonomous | One full state set, including any retained answer states | No external epoch or length-dependent decoder; correct at every terminating length 0..N; known tables and atomic rows remain free |
| Resonant polygon | q processing labels, exact rows; final answer needs 2 | Horizon-specific q and decoder; command matrices can be identical across epochs |
| Rational counter | 3(t+1) at cut t, 3(N+1) clocked peak | Rational rotation and exact rational tables; not a denominator-free fair-bit count |
| Autonomous counter | 3(N+1)+2 total states | Count plus triangle label in one state set, fixed decoder |
| Contractive comparison | Fixed q processing labels and up to 2 answer states | One device for all lengths for rho<1; does not retain the unit-rotation divergence hypothesis |

For irrational polygon rows, exact computable-real coefficients are part of the atomic-row mathematical model. No finite fair-bit exact sampler is asserted. The inherited rational sampler uses separately counted control and proposal-prefix states and a self-paced environment. Program size, row construction, arithmetic and lookup time are not priced by the width theorem.

The final query supplies one coordinate and is consumed atomically. The paper does not promise jointly independent answers to repeated queries from one installation. Exact terminal tags in the inherited composition theorem retain their own support-zero assumptions.
