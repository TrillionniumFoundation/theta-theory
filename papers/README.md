# Five-paper v8 periodic-Sinai series

1. `paper-I-liouville-ensembles` - compact finite-horizon geometry, Liouville current LDP, endogenous theta, Gibbs conditioning.
2. `paper-II-cell-homogenization` - ballistic and diffusive physical-time limits of actual cell displacement.
3. `paper-III-theta-generator` - exact canonical excess-pressure DPP and the physical theta-generator.
4. `paper-IV-control-information` - information structures, pure saddles, and optimizer-response calculus.
5. `paper-V-rigidity-tangent` - entropic rigidity, tangent laws, Girsanov, and BSDEs.

Each directory has one controlling `main.tex`, one `references.bib`, a README, a
referee guide, and normative `sections/part-*.tex` modules included by `main.tex`.
The single load-bearing platform for Papers I-III is `TL1-LIO-v1`.
