\section{Common roof versions and oriented physical interfaces}
\label{sec:v73-common-versions}
Throughout this part, $I=[9/20,47/100]$, $m\ge2$, $R\in I$,
$1\le n\le m$ and $k\in\Z^2$. The exact event is
$\Pi=\Pi_{n,k,m,R}$, the roof is $L=L_{m,R}$, and the source is
$\mu=\one_\Pi\nu_R^*$. Thus the factor
$c_*^{-1}$, where $c_*=91/(10000\pi)$, occurs once. The occupation
count uses times $0,\ldots,m-1$ and terminal membership uses time $m$.
All parameters introduced in a collision limsup are fixed before that
limsup unless an outer dependence is explicitly displayed.

\begin{lemma}[One finite kernel for the original source]
\label{lem:v73-common-kernel}
There is a Borel kernel $t\mapsto\mathsf D_t$ of finite positive
measures on the physical source space such that
\begin{equation}\label{eq:v73-source-kernel}
 \mu(A\cap L^{-1}(J))=\int_J\mathsf D_t(A)\,dt,
 \qquad \mathsf D_t(1)=p(t),
 \qquad \mathsf D_t(L=t)=p(t)
\end{equation}
for every Borel $A,J$, with the last two identities outside one
Lebesgue-null set. It may be taken to be zero where $p=0$.
For a chosen Borel physical weight $W$, define
$p_W(t)=\mathsf D_t(W)$. Every pointwise identity or order relation
between the chosen physical weights is then inherited by their
roof densities on this same kernel. In particular all the original
positive-source decompositions and all bounded mark dominations
hold simultaneously in this representation.
\end{lemma}
\begin{proof}
The collision space is standard Borel. Disintegrate $\mu$ over $L$
with respect to its marginal $p(t)\,dt$, whose absolute continuity
is Theorem~\ref{thm:v44-complete-density-bound}. If $Q_t$ is the
resulting probability kernel, put $\mathsf D_t=p(t)Q_t$ and set it
to zero on the remaining null set and on $\{p=0\}$. A countable
basis of roof intervals gives the fiber assertion in
\eqref{eq:v73-source-kernel}. Integration of an actual Borel weight
against this kernel is a version of its pushforward density.
Linearity and positivity prove the remaining assertions; in particular
$|p_{Ww}|\le M p_W$ whenever $W\ge0$ and $|w|\le M$.

The assertion is about a common kernel and specified Borel weights,
not a simultaneous choice of representatives for every equivalence
class of measurable functions. A source identity holding only
$\mu$-almost everywhere is first imposed on a common full-measure
set for the finite or countable collection of identities being used.
No union over an uncountable set of arbitrary source-null sets is
required.
\end{proof}

Apply this construction to the existing weights with densities
\begin{equation}\label{eq:v73-common-split}
 b=s+r,\qquad s=s_{71,1},\qquad
 r=d_{71,1}+b^{\varepsilon,\mathrm{inc}}+e_{70}.
\end{equation}
Here $e_{70}$ is the original first-clearance source outside the
selected disks. It does not include first incidence. Every term in
\eqref{eq:v73-common-split} has its original exact labels. For a
fixed $\delta>0$, the function $q=A_\delta b$ is continuous and
independent of the representative of $b$: it is a difference of two
values of the absolutely continuous indefinite integral of $b$.
Set $\alpha=\min\{1,(Kq-s)_+/r\}$ where $r>0$, and set
$\alpha=0$ elsewhere. This is a Borel function after modification
on the fixed exceptional set. If $W_s,W_r$ are the original weights,
the complementary replacements are exactly
\begin{equation}\label{eq:v73-common-allocation-weights}
 W_s+\alpha(L)W_r,\qquad (1-\alpha(L))W_r.
\end{equation}
The fiber assertion in Lemma~\ref{lem:v73-common-kernel} proves that
their densities are $s+\alpha r$ and $(1-\alpha)r$. Where $r=0$,
positivity gives $\mathsf D_t(W_r)=0$, so the convention for $\alpha$
has no effect. This verifies the allocation on the original space,
without transport, a new conditioning event, or a regularity claim
for $\alpha$.

If $X$ is the original path observable with values in a Polish path
space, use $X_\#\mathsf D_t$ and its weighted counterparts. A
countable bounded-Lipschitz norming class fixes the common exceptional
set for the path inequalities. For different radii the exceptional
sets may be different. Every norm below has the order
$\sup_R\operatorname*{ess\,sup}_t$, not an essential supremum after
an uncountable union of null sets.

\begin{proposition}[The interface ledger]
\label{prop:v73-interface-ledger}
On regular physical patches, combine coarea fluxes before taking
Jordan parts. An artificial interface cancels when the physical
roof and source agree on its two sides. An actual source jump,
physical itinerary boundary or exact-label boundary is retained.
The compactly supported window $f\one_{(a,b)}$, with $f\in BV(a,b)$
and finite one-sided traces, contributes both atoms
$f(a+)\delta_a-f(b-)\delta_b$ in addition to its interior derivative.
\end{proposition}
\begin{proof}
In common coordinates let an interface normal $n$ point from
$\Omega_-$ to $\Omega_+$. Write $F_\pm$ for the roofs and
$V_\pm=\nabla F_\pm/|\nabla F_\pm|^2$. The boundary contributions
of Proposition~\ref{prop:v72-coarea-flux} are
\[
 -(F_-)_\#(w_-V_-\cdot n\,d\mathcal H^1)
 +(F_+)_\#(w_+V_+\cdot n\,d\mathcal H^1).
\]
When both patches describe one smooth physical source, their traces
coincide and these measures cancel. With a common roof but a true
jump, the surviving flux is the pushforward of
$(w_+V_+-w_-V_-)\cdot n\,d\mathcal H^1$. When the roofs do not
coincide they are not identified. A boundary with no patch in the
same exact event retains its one-sided contribution. This covers
physical-word and exact-label boundaries, not only chart cuts.

One-dimensional BV integration by parts gives
\[
 D(f\one_{(a,b)})=(Df)|_{(a,b)}+f(a+)\delta_a-f(b-)\delta_b.
\]
Adjacent pieces therefore cancel artificial traces and count a true
jump once. The derivative has total mass zero when the function is
compactly supported. At critical or singular sets the full current
is the distributional limit specified in
Proposition~\ref{prop:v72-coarea-flux}. Cancellation is asserted
only for matching artificial interfaces. Neither that exhaustion nor
the existence of a finite full current below asserts convergence
of arbitrary patch currents in total variation.
\end{proof}
