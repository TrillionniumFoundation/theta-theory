# Resource ledger — v42

| Item | Convention |
|---|---|
| Main resource | Maximum available persistent label cardinality, including a held binary output with two labels |
| Epoch and horizon | Declared external clock and known N; redesign per N allowed |
| Queries | One selected terminal coordinate or declared frame row; no joint-output requirement |
| Randomness | Fresh atomic real stochastic rows; no free retained random tape or seed |
| Description | Row tables, construction, lookup and real arithmetic are not label storage |
| Common-row upper tables | At most alphabet-size times K command rows, plus initialization/decoder rows |
| General clocked tables | At most alphabet-size times sum of layer widths command rows |
| Packet length | Every one of r(L-1) binary/finite letters is processed and charged; packet identity is not supplied |
| Conditional centroids | Proof-side conditional means, not runtime vectors |
| Upper vectors | Read-only descriptions of labels; the machine stores their indices only |
| Components | Coset and irreducible branch identities are included in disjoint labels |
| Real/algebraic data | Explicit dual-BA angles are algebraic, but their trigonometric matrices are only asserted computable-real |
| Fair-bit compilation | A different resource with additional state/precision assumptions; no optimal-width identification |
| Spectral gap | Infinite-dimensional qualitative/certified hypothesis; finite truncation alone is not a proof |
| Calibration | Finite polynomial problem given certified isotypic algebraic data; exponential sign constraints are explicit |
| SDP | Certified upper relaxation; exact only when a suitable rank-d optimizer is available |
| Query frames | Reconstruction norm prices all independent coordinate errors; duplicate queries do not improve it |
| Finite groups | Orbit tracking supplies a constant upper bound, not an exact general minimum |
| External expansion | Rational two-letter SO(3) example uses a qualitative Benoist–de Saxce input for a symmetric auxiliary average |

The nongapped hierarchy fixes r, angles, signal and tolerance before N grows. Its error range is epsilon < rho/(2 sqrt(2)), rho<=1/10. It does not assert a uniform vanishing-signal or high-dimensional theorem. Label bits are the logarithm of the label count, not the count itself.
