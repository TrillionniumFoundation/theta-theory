\begin{abstract}
We study the actual uniform probability error of finite numerical
experiments realized by two-state stochastic registers. The inherited
antisymmetric scalar normal form is completed by a sign-and-magnitude
alternative valid at every error threshold, including zeros. After a
canonical support reduction, feasibility is a finite disjunction of
logarithmic linear systems. Every infeasible chamber has an integer
multiplicative certificate supported on at most one more inequality
than the number of essential factor coordinates. These certificates
are converted into a finite univariate algebraic description of the
optimal error and into legal stochastic witnesses. A one-epoch,
two-command rational response table has an explicitly determined
cubic optimal error: algebraic rows attain it, but no rational rows
do. A second exact example uses distinct rational orthogonal commands
at arbitrary horizon. We retain the complete earlier compatibility,
Gram, arithmetic and implementation results, and make candidate
verification, global certification and encoding complexity distinct.
The primary resource is nonuniform clocked atomic-row label width;
no uncharged mixing selector or uniform-space interpretation is used.
\end{abstract}
