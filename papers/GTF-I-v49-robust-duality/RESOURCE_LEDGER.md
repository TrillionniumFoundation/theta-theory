# Resource and input contract

The primary resource is available labels K_t at each command boundary plus a held two-label output. Zero-mass padding counts. Fresh stochastic draws are private; an enduring seed, branch or mixture selector must fit the retained label. Epoch, horizon, arbitrary known exact real row tables, their construction/lookup and real arithmetic are free in the atomic model. One selected terminal query is answered, not a joint query channel. The machine may be redesigned for each horizon.

New complete duality: K_0=...=K_N=2, antisymmetric finite binary target, explicit positive-seed table. Mean tolerance delta is twice binary-TV tolerance. Modes are seed, each command epoch and query. Intermediate widths may be larger only in separately stated bottleneck corollaries. No convex mixture of machines is uncharged.

Candidate Gram validation: displayed rational arrays, unary N, binary coefficient encodings. The named rational-height lemma prices intermediate arithmetic. Existence of an unknown candidate, moment minima and a global width frontier have different complexity.

Threshold oracle: exact rational input and arithmetic, finitely many signs and inequalities. Default factor-sign limit20, generated-row limit50000 and exact product exponent budget1000000. Limits return undetermined, not infeasible. An algebraic primal is represented by signs and rational powers of rational bases. The full algebraic-optimization theorem is analytic, not an implemented general symbolic optimizer.

Neither the NP-complete variable-table corollary nor the cubic arbitrary-table example is a fixed-dimensional orthogonal hardness theorem. Algebraic stochastic rows are not finite-fair-bit implementations. The retained finite-bit compiler has its own workspace, precision and input promises.
