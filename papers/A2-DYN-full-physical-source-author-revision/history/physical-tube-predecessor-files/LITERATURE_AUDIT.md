## The precise unrestricted pressure bridge still requiring reconstruction

Historical 239 compares the actual physical-word sum to the corresponding homogeneous partition sum. Historical 241 attempts the passage from that partition object to curve growth. The remaining global issue can be stated as a single sufficient bridge: uniformly for every radius and collision count, dominate the complete homogeneous partition weight by a bounded number of sums over actual admissible inverse components of specified stable test curves, with one uniform multiplicity and distortion factor. Together with the already matched curve-growth estimate this would give the desired \(Q_*\).

For the retained route, the proof must supply a uniform positive weighted fraction on long backward cells, actual test curves meeting those cells, and bounded multiplicity of the final physical singularity cuts and assignments. A curve-growth estimate alone does not establish that whole-partition domination. Nor does the new fixed-margin atlas establish it for the guard complement. This is an author-side inference about the logical interface, not an additional theorem attributed to either external paper.

The corrected distinction matters in both directions: the two optical factors are now proved and should no longer be left as unfilled inputs; the unrestricted whole-cylinder partition bound should not be silently marked complete because the guarded pressure theorem holds.
