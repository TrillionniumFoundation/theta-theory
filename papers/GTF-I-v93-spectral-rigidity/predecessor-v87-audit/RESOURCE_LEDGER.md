# Resource ledger — v87

The device remains ordered, memoryless, input-consuming and classical-output. All operational distances use unhalved final trace norm. Prior resource ledgers are preserved under predecessor-v86-audit and earlier archives.

| Resource | Current theorem contract |
|---|---|
| N | Hard maximum number of unknown-device calls on every record, not merely expectation |
| b | Maximum calls inside an initially entangled complete probe–reference block, 1<=b<=N |
| Between blocks | Independent states, or public mixtures with retained classical record; no shared quantum correlation or input feedback |
| Within blocks | Arbitrary entangled inputs and references; final output/reference processing unrestricted |
| Parallel endpoint | b=N includes every entangled parallel input, not only independent Choi acquisitions |
| Adaptive comparison | Existing theorem permits full quantum memory and bounded public stopping; only local orders are equated |
| Coherent lower | Known E,H,s,N,b; local reference at most 2d per call; GHZ block inputs, final tensor recovery and binary event |
| Unknown remainder | No preparation, recovery or lower event depends on F-E-sH within the allowed tube |
| Quantum controls | Ideal existence; inherited conditional implementation-error results remain separate; no general circuit synthesized |
| Classical certificate | Polynomial exact represented-input cone, support, sufficient nonemptiness and optional pair checks |
| Nonempty interval | Legality and explicit finite-remainder control only, not the discrimination interval |
| Description payload | Retained target-independent public dictionary index; dictionary reconstruction can be exhaustive |
| Learning | Balanced interior and fixed k; the k^3 upper is not a growing-k optimal law |
| Execution | Exact finite arithmetic and small entangled-input probability laws only; no physical protocol |

Classical-feedback inputs and separable probe marginals with arbitrary shared quantum references are not identified with independent complete blocks. The new theorem does not classify every intermediate resource model. Controlled powers require O(t^(2q)); global arbitrary-pair geometry and general higher-order approaches remain separate.
