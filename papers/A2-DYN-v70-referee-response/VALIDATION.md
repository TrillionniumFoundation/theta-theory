# Revision 70 validation boundary

The v70 workflow checks its actual checkout SHA, the complete frozen v69 paper tree and controlling review blob. The verifier checks byte preservation of all 151 inherited core modules, 203 Python sources, nine appendices and references.tex; exact archived opening text; every old input and label; all 154 active core inputs; and the complete inherited boolean status map.

Finite diagnostics run both normally and with Python optimization. They cover zero angular capacity, full/no/partial overlap, high-ratio monotone profiles, later births, losses invisible to ordinary derivatives, projected signed cancellation, single attribution of coincident interfaces, density distortion, complementary source weights and the legal B-dependent parameter choice. They include negative controls against pretending that a narrow spike has no loss or that a partition of weights is a disjoint event partition.

Native TeX runs without shell escape until references stabilize. The build rejects undefined or duplicate labels, LaTeX/package warnings, overfull boxes and missing characters. The render script resolves actual proof-page numbers from the final auxiliary file and rasterizes every new proof page. The artifact contains the PDF, logs, exact source archive, SHA-bound verification JSON and rendered pages.

A successful run is evidence for source preservation, finite diagnostics and typesetting only. It is not a proof of the continuum collar theorem, a uniform radial/current tail, complete outside or first-incidence height, or independent human review. This file is a protocol, not a pre-asserted successful workflow receipt. A local extracted-source check is explicitly marked local and cannot establish a remote checkout SHA.
