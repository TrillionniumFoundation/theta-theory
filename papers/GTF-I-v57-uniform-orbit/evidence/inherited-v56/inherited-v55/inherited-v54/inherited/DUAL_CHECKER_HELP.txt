usage: dual_certificate.py [-h] (--delta DELTA | --bisect BISECT)
                           [--max-rows MAX_ROWS]
                           [--max-sign-variables MAX_SIGN_VARIABLES]
                           input

Exact threshold certificates for bounded rank-one word tensors. All decisions
use rational products, never numerical logarithms or LP tolerances. The
general algorithm can be exponential. Resource limits raise ResourceLimit;
they NEVER turn an unfinished search into an infeasibility conclusion. Input:
a complete positive-seed mean tensor (the negative seeds are its negative).
Run `python dual_certificate.py --help` for the JSON interface.

positional arguments:
  input                 JSON with dims and lexicographic values (rational
                        strings)

options:
  -h, --help            show this help message and exit
  --delta DELTA         Mean-error tolerance as a rational string (twice
                        binary TV)
  --bisect BISECT       Number of certified rational bisection steps
  --max-rows MAX_ROWS   Maximum Fourier-Motzkin rows (default 50000);
                        exhaustion returns undetermined
  --max-sign-variables MAX_SIGN_VARIABLES
                        Maximum essential factor-sign variables (default 20);
                        exhaustion returns undetermined
