# Resource ledger — Revision 34

| Resource | Convention and theorem use |
|---|---|
| Initial seed | One of four external atomic inputs; any retained distinction must enter K_0. |
| Commands | N external binary symbols. Uniform independent bits are a converse test distribution, not a restriction of the wordwise specification. |
| Register | Available labels K_t at each declared cut; all persistent randomization is included. |
| Clock | Epoch is external for W; updates may depend on t and N. |
| Final query | One coordinate supplied atomically after the prescribed length; output decoded in that update. |
| Answer retention | Two labels when explicitly held after emission. Exact peaks here are already at least three. |
| Exact rows | Known atomic stochastic kernels; table construction, read-only description and arithmetic are not counted as register labels. |
| Conditional phase | z_t is a proof-side conditional expectation; not a free runtime posterior or a statewise future vector. |
| Hidden lifts | Arbitrary hidden state continuations are allowed; no bound on projected vertices is used by the new lower proof. |
| Approximation | Uniform row-TV error epsilon over all complete words and both final queries. Polynomial lower bound when epsilon<1/20. |
| Diagram defect | Sum of common-row finite deficiencies and terminal deficiency; an executable error upper certificate, not necessarily the exact final error. |
| Fixed-length autonomy | Common T_0,T_1 and d, correctness only at N; horizon-specific machine allowed. |
| Anytime autonomy | Same decoder correct at every length 0..N; a stronger task. |
| Rational sampling | Fair-bit rejection implementation has separate phase/current input/old state/prefix workspace as retained from v31. |
| Real resonance | Irrational exact rows are mathematical kernels; no finite exact fair-bit compiler is claimed. |
| Historical program | Independent analytic gates unchanged; no A2/B4/C2 or eleven-paper closure follows from a finite-register theorem. |
