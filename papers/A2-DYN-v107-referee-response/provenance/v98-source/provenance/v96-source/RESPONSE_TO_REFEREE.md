## 1. The two-nongrazing packet — report §§7,10.1,14.1

Module 229 distinguishes an exact-event segment from its underlying regular physical word. Section decisions may end the former without ending the latter. We construct a separate comparison flow on a fixed nongrazing endpoint collar, stopping at actual physical or collar boundaries and at a backward critical end. The original stopped flow, original segment endpoints and original minimum packet are unchanged.

The occupation anchoring theorem bounds an admitted target source by the original same-label source over a prescribed roof interval. An admitted physical continuation must have inverse coarea Jacobian at most D and spend at least fraction beta of that interval back in the same selected event. The anchor indicator includes the exact n and k, both endpoint section tests and any original selector. It never accepts neighboring occupation labels. Arbitrarily many returns are allowed without a return-count factor, because the flow map is injective at each fixed sampled roof.

Module 230 applies this to the actual positive minimum of the two traces on each short original segment. For targets returning to the selected short-segment event, the common two-nongrazing packet has essential height at most

`C (D/beta) delta^(1/32) + C (1+epsilon^(-1)) delta`

at every fixed positive entrance gradient. This is decay of the packet itself on the full admitted family, not just its difference from the current target source. With returns only to the ordinary exact event, a second theorem gives

`C (D/beta) [epsilon^(1/16)+epsilon^(-1)sqrt(r)] + C(1+epsilon^(-1))delta`.

The latter is compatible directly with the original reconstruction limit. It includes targets on arbitrarily short section-cut segments which return to longer components of the same exact event.

The two-nongrazing packet failing continuation, compression or occupation tests is not declared small. Thus the full request is advanced but not marked closed.

## 2. The disappearing radial tail — report §§8.4,10.2,14.2

For the admitted original union `z<a or ell<delta`, the finite-count occupation inequality is combined directly with the complete critical-volume and backward-end source estimates. The resulting essential-height bound is

`C (D/beta) [a^(129/128)+delta^(1/32)]`.

The entire source below the upper gradient cutoff is present at finite count. There is no lower gradient cutoff and no summation of already-taken annular limsups. The finite-count formula explicitly retains the fixed-band floor divided by the previously fixed sampling radius and both spectral remainders; the auxiliary band is enlarged only after the collision limit.

For the inner critical core `z<a/2`, when `r<=a^2/(8 Lambda)`, every available comparison interval stays below `z<a`. Ordinary same-label occupation is then already occupation of the critical selector. The full admitted inner core has height `C(D/beta)a^(129/128)`, including annuli that disappear with collision count. No separate radial-return assumption is imposed in this corollary.

This is an all-gradient theorem for the admitted physical class, not a proof that the full critical source is admitted. The remaining failure source is retained.

## 3. Joint forcing localization — report §§10.3,14.3

Module 231 makes an exact, disjoint partition of the original bad source. A target fails either because neither comparison direction lasts r, because no available direction has the bounded inverse-Jacobian ratio, or because no such direction returns to the same exact event for fraction beta. Each failed target is charged once with its original W and original coarea measure.

The admitted source is bounded pointwise by an explicit interval integral of `b^epsilon + kappa_epsilon(r) p`, with `kappa<=C epsilon^(-1)sqrt(r)`. Since the retained post-projection joint forcing is bounded by the original source, this gives a complete forcing localization into the estimated continuation class and the three exact failed-test sources. No minimum or positive part is moved through projection. The same construction applies to the original critical-or-short-residence union without double counting its intersection.

The conclusion is not that these failed sources vanish. It identifies what must now be proved about actual physical interruption, coarea compression or sparse same-label occupation. In particular a pulse with insufficient occupation is not hidden by the new comparison.

## 4. Parameter schedule — report §14.4

A simple common schedule is `D=2`, `beta=1/4`, `r(B)=c epsilon(B)^4`, with the original `epsilon(B)=A_0 B^(-1/12)`. The admitted full-source contribution is `O(epsilon^(1/16)+epsilon)`. The cofinal union `a=r^(1/8)`, `delta=r^(1/4)` has admitted height `O(r^(1/128))`. The short-packet comparison additionally requires `epsilon^(-1)delta -> 0`; for that application choose its independent residence threshold `delta_packet=epsilon^2`, with each fixed positive entrance gradient retained first.

More generally `D/beta<=C epsilon^(-tau)`, `tau<1/16`, and `r=c epsilon^N`, `N>2(1+tau)`, pay the two explicit full-source errors. All choices are fixed before the collision limsup; no Fourier band depends on collision count. The remaining failure-source height has not been bounded by a vanishing rate.

## 5. Exact event, reentry and physical source

The auxiliary flow never crosses a true grazing, first-hit, competing-hit or collar end. It may cross section-decision walls, but the source is sampled only after retesting the identical original exact event. It is not a replacement billiard model, a different return map, or a pooled label. If a sampled state has the wrong n or fails either endpoint test, it contributes zero.

Reentry is used only in this explicitly defined comparison construction. It is not inserted retrospectively into the prior first-exit assignment or ancestral budgets. At a fixed sampled roof the regular physical map has multiplicity one, even if its orbit has crossed many decision walls. The inverse physical Jacobian is kept in D and the original nonmonotone smooth guard is retained through its original Lipschitz modulus.

## 6. Scalar and downstream claims — report §14.5

The full original pointwise theorem is not proved in this revision. Along the stated legal schedule, it is equivalent to zero height of the three failed-test sources, because their sum is a subsource of the original b. Neither that condition nor uniform admission of all possible spike targets is established. All original pointwise, essential-likelihood and unrestricted downstream flags remain unchanged. No arithmetic zero class is normalized.
