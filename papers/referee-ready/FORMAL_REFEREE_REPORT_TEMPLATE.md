## 1. Executive recommendation

Choose one and explain:

- accept in present form;
- minor revision;
- major revision;
- reject because of a correctness defect;
- reject because the result is not sufficiently novel or significant for the
  proposed venue;
- unable to assess without an additional specialist report.

## 2. Principal theorem audit

For every principal theorem, record:

| Theorem | Statement correctly typed? | Hypotheses sufficient? | Proof complete? | Actual example verified? |
|---|---|---|---|---|
| | | | | |

Please distinguish a missing proof from a false statement and from a statement
that is correct only after narrowing its scope.

## 3. Dependency audit

- Are all imported companion results stated precisely enough to be checked?
- Is any later paper or stochastic representation used circularly upstream?
- Are any compactness, comparison, selection, integrability, aggregation, or
  common-domain hypotheses hidden?
- Are all sums, limits, derivatives, and optimization operations exchanged
  legally?

## 4. Actual-model audit

For each claimed actual system:

- verify every field of the theorem packet directly;
- identify any step that remains conditional on a model-specific estimate;
- check nondegeneracy, nonconjugacy, ellipticity, observation positivity,
  control compactness/coercivity, and path dependence as applicable;
- check that a source-specific result is not advertised as a generic theorem.

## 6. Exposition and organization

- Is the one-sentence central theorem visible from the introduction?
- Can the manuscript be read without internal repository documents?
- Are notation, conventions, and dependencies stable?
- Which proofs should be moved, expanded, shortened, or split into appendices?

## 9. Verification boundary

This report should state explicitly whether it is:

- a full correctness review;
- a partial specialist review;
- a novelty/significance review only;
- an expository review only.

No positive recommendation should be read as verification of areas outside the
referee's stated expertise.
