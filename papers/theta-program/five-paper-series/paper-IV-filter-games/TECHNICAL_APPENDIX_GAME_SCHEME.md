# Technical appendix: actual sequential and simultaneous four-branch game schemes

This appendix supplies complete monotone schemes, consistency, comparison, and
convergence for the bounded four-branch hidden-symbol game.  Together with the
one-step filter collapse in Paper IV, it gives an actual scoped K3 realization.

## B.1 Controlled branch data

Let `U,V` be compact.  For branches `i=1,...,4`, assume continuous data

\[
p_i(x,u,v)\ge p_*>0,
\qquad \sum_i p_i=1,
\]

\[
\sum_i p_i(x,u,v)c_i(x,u,v)=0,
\tag{B.1}
\]

and bounded branch drifts `b_i`, running reward `ell`, and increments `c_i`.
Define

\[
\bar b(x,u,v)=\sum_i p_i b_i,
\]

\[
A(x,u,v)=\frac12\sum_i p_i c_ic_i^T.
\tag{B.2}
\]

Assume a common Lipschitz modulus and uniform ellipticity.  The hidden-symbol
prediction matrix has identical rows `p(x,u,v)`, so it forgets every prior in
one fast step.  That step has slow duration `h` and hence satisfies the
vanishing-initial-layer condition.

## B.2 Sequential schemes

For a bounded test function `phi`, define

\[
\begin{aligned}
(\mathsf S_h^-\phi)(x)
=\sup_{u\in U}\inf_{v\in V}\Big\{&h\ell(x,u,v)\\
&+\sum_i p_i(x,u,v)
\phi(x+\sqrt h c_i+h b_i)\Big\},
\end{aligned}
\tag{B.3}
\]

and

\[
\begin{aligned}
(\mathsf S_h^+\phi)(x)
=\inf_{v\in V}\sup_{u\in U}\Big\{&h\ell(x,u,v)\\
&+\sum_i p_i(x,u,v)
\phi(x+\sqrt h c_i+h b_i)\Big\}.
\end{aligned}
\tag{B.4}
\]

Both are monotone, constant preserving, and sup-norm nonexpansive.

For `phi in C_b^3`, Taylor expansion and (B.1) give

\[
\frac{\mathsf S_h^-\phi-\phi}{h}
\to
H^-(x,D\phi,D^2\phi),
\tag{B.5}
\]

\[
\frac{\mathsf S_h^+\phi-\phi}{h}
\to
H^+(x,D\phi,D^2\phi),
\tag{B.6}
\]

where

\[
H^-=\sup_u\inf_v
\{\ell+\bar b\cdot p+A:X\},
\tag{B.7}
\]

\[
H^+=\inf_v\sup_u
\{\ell+\bar b\cdot p+A:X\}.
\tag{B.8}
\]

### Theorem B.1

Backward recursions generated by (B.3) and (B.4) converge locally uniformly to
the unique bounded uniformly continuous viscosity solutions of the lower and
upper equations.

#### Proof

Monotonicity and stability are immediate.  Consistency is (B.5)--(B.6).
Comparison follows by the same doubled-variable argument as Paper III's
technical appendix, now using a common nearly optimizing pair `(u,v)` in the
appropriate order.  Half-relaxed limits give convergence.

No Isaacs equality is used.

## B.3 Simultaneous relaxed scheme

Let `mu in P(U)` and `nu in P(V)`.  Extend all coefficients by product
integration and define

\[
\begin{aligned}
(\mathsf S_h^{\rm mix}\phi)(x)
=\sup_{\mu}\inf_{\nu}\Big\{&h\bar\ell(x,\mu,\nu)\\
&+\sum_i\bar p_i(x,\mu,\nu)
\phi(x+\sqrt h\,\bar c_i^{\mu,\nu}
+h\bar b_i^{\mu,\nu})\Big\}.
\end{aligned}
\tag{B.9}
\]

Equivalently, one may integrate the entire branch transition kernel rather than
averaging branch increments separately; this is the canonical relaxed
formulation.  Its consistency Hamiltonian is

\[
H^{\rm mix}(x,p,X)
=
\sup_{\mu}\inf_{\nu}
\int_{U\times V}
\{\ell+\bar b\cdot p+A:X\}
\,d\mu d\nu.
\tag{B.10}
\]

The integrand is affine in each relaxed control.  Compact minimax gives

\[
\sup_\mu\inf_\nu=\inf_\nu\sup_\mu.
\tag{B.11}
\]

### Theorem B.2

The simultaneous relaxed recursion converges to the unique mixed-Isaacs
viscosity solution with Hamiltonian (B.10).

#### Proof

The scheme is monotone and stable because it is a sup--inf of probability
averages.  Taylor consistency follows before or after product integration.
Comparison uses the common Hamiltonian in (B.11).  Half-relaxed limits complete
the proof.

### Pure-strategy boundary

Theorem B.2 does not produce a pure saddle.  If a measurable pair `(u_*,v_*)`
satisfies

\[
F(u,v_*)\le F(u_*,v_*)\le F(u_*,v)
\]

for every `u,v`, the relaxed value is attained by Dirac controls and the pure
scheme has the same limit.  Without this extra certificate, only the mixed
value is claimed.

## B.4 Filtering in the game recursion

Because the hidden prediction matrix has identical rows, the predicted belief
is `p(x,u,v)` independently of the prior.  The observation update therefore
also loses the prior after one fast prediction.  The running reward accrued
before that prediction is `O(h)` and vanishes.  Hence all schemes above are
uniform over initial beliefs and strategy trees.

If the belief is retained as a macroscopic state instead, the same branch
kernel defines a finite-dimensional simplex-valued Markov chain; its monotone
scheme gives the belief-state HJB.  Genuine additional history remains in the
path-state/PPDE branch.

## B.5 Actual scoped conclusion

The four-branch hidden-symbol construction now supplies, without an unnamed
DPP or comparison assumption:

1. exact filter and initial-layer collapse;
2. lower and upper sequential limits;
3. a simultaneous mixed-Isaacs limit;
4. a pure limit under the explicit saddle gate;
5. time-consistent game evaluations.

The weighted noncompact theorem in the main manuscript remains a separate
packet theorem and is not inferred from this bounded model.
