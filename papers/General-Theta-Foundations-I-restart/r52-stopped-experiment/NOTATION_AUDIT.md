# Notation audit

- theta: fixed unknown experimental model, never an input read by a program.
- H: compact prediction range; mathcal H: visible history with prior coins. These are different.
- X or rho: physical state, not the observer label.
- Z: protected audited target after commitment. m_{t,a} is its conditional mean; m alone is terminal dictionary size.
- B0: one common irreducible conditional-variance baseline. The new realizations use B0=0.
- f: observable task proxy, not the predictive quotient. w: residual squared-risk mark; sqrt(w): its geometric scale.
- nu_a: actual prepared reference report law. h_a nu_a: profile-selected terminal submeasure, not automatically a correlated execution law.
- x_a: profile count; actual count before rescaling is separately named in the proof.
- N: expected raw acquisition budget in the core. n: core budget in the three-extra-call extension. M: total persistent live+terminal labels; m: output values.
- d: actual location-mass exponent. alpha: low-uncertainty mass exponent. Neither is ambient physical dimension.
- q: positive hidden-transition or channel floor. mu: Gaussian separation. kappa=(1-2q)/(2q) only for the known symmetric two-state curve.
- beta: actual revealing branch mass; r=1-beta N when positive. Do not confuse it with calibration delta or deficiency epsilon.
- Q_mu: explicit Gaussian marked tail profile, not an exact all-history risk. Xi: general marked allocation profile.
- TV: common bounded-law comparison. It does not control expected time without an additional resource certificate.

The source checker validates active input closure, unique labels, all cross-references, matching bibliography/citations and balanced theorem/proof environments. It does not validate these semantic distinctions automatically.
