# Literature comparison: consulted mechanisms, not a priority certificate

| Precedent | Relation and difference |
|---|---|
| Graf–Luschgy, quantization | Classical checkpoint geometry and small-ball bounds; new claim concerns their connection to a constructed recursive machine under actual acquisition |
| Shalizi–Crutchfield; Littman–Sutton–Singh; Fritz | Predictive representations and sufficiency are established; quotient proposition is a typed version certificate, not a novelty claim |
| Diaconis–Freedman, iterated random functions | Average contraction is established; the current sufficient theorem needs a square-moment inequality plus true-law candidate envelope and finite inward cover |
| Pages–Pham; Sellami; Feuer–Goodwin | Recursive/filter quantization is prior art, not invented here; compare the retained alphabet and actual lower, not only an upper discretization error |
| McDonald–Yuksel, arXiv:1910.08463v2 | Dobrushin filter stability under the physical law; the new theorem converts its own raw contraction/envelope verification into a finite-label upper and actual-law lower |
| Kara–Yuksel, JMLR 23(11), 2022, Theorems 12/16/17 | Finite-window belief approximation and near-optimal POMDP control; this paper is NOT a stronger optimal-control theorem. Its different claim is the hard label/output cut and matched actual prediction geometry |
| Saldi–Yuksel–Linder, consulted arXiv:1710.07009 | Finite belief-model approximation in discounted control; not equivalent to the fixed-exploration predictive-label problem |
| Charalambous–Stavrou–Ahmed, IEEE TAC 59(4), 2014 | Nonanticipative information rate constraints are not the same as a hard persistent alphabet; no conversion without a coding theorem |
| Zhu, consulted Moran preprint | Singular quantization and multiscale cylinder geometry are established; the new extension keeps the finite atomic acquired law and transports old error through time-varying nonreset mode changes |
| Blackwell; Le Cam; Torgersen | Classical comparison/deficiency underlies bounded common-loss transfer; simulator state/action/clock accounts must additionally be specified |

Primary publisher/arXiv sources were consulted, including the JMLR theorem text. Some cited preprints are explicitly the versions consulted; this does not assert that no later journal version exists. The supplement's broader bibliography remains available. An exhaustive modern literature search or independent originality certification is not claimed.
