# Resource accounting

| Resource | Definition / constructive bound | Proved converse |
|---|---|---|
| Raw acquisition N | Filter T+2; singular B+T+2; include failures and holds; serial subroutine calls add | Actual acquisition variance A in the SAME task; no optimized adaptive schedule theorem |
| Prediction labels M | Main finite cover; filter (2K-1)^d; singular 2^(m+2)-2 | Actual submass quantization or common-oracle lower |
| Label bits | ceil(log2 M), mode/length included in singular labels | Label cardinality lower, not total computational bits |
| Output precision b | Fixed dyadic forecast alphabet; filter indexed output vector in D_b^d | Matched 2^(-2b) for this output cut |
| Calibration delta | Terminal unobservable sign in common task; input/matrix calibration separately propagated | Exact sign-class lower delta^2; not every calibration allowance |
| Numerical/input error u | Certified envelope-preserving candidate enclosure, added before invariant radius | Constructive upper; no universal internal-arithmetic floor |
| Readout error v | Added in common L2 task norm before squaring | Fixed alphabet converse only when specified |
| Complete causal defect epsilon | Uniform parameter/declared-policy transcript+task TV | Bounded-loss upper L_* epsilon; lower requires explicit alternatives |
| Simulator R / controller D / clock Q | Serial tuple upper MRDQ | Only under executable post-cut tag separation, not for arbitrary private registers |
| Workspace W | Concurrent scratch accounts; compander tables/enclosures and finite prefix arithmetic | No general optimum or matching lower |
| Program length | Raw schedule, table constants, certified routines separately stored/charged | No general optimal-description lower |
| Physical time | Every actual subroutine and waiting opportunity counted | No general optimal runtime theorem |

Metric errors add in root mean square before squaring. Complete interactive TV defects add in bounded common loss after metric composition. Persistent cardinalities multiply for the specified serial construction; their bit counts add. The source and target Bayes baselines are not silently equated. Unknown parameters cannot be embedded into a free program or simulator state.
