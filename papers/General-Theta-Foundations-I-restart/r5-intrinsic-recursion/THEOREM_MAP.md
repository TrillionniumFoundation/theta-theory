# Theorem dependency map

Raw experiment + legal continuation interface -> `prop:quotient` -> predictive state and task.

Static inward cover + raw true-law pair moment + candidate envelope + legal seed -> `lem:recursion` -> **`thm:inward`**.

Conditional projection -> `lem:projection` -> exact checkpoint identity. Actual positive submeasure -> `prop:submass` -> matched acquired lower. These branches meet in the main theorem; neither realization is a premise.

`thm:inward` -> `cor:perturb` -> controlled input/calibration/arithmetic and readout upper.

`prop:oracle` -> actual acquisition plus ideal-law lower witness (actual law retained). `prop:output` -> output-alphabet cut. `lem:calibration` -> one explicitly specified common sign-minimax task.

Raw finite-state kernels -> `lem:filter-raw` (quotient, contraction, envelope); `lem:compander` (static finite cover); raw Jacobian -> actual submass -> **`thm:filter`**.

Raw finite-read kernels -> `lem:symbol-gains` (completed-domain metric and static cover), `lem:symbol-drift` (all-pair true-law gain), actual depth recursion + `prop:oracle` + `lem:calibration` -> **`thm:singular`** -> `cor:no-exponent`.

Report continuity + main recursion -> `prop:report`. Parameter-independent compatible causal morphisms -> `thm:morphism`. Executable post-cut challenge -> `prop:interface`, not conversely.

There is no dependency from either realization back to a foundations theorem. The preserved supplement has its own dependency graph; none of its unimported results is an unstated premise of the new main.
