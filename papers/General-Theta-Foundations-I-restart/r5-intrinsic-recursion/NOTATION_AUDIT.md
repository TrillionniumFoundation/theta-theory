# Notation audit

X_t denotes a hidden state only in the raw experiment definition; X later denotes a clearly introduced latent terminal score in the common-oracle argument. S_t is a derived predictive state, not an assumed parameter manifold. P_T is its task prediction; the filter also uses P_{t,i} for posterior coordinates and explicitly writes zeta_T for nominal task scores.

T counts recurrent opportunities; N_raw counts ALL paid calls. B counts initial paid bits in the singular experiment; B_T is a Bayes risk and b_delta the separately specified common oracle baseline. H_t is the singular acquired prefix depth; script-H_t is the observed filtration. H in the main theorem is the candidate envelope bound, not a hidden state.

M is prediction-label cardinality, K the total implementation state bound in the resource theorem; K in the explicitly local compander lemma is its positive-node count. Each reuse is local and declared. w is an envelope; w_T in the singular model is the actual mode-one probability. v=(1800,1) is the local singular metric weight, while v in the perturbation theorem is a readout-error allowance.

TV is sup_A |P(A)-Q(A)|. Squared task norms and root-mean-square metric errors are distinguished. The filter uses normalized Euclidean task norm and oscillation state metric. Delta is a sign-class amplitude where a lower is claimed, not a universal lower attached to all error certificates. All formal labels and citations are checked by verify.py.
