# Assumption matrix

| Ingredient | General theorem | Filter verification | Singular verification |
|---|---|---|---|
| Raw data / quotient | Standard-Borel kernels; declared report versions and legal interface | Positive finite-state Bayes formula; posterior separated by indexed probe | Mode and cylinder posterior; reported operations and terminal separating score |
| Actual acquisition | Fixed prepared path law and deterministic protocol | T paid reports, final mixing subevent has mass p | B paid bits plus T opportunities; explicit finite atomic law |
| Static cover | d(x,c) <= r_M w(x), w(c)<=w(x) | Exponential product compander, (2K-1)^d labels | All word lengths <=m and both modes, 2^(m+2)-2 labels |
| Raw pair moment | Integral under TRUE report law <= kappa d(x,z)^2 | kappa=1-p+p(1-s)^2 | v=(1800,1), kappa=17/20 including cross-mode candidates |
| Candidate envelope | True-law drift a w(z)^2+b | exp(eta oscillation), a=(1-p)exp(2eta B_a)<1 | w=1, a=0,b=1 |
| Seed | Legal finite-label seed, paid acquisitions | Known uniform prior represented exactly | Paid prefix reader retains min(B,m) bits |
| Geometric lower | Actual submeasure small balls, or exact common-oracle bridge | Actual last-mixing event has d-dimensional bounded density | Physical singular lower ONLY via oracle bridge; actual acquired law stays atomic |
| Continuity | State/report and terminal TV bounds for finite-path comparison | L_J=a/4, L_Y=1/4 | Coordinate-independent active reports within modes; finite cross-mode distance |
| Suspension | Deterministic independent active probabilities | All calls active; identity-gate observations NOT holds | Independent exact holds, every call charged |
| Resource limits | Fixed controller; separate registers and exact Borel/finite-bit distinction | M labels; fixed dyadic output; matrix/input arithmetic charged | Mode/length included; finite packets; schedule/clock charged |

Neither common invariant reference nor terminal occupation domination is assumed in the new theorem. The filter does not require a common invariant law for its matrices. The singular model allows zero initial or terminal mode masses. These differences do not make the new theorem a necessity criterion.
