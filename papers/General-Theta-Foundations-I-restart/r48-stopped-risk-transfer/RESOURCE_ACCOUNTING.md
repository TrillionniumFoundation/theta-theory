# Resource accounting

| Resource | Charged quantity | What is not free |
|---|---|---|
| Raw acquisitions | sup_theta E tau <= N; every attempted call counts | rejected/tail reports, early stops, retries |
| Persistent states | live l + terminal j <= M | control, stop flag, terminal codepoint label |
| Regularization | fresh k-bit coin for dyadic rho | generation/workspace/time, but no extra persistent label |
| Action/routing program | table bound in prop:description | dependence on precision, finite action/cell tables |
| Calibration/model family | known effective family and uniform certificates | true theta is never accessible |
| Temporary workspace | report selector plus coin/index/arithmetic scratch | no retained exact posterior or report tape |
| Numerical precision | q probability bits; decoder mesh; certified selector error | arbitrary Borel cell oracle |
| Offline synthesis | explicit finite enumeration bound | no polynomial/global-efficient claim |
| Physical time | all executed calls and selector/table operations | geometric stopping is not a hard deadline |
| Simulator | its internal states multiply observer states | raw-call conversion/cost certificate |
| Audit | protected terminal physical invocation | not silently included in core N unless explicitly stated |

The exact-budget theorem concerns the specified core acquisition count. In the retained joint error experiment, additional bit and audit calls are explicitly charged there. Appendix finite-description separates program size from log2(M); neither is the other's substitute.
