# Resource accounting

| Object | Persistent labels | Other charged resources | Error/caveat |
|---|---:|---|---|
| General stationary observer | m<=M, includes action/update/readout state | program, RNG implementation, phase if not visible, temporary arithmetic | N is evaluated physical calls, not a free internal stopping clock |
| Primal u / dual z | 0 runtime labels only because not runtime input | offline certificate storage and rational arithmetic | model dependence is proof-side only; not a simulator oracle |
| Counted recursive geometry | QJ<=M | cover program, calibration, workspace, global projection computations | full root error squared; baseline and actual law fixed |
| Raw controlled load/hold | M centers, one fixed action absorbed | 1 preparation +1 load +L scored services each cycle; codebook numeric storage | load report V cannot persist outside counted state |
| Diagnostic | 2 sign labels | one diagnostic call; quantum variant adds a preparation call | no internal horizon; audit never feedback |
| Joint profile | 2 floor(M/2)<=M | 4 physical calls/round, all audits counted | per-round risk /4 is per-call risk |
| Simulator lift | m*s | raw acquisitions, physical time, calibration and description separate | both endpoint bridge conditions on joint state; no fake reverse inequality |
| Approximate finite codebook J in R^q | ceil(log2 J) data bits | O(J q p) coefficient-description bits, O(qp+log J) workspace for streaming distance search, O(Jq) coordinate operations per load | p-bit arithmetic/rounding certificate required; these are upper costs, not optimality claims |

Persistent labels do not equal total bit complexity. Exact real codebooks in a mathematical risk theorem need a separate finite-precision certificate for a physical bit machine. Current readout norm error xi changes a q_J upper to (sqrt(q_J)+xi)^2. Calibration delta in the joint law is an actually invisible fixed sign and is distinct from the numerical per-update delta convention in the recursive theorem. Task normalizations and audit deadlines are stated before each comparison. The complete optimal multiresource computation region is not proved.
