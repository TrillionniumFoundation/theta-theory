## Checked dependencies and delicate steps

1. **Common projection.** The identity-word transition graph, lazy averaging matrix, stochastic idempotent and closed classes depend only on the fixed command matrices. They therefore serve every initial preparation simultaneously. Applying the same projection separately to each initial row preserves its own closed convex constraint set; no mixing between different preparation specifications occurs.
2. **Exact initializer count.** A prescribed pure label in a closed class projects to that class's stationary row and hence a point of the projected simplex. Distinct mixed projected preparations require distinct original labels outside all closed classes. Counting each distinct row once therefore gives `k+iota <= M`; conversely one transient initializer for each distinct mixed row implements the same decoder and the first actual command correctly.
3. **Invariant polytope formula.** The profile action convention is consistent: `q_x(hg)=q_{x.h}(g)`. The product-simplex polytope can extend outside the original response span. In the pure lower, nonvertex target profiles already present at core labels consume at most `k-v(P)` labels; other distinct targets consume distinct mixed rows. This is necessary to avoid double charging a nonvertex continuing label. The converse chooses vertex labels and one transient label for each prescribed nonvertex profile, with no inconsistent equality cases.
4. **Joint Fourier rank.** Under the manuscript's transform convention, left translate in the argument sends `A_rho(b_i)` to `A_rho(b_i) rho(h)`. Independent linear combinations from different preparations allow independent right matrix multipliers; their joint right module has multiplicity equal to the dimension of the union of column spaces, namely the rank of the horizontal concatenation. This rank can exceed `d_rho`; merely taking the largest separate rank would be wrong.
5. **Real/complex descent.** The inherited real-descent proof from section 42 was read: a complex injection `A+iB` has a nonzero maximal-minor polynomial in a real scalar parameter; some real scalar preserves injectivity. It applies to quaternionic and complex types and justifies using complex multiplicities to decide the real embedding.
6. **Common-mean positivity construction.** The shared average implies one invariant probability line and a nontrivial complement with zero total output mass. An equivariant embedding of that complement into a permutation module has zero coordinate sum. Its invariant orthogonal left inverse annihilates the uniform row. The formula `lambda_i=p+eps*a_i`, `D_t=pi+(t/eps)*T` then uses one decoder for every preparation and gives the exact contrasted family. Deleted zero-average outcome columns are identically zero by positivity. The constants force both nonnegativity and row normalization. The positive constant `B` exists because if evaluation at identity vanished on the nonzero invariant complement, equivariance would make every evaluation vanish.
7. **Robust Fourier constants.** Each preparation's Fourier error has operator norm at most `sqrt(2)*delta`; horizontal concatenation weighted by square roots of weights summing to one preserves that bound by Cauchy--Schwarz. The approximate joint block has rank no greater than the same projected core's multiplicity, independent of the chosen weights. Separate weight choices for different irreducibles still supply simultaneous necessary inequalities for that core.
8. **Unbounded joint multiplicity.** The `C2` sign block is `eps[e_i-e_0]`; its Gram matrix is `eps^2(I+11^T)`. Rank `q` requires `q` two-cycles, hence `2q` labels. Equal weights divide the Gram matrix by `q`; the asserted singular-value threshold is conservative at `q=1` and valid for all `q`.
9. **Unbounded pure cost.** The distinct empty-word binary laws force `r` different pure initial labels with first decoder coordinate greater than one half. If these were the only labels, every stochastic first-command mixture would stay above one half, contradicting the reflected target. The additional negative core vertex yields the matching `r+1` upper, including `r=1`.
10. **Different-means boundary.** The trivial-group four-row cycle example has a size-four positive diagonal fooling set (each distinct diagonal pair has a zero cross entry), hence nonnegative rank at least four, while ordinary rank is three. It correctly excludes an unrestricted extension of the common-mean synthesis equality.
