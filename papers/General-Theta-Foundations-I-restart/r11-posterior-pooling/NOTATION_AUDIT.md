# Notation audit

n: number of controlled sensing calls; N=n+3 only in the joint preparation/channel/audit experiment.
M: total persistent alphabet; L_t: per-phase label allocation; S: complete pooling state count; separate simulator S in Proposition 5's local scope is explicitly identified as simulator state.
B_n*: optimal full-history absolute Bayes risk; B_n^pi: policy-dependent risk. Their distinct acquired laws are never interchanged inside an infimum.
p or Q: actual posterior given the retained finite label. W: post-report, pre-pooling posterior. P_n^pi: full-history posterior used only for the checkpoint and lower.
Lambda_t(p,a): raw conditional posterior pushforward. lambda_t: actual mixture induced by the implemented controller. rho: upper density constant, never a normalized replacement for rare mass.
kappa: interior carrier margin; h_t: grid mesh; alpha: hidden transition flip probability in the two-state realization; lambda (without subscript): sensor strength there.
d: actual posterior coordinate dimension verified from raw Jacobian; d_s: relative stratum dimension; r: terminal lower-bound stratum rank.
gamma_t: Bellman score slack; beta_t: evaluation-coordinate tolerance; u: output tolerance; zeta_t: conditional physical-kernel TV; xi_t: certified evaluation failure probability.
L_loss: bounded scored loss; overline L: maximum per-phase label allocation. Distinct typography avoids treating loss range as label count.
No block stopping variable is used in a fixed-horizon formula. Supplement notation is local to each separately numbered integral component.
