# Separate resource accounts

| Resource | Account |
|---|---|
| Actual core acquisitions | C_tau, including failed gates, preparations within the core, and every rejected productive report; lower bound cost per call c_*>0 |
| Productive attempts | A_tau; b_-=N/kappa_- from actual witness effort, not a report-independent external horizon |
| Calibration preparation/observations | N_cal separately, and any confidence/error inference theorem separately; actual total N_raw=N_cal+N_core+explicit initial/final task calls |
| Joint-task initial and audit calls | exactly two extra unit calls in cor:calibrated-joint; N'=N-2 |
| Persistent alphabet | event max(B,D0 m); state-stopped B+D0 m; distinct labels, not just terminal values |
| Persistent bits | ceil(log2 M) only for the explicit alphabet; a program description or continuing random seed is additional unless encoded there |
| Transient computation | acceptance/mark/readout evaluation workspace and time, not inferred from M |
| Program description | comparison law representation, dictionary, routing, exports, predicates, probabilities; ideal Borel descriptions need extra effective hypotheses |
| Numerical precision | acceptance error zeta_q and physical exported-readout error zeta_r; error budgets are charged before correcting the acceptance cap |
| Calibration defects | full current-row a_-,e_- at actual witness; actual accumulated a_N,e_N; upper a_+,e_+; not full-path deficiency |
| Potential functions | proof certificates evaluated analytically on physical/history states; not a machine register |
| Simulator | live K, terminal export E, pair state bound; clocks and seeds included; full stopped scored-law error separate |
| Physical time | waiting and task durations charged by separate additive/potential certificate, not total variation alone |
| Quantum physical system | part of the experiment; not uncharged persistent quantum memory for the classical observer |

Theorem thm:reference-stability gives Borel implementation and a sharp geometric regime, not an optimal joint bit/time/workspace synthesis theorem. The retained finite implementation result and new numerical proposition state their additional effective assumptions. Probabilistic row approximation and an attained invisible calibration sign are not the same error model; the latter contributes delta^2 only in the explicit common task.
