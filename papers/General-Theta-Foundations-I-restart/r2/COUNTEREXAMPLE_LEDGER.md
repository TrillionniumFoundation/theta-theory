# Counterexample and boundary ledger

1. **Envelope versus acquired law.** The same [0,1] envelope supports a point law with zero distortion or a uniform law with positive finite-label distortion. G uses actual density and weights.
2. **Repeated rounding on holds.** Exact identity retention incurs no new error; N*r is not an inherent waiting cost. Holds have zero forcing and zero local arithmetic error.
3. **Negative log gain is insufficient.** Gain 1/4 with probability 9/10 and 4 with probability 1/10 has negative E log G but E G^2=53/32>1. One prior innovation already has growing second moment.
4. **Rare mass normalization.** A nonzero stationary H row cannot certify a terminal component of zero acquired mass. The K theorem requires the explicit zero-row test and weight normalization.
5. **Wrong oracle comparison.** Exact fair-bit observation has a two-point posterior; a Gaussian-garbled observation has continuously varying posterior. Matching each own oracle is not common-loss data processing.
6. **TV is not LDP equivalence.** delta_0 versus (1-exp(-Nc))*delta_0+exp(-Nc)*delta_1 have vanishing TV but different exponential rates at 1.
7. **State product is not automatically necessary.** Cartesian product is an implementation upper. Only separately executable continuation distinctions yield the new mandatory-tag converse.
8. **Allowed error is not unavoidable error.** Exact calibration satisfies any larger tolerance. The robust theorem instead specifies indistinguishable calibration/numerical input alternatives.
9. **Future-answer leakage.** A simulator allowed to request the terminal bit before making a preterminal simulated report could defeat the erasure converse. Such a request is illegal in the defined phase interface.
10. **Null continuous reports.** Event-law equality yields only almost-everywhere density equality without continuity/full support. Arbitrary pointwise Bayes division is excluded.
11. **Free clocks/programs/tapes.** Adaptive time, observation-dependent pointers and surviving scratch registers count as persistent information; readonly tables have description cost.
12. **Singular width inversion.** Deleted zero coordinates do not produce infinite constants; compulsory finite-precision input bit length is still charged when a rational width is tiny.
13. **Unconditional mean costs.** An average per-call bound under one call distribution need not compose under adaptive selection. Conditional uniform bounds are required.
14. **Borel versus bit algorithms.** A finite label set plus an arbitrary real threshold is not an effective finite-bit program. Certified approximate comparisons carry nonzero error.

These examples delimit hypotheses. They do not replace the central positive results with impossibility claims. Regression counterchecks exercise finite instances, not the continuum proofs.
