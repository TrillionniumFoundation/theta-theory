# Resource accounting

| Resource | Charged object and theorem use |
|---|---|
| Raw core acquisitions N | ALL failed gate calls, productive calls and declared preparations through commitment; reference kappa E A lower and common kappa per-attempt upper |
| Gate floor p0 | Known guaranteed lower bound, not true hidden success rate; kappa=1+1/p0; fixed-budget infeasibility displayed |
| Persistent labels M | Live routing + exported terminal values; exact B+m or upper B+D0m; semantic mandatory lower uses same witness |
| Encoding bits | At least ceil(log2 M) to encode labels; not total bit complexity |
| Current workspace | Report evaluation, nearest-center comparison, command coin and temporary indices; erased between calls except accounted live/terminal state |
| Read-only program | Dictionary, acceptance rule, thresholds, physical command interpreter; finite description only under explicit approximation certificates |
| Calibration delta | Root output error adds before squaring; separate hidden fixed-sign offset in the attained lower construction |
| Numerical errors | Acceptance rho on 1/b scale, unnormalized loss eta/b, conditional attempt cost; absolute e amplifies to be |
| Causal deficiency epsilon | Full stopped/scored TV with required early completion; risk <= loss-range*epsilon; reverse lower separately proved only for attained example |
| Simulator state S | Product SM, never M alone; own workspace/description/time cost and action/clock compatibility required |
| Physical time | Sum actual gate, productive, preparation, readout and audit times; no inference from TV |
| Final audit | Core theorem excludes a separately executed final audit; add one physical call. Joint task also has an initial sign call: N_total=N_core+2. |

Worked finite example: 3 persistent states (2 encoding bits); 45 read-only threshold bits plus fixed comparator and output; two 15-bit coordinate registers and a fresh coin plus constant scratch; expected core cost <161, final audit gives <=162. Uniform hidden dynamics and zero positivity floor are permitted, but the pulse and digitizer are physical primitive assumptions whose time costs are declared.

Joint task upper: one initial label + three tagged copies of a 2-live + m-terminal core, giving 1+3(2+m)<=M, M>=13. It is a sufficient construction, not a minimal total-program-complexity claim.
