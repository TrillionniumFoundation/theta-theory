# Counterexample ledger

| Invalid shortcut | Concrete failure / response |
|---|---|
| Equal primary law means equal scored law | Report X=0 for both inputs, audit Z=+1 or -1. Mass balances; first task moment does not. Section 5. |
| Every natural history has a positive variance floor | A static sign with accumulating informative reports has conditional variance approaching zero; a deterministic known-to-history sign has zero variance. The minimax witness and balanced upper still work in the declared larger class. |
| All-model primary closure follows from one observable mode | Two hidden sign histories yield different Gaussian means +a and -a with the same visible port. No exact common primary row. The Gaussian proof does not collapse them. |
| Action names create an intrinsic memory invariant | Duplicate the same physical command with phase-specific names; printed disjointness can increase while legal physical intersections do not. Use semantic commands and no-free-context hypothesis. |
| Averaging an intervention preserves the original estimation target | Flipping a pre-existing sign changes that target. Classical/quantum balancing scores the post-command audit; Gaussian reflection is instead a software/report symmetry for a nonintervening task. |
| Arbitrarily small p0 is feasible at fixed N | Need N>=1+1/p0. The known guaranteed bound is not a learned true rate. |
| Singular reference laws may be normalized to their continuous part | An actual zero-loss atom of mass lambda changes the risk to zero at N/kappa>=1/lambda; removing its mass changes the problem. |
| Terminal TV controls duration | A rare transition can cause arbitrarily long waiting while the final reported value is unchanged. Relative acceptance or killed potentials are separate. |
| Continuous digitization has small TV | Atomic digitization and continuous law may have TV one. Use same-report decision boundary mass and raw moment errors. |
| Allowed error >=0 implies a risk floor | An exactly implementable task satisfies any error allowance. Lower delta/epsilon terms require the constructed hidden offset and early erasure. |
| Finite labels imply finite program description | An arbitrary Borel partition need not have a finite code. Effective primitive certificates are required for Proposition prop:finite. |
| All finite flow equations already give actual occupation | An unreachable zero-acceptance recurrent circulation solves balance. Minimal Green occupation removes it without changing terminal mass. |
