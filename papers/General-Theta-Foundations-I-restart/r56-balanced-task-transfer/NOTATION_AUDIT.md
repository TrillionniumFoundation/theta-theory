# Notation and quantifiers

- theta: inaccessible model fixed per execution; theta0: ONE admitted lower witness.
- K0: actual reference report/audit law; nu: its report marginal. It is not an arbitrary reference volume.
- f,w: conditional first moment and residual squared norm derived from K0; not the full predictive quotient by definition.
- C_tau: actual core cost; A_tau: productive count. C without subscript is a finite output dictionary only where explicitly stated.
- kappa: raw effort per productive attempt, matched reference lower/common upper; b=N/kappa is feasible selection cap.
- m: checkpoint/virtual dictionary size; M: all autonomous states; B: all live routing states; D0: exported terminal multiplicity.
- h: density in profile, also a history variable only in conditional-kernel paragraphs; context disambiguates and no equation uses both ambiguously.
- Q_m(b): actual acquired-law profile; never a free-form covariance quantization.
- d,alpha: actual rectangle exponents; p0: guaranteed gate floor; q is not imposed in the new zero-floor theorems.
- delta: root calibration/readout error or the separately declared hidden offset; epsilon: TV convention sup_A |P(A)-Q(A)|, one half L1 for dominated laws.
- rho,eta: relative acceptance/numerator errors; e is absolute report decision/precision error. They are not interchanged.
- a,sigma: fixed known Gaussian sensing parameters; t_b is determined by actual two-sided mixture tail mass.
- Z: bounded future audit; E: physical sign in realizations, E as ordered vector space only in the finite moment proposition.

No result exchanges fixed-time, bounded stopping and general infinite-horizon claims. No finite-dimensional identity is promoted to unbounded operators. All numbered-source references and bibliography keys are mechanically checked; mathematical meaning is audited separately.
