# Assumption matrix

| Layer | Required raw/certified condition | Not assumed or not implied |
|---|---|---|
| Prepared experiment | Standard Borel kernels; fixed inaccessible theta; declared commands and bounded future audit; positive minimum call cost | No ambient manifold, Fisher matrix or chosen covariance |
| Predictive quotient | Determining executable tests, Borel image/section, legal interface and update factorization | Not every task mark is the full predictive state |
| Converse | ONE admitted theta0, common productive reference moments after FULL report for every competing policy, E C >= kappa E A | Not one favorable model selected separately for each code; not all models share that row |
| Upper | ONE parameter-independent B-live program; every-history cost <= kappa; joint unnormalized mass/loss balance; export multiplicity D0 | Not report-only balance; not an exact true-model filter; not a free preparation pulse |
| Exact state width | Same theta0 makes contexts mandatory; physical command intersections give B; no free context input | No lower from duplicated action names; not a complete minimal-automaton classification |
| Exponent | Actual marked rectangles with fixed d,alpha,c,C,r0 and global packing | Not ambient dimension or formal reachability; actual atom handled separately |
| Stability | Fixed raw classical/quantum instrument; integrated trace/base-norm estimates | Not same-policy estimates recast as unrestricted control; not uniform normalized contraction |
| Finite implementation | Effective L1 report partitions, certified probability/output/coordinate errors, finite primitive descriptions | Borel existence is not finite bit complexity or efficient synthesis |
| Simulation | Parameter-independent typed strategy/report/action/clock/readout; FULL stopped/scored TV; independent resource certificate | Terminal TV alone does not control waiting |
| Joint lower errors | Actually inaccessible offset and actual early erasure with required completion clock | Allowed error ceilings are not unavoidable risk floors |

Both classical and quantum examples use the same main theorem with B=2,D0=1,kappa=1+1/p0. Gaussian nonintervening sensing has a separate sharp residual-variance lower and a two-value upper. The post-command and pre-existing-target tasks are not identified.
