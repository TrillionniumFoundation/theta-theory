# Theorem dependency map

Labels are stable source identifiers; printed theorem numbers are recorded by the build receipt.

```
raw finite-history product domination + conditional return envelope
    -> lem:tensor -> continuity of P,d,r
finite stochastic matrix identities (classical Meyer mechanism)
    -> thm:regularity -> compact recurrence sublevels
    -> lem:roots -> time-changed group inverse + recurrent Poisson bias
conditional stopped-cycle martingale + overshoot + Abel identity
    -> thm:main (i)-(iv)
complete conditional marked-cycle comparison
    -> thm:defect + prop:primitive
raw graph floors + early end probability -> prop:graph
    -> support-preserving cell average / rational rounding / forest evaluation
    -> thm:compile
realized future-test quotient -> lem:quotient
actual class-weighted occupation + conditional projection
    -> thm:geometry (lower, codebooks, counted QJ lift, numerical bound)
    -> cor:matching (control sandwich, conditional optimized power law)
    -> thm:main (v), using (i)-(iii), not conversely
raw killed drift -> prop:drift -> thm:queue, thm:quantum
raw separating loads + actual mass + global cover + weighted gain
    -> cor:rawgeometry, prop:endogenous
fresh holding target -> prop:holding
fresh audit bit + fixed inaccessible calibration -> thm:joint
slow boundary / distinct durations / rare long cycles
    -> prop:boundarysharp, prop:tailsharp
```

Neither queue nor quantum realization is used in the proofs of the general theorem. Theorem 2.1(v) is proved later by combining independently proved transfer and geometry inequalities with parts (i)-(iii); the proof order is not circular. Historical Companions C/B/A/X/W/V/U/T/S are complete provenance, not omitted premises.
