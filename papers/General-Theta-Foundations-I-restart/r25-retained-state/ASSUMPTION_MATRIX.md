# Assumption matrix

| Statement | Primitive/common data | Additional condition | Actual scope |
|---|---|---|---|
| `thm:main` i-iii | standard Borel marked raw kernels, finite actions, one stationary parameter-independent M-state program, product response domination, uniform conditional cycle tail | h(P) <= H for all models; nonempty class | arbitrary fixed model family, retained observer, transient/periodic/multichain boundary |
| `thm:main` iv | same raw model | finite model family | unrestricted fixed-M average value is inf over H; no unrestricted uniformity/attainment conclusion |
| `thm:regularity` | compact family of finite stochastic matrices | none | equivalent cost-universal temporal regularity criteria; not a recursive geometry classification |
| `thm:defect` | complete marked conditional cycle TV, including exit state and length | BOTH endpoints have common tail and recurrence bounds | same task and paired program class, not report-only marginal proximity |
| `thm:compile` | computable reconstruction, model nets, readout net, tail and integrations | support-stable graph floors with primitive end probability | all Borel programs in this architecture, not arbitrary spectral-sublevel rounding |
| `thm:geometry` | one actual law/exploration or a separately verified common predictive realization | global candidate-valid cover, all-pair update gain, finite actual gain occupation | fixed controller, counted QJ labels, known prior initialization only in predictor coordinate |
| `cor:matching` optimized conclusion | joint-control lower/upper sandwich | uniform baseline/mass for all legal controls and one fixed-size attaining controller | conditional matching optimized law; fixed-policy examples alone do not imply it |
| `thm:queue` | unbounded workload, p_a <= pbar < 1/2, finite report/audit laws | spectral sublevel or graph floors | action-uniform drift, no finite filter assumption |
| `thm:quantum` | dominated finite-dimensional positive instruments | dual alive drift; graph or spectral recurrence | classical M-state observer; noncommuting and rank-changing physical state |
| `prop:endogenous` | separating raw hidden/quantum load and state-dependent alive/end instrument | smax (2 smax/smin)^2 < 1, counted exploration recurrence | no independent lifetime, normalized update can expand |
| `prop:holding` | fresh V and finite mean lifetime, fixed response codebook | none on domination of preparation family | direct pointwise result, not general nondominated adaptive compactness |
| `thm:joint` | fresh per-cycle hidden audit B, inaccessible fixed calibration, complete task wire | task-preserving early-report simulator; q_M(pi) power law | matched selected resource slice; not arbitrary Blackwell deficiency |

Reports of zero score may update the controller. Preparation costs one call. The readout is taken from a committed persistent label; report workspace is not a free output channel. The statistical parameter is fixed across the entire path. Fresh B in the joint example is a physical random variable, not a redrawn parameter.
