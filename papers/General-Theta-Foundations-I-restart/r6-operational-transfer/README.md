## Reproduction

From this directory, with Python 3, pdfLaTeX, the AMS/LaTeX extra and recommended fonts packages, and `pdfinfo` installed:

```sh
python3 verify.py
python3 regression.py
python3 -O regression.py
python3 build.py --source-sha <full-source-commit> --expected-tree <native-source-tree>
```

Omit the two optional binding arguments only for an explicitly labelled uncommitted preflight. `build.py` performs two isolated native-subtree builds, three TeX passes each, both Python modes, input-recorder and reference checks, and byte comparison. It writes the PDF under `artifacts/` and the receipt under `evidence/`. It does not run or certify every historical repository project. `refresh_manifest.py` is an intentional source-maintenance operation and must not be run as a read-only validation step.

Read `REFEREE_RESPONSE.md`, `PROOF_LEDGER.md` and `SCOPE_AUDIT.md` before evaluating the scope. The code is regression/provenance evidence, not a proof assistant. Referee-ready means ready for another external assessment, not journal acceptance or independent mathematical certification.
