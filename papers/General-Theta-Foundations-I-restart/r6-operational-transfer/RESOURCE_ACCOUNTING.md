# Separated resource accounting

| Coordinate | Definition and constructive account | Converse supplied here |
|---|---|---|
| N_raw | Every preparation, acquisition, failure/hold and terminal probe | Exact protocol counts: Gaussian T+2; singular B+T+2. Acquisition conditional variance is an exact task term. Not optimal experiment selection. |
| M | Cardinality of predictor's persistent alphabet | Actual score quantization and singular oracle bridge; matched rates under stated hypotheses. |
| R | Persistent simulator states | Serial upper MRDQ; necessity only under a reverse morphism or executable continuation challenge. |
| D | Controller states, including adaptive action state | Same product upper; not a free full-history controller in total-memory claims. |
| Q | Clock/phase/stopping interface states | Same product upper; stopped checkpoint cut uses MQ or full tuple, unless a free interface is explicitly conditioned on. |
| W | Temporary live workspace erased at a cut | Concurrent-register upper only. Persistent workspace must join the state count. No matched general bit-space lower. |
| L_prog | Read-only program, tables and computable calibration description | Additive stored-description upper; arbitrary real constants are not finite descriptions. |
| b_out | Fixed physical forecast grid precision | Actual acquired lower via min(M,(2^b_out+1)^d); not all internal arithmetic. |
| u, v | Certified stable-metric local error and terminal root task error | Add in the same root-error norm before squaring. Relation-preserving enclosure is required. |
| delta | Inaccessible terminal calibration sign in the declared scored task | Matched delta^2 under that explicit alternative class. A generic allowance alone has no positive lower. |
| epsilon | Complete joint stopped transcript/task TV defect | Add L_* epsilon after task distortion; reverse certificates yield lower transfer. Erasure witness proves possible linear dependence, not a universal floor. |
| physical time | Actual durations of executed calls and waits | Add over actual executions. Nested per-call bounds can multiply with the number of simulated calls. No universal minimum runtime claim. |

Sparse finite-input implementation clips to a declared Gaussian box, charges failure-marker probability, and uses finite interval arithmetic inside it. Its acquisition law differs from the analogue one; the transfer bound keeps that defect explicit. Program constants and workspace are not inferred from M.
