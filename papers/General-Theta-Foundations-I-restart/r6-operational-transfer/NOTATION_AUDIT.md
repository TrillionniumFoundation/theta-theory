# Notation audit

`S_t` is a predictive state, not the microscopic hidden state `Z_t`. `J_t` is the true report kernel, `F_t` its common candidate update, and `mathscr F` an exact block flow used only in the proof. `D` in calligraphic type is the fixed rounding relation; `D(pi)` is projective spread in the filtering section; plain controller cardinality D appears only in the resource section and is explicitly typed there.

`m` is raw block length; `M` is hard prediction alphabet size; `K` is a block horizon or total retained budget only in the locally declared statement. `r_M` is static stable-metric resolution, `u` local certified implementation error, `v` terminal root task error, `delta` a calibration sign magnitude, and `epsilon` a complete-law TV defect. `rho` in the stopped theorem is r_M+u, not a transition contraction coefficient.

`nu_T` or `nu_tau` always means the actual conditional-score law. `A_T` is acquisition uncertainty, `B_T` the full-history task variance, and `b_circ`/`b_delta` a specified physical-oracle benchmark. They are not exchanged across different experiments without a common-task certificate.

In the singular section `ell_h` is a nonhomogeneous cylinder scale, `H_T` actual read depth, `omega_{T,i,h}` its actual joint mode/depth mass, and `v_i` a mode metric weight. Finite centers c(u) are predictive posteriors, not physical Cantor points.
