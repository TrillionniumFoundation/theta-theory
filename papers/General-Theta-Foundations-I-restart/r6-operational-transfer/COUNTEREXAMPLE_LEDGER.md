# Counterexample and failure-mechanism ledger

1. **Inwardness is not component mass.** The probabilities (0.9,0.09,0.01) and (0.01,0.09,0.9) have the same projective spread, but the latter first coordinate is below one third of the former. A sparse product's positivity can therefore be destroyed by arbitrary inward rounding. This motivates the independent mass relation.
2. **One-step contraction need not be strict.** A four-state lazy directed cycle has disjoint one-step row supports and positive three-step products. The new theorem works with a block while quantizing at each microstep.
3. **A missing report is not an independent hold.** State-dependent missingness changes the posterior through likelihoods (1-q_i). Treating it as a copy would change the experiment. Independent exact suspensions are separately typed.
4. **Ignoring cross-stratum gains changes the theorem.** The singular 0-to-1 deletion carries squared gain 900 before its destination weight. Diagonal-only estimates omit a real transported error.
5. **Finite acquisition need not yield continuous acquired mass.** At zero read depth the within-mode predictive state is one atom although the physical tail law is Cantor. Small-ball claims for the physical law cannot be assigned to the actual acquired law.
6. **Stopping can select large errors.** The first-success Bernoulli example in Section 3 has deterministic-time error r^2 but stopped error near 1-e^-1. This is a failure of transferring an existing bound, not a minimax lower against all predictors.
7. **A free clock changes the information cut.** If a retained/public stop time reveals a fair hidden bit, one prediction label plus that clock can decode it exactly; a one-label code without the clock has squared distortion 1/4. Hence the stopped cut must count or condition on the interface.
8. **Error allowances do not impose positive floors.** Identical experiments meet every positive TV upper allowance while their actual defect is zero. Calibration and deficiency lower rates require attained alternatives, not a budget label alone.
9. **A proof shadow is not an executable real register.** Telescoping must charge every rounding insertion and its later Lipschitz gains; storing a real shadow or a block of reports would change the resource model. The implementation in Section 2 does neither.

Regression checks exercise finite instances and algebra of these mechanisms. The analytic examples and proofs above, not the count of test cases, justify the boundaries.
