# Notation and quantifier audit

| Symbol | Meaning | Distinction |
|---|---|---|
| N | raw acquisition horizon including failures | not number of successes |
| m | predictive-label cut, online at every time | not total persistent M |
| M | optional total m*R*D_c*Q cap in composition | matching lower needs its own overhead certificate |
| X_t,H_t | hidden raw state / actual visible history | no observation tape after compression |
| mu,b,pi_t | preparation / admissible belief / posterior version | not an unknown parameter coordinate |
| s_t,e_t | predictive quotient state / state approximation error | test-evaluation map is distinct mathsf e_t in §1 |
| p_t | weighted executable terminal prediction vector | not necessarily complete future coordinates |
| B_N | full-history risk in this fixed task and experiment | not silently replaced after a morphism |
| nu_N | actual law of the prediction vector | not valid covering envelope D |
| w_Nj,pi_j | acquired component weights / prepared sensor mixture weights | w includes acquisition probability |
| a_ji | physical chart widths | zero widths deleted, never inverted in final bound |
| psi_j,Psi_N | explicit chart scale / finite allocation formula | not assumed optimal distortion |
| A_t,B_tj,Z_Nj | multiplicative sensitivity / error-injection coefficient / transported injection | analysis marks not algorithm-accessible inputs |
| U_N | propagated calibration/numerical state error | enters before squaring |
| epsilon,zeta | causal path defect / same-state one-step report error | avoid double counting |
| q_0,rho,a | HMM flip probability / contraction / commanded detector strength | q_0 not dimension or quantization count |
| s,h_N | sensor success probability / raw no-success probability | use h_0=1 explicitly |

Quantifiers: general theorem fixes preparation, exploration, task and horizon;
constants are uniform only over specified widths, weights, budgets and horizons
with uniform certificates. Parameter-uniform morphisms have a separate lambda
supremum and a common implementation. Intersecting strata require m>=2J, not all
budgets. Separated charts have all m>=1. HMM constants are not uniform at q_0=0.
