# Pipeline derivation — original G1/G3 line

1. **Raw experiment.** Specify preparation, intervention kernels, legal strategies,
   observation filtration, terminal tests and actual costs. Conditioning is done
   under this law; a success-only reweighting is never called raw acquisition.
2. **Predictive quotient.** Test evaluations identify histories with the same
   executable futures. Compact realization and explicit conditional versions prove
   measurability/updates; sufficient statistics factor through these coordinates.
3. **Same task.** Weighted terminal square loss yields B_N plus distortion of the
   actual posterior-prediction law. This identity is inherited/classical.
4. **G1 mass/geometry.** Integrate raw conditional histories or a raw report
   Jacobian to obtain chart densities and weights. Global physical chart covers
   yield radii. Projected small-ball bounds yield lower scales
   max_l[(a_1...a_l)/k]^(2/l), including rank loss. Allocation includes whole
   discarded strata. For intersections the all-center lower and finite-J allocation
   comparison remove any inverse inter-stratum separation above m>=2J.
5. **G1 causal closure.** Build the actual finite-label update. Inject rounding only
   where executed. Unroll its forced positive recurrence. Match its second moments
   to the same acquired weights. This is the load-bearing transport step, not an
   appeal to a realization formula. Contractive updates and exact holds/overwrites
   independently verify it.
6. **G3 composition.** Add calibration/numerical state errors before propagation
   and squaring. Keep report-kernel TV and causal-deficiency errors as common-loss
   allowances. Compose raw acquisitions/time maps and persistent state products.
7. **Matching status.** Intrinsic predictive-label curves match in the certified
   class. Positive robust calibration/deficiency floors require the explicit
   alternatives in Prop. floors; an upper tolerance is not a lower bound.
8. **Downstream verifications.** HMM: positive rational update, actual Jacobian,
   logit contraction, report continuity. Sensor: actual unsuccessful-acquisition
   mass, glued singular support, indicator transport, continuous terminal kernels.

No quantum spectral formula, old realization conclusion, CI outcome, or source
inventory count is used to prove steps 1–7. The historical kinetic/Sinai/LDP/operator
pipeline is not silently promoted to a theorem in this manuscript.
