# Counterexample and negative-control ledger

| Unsafe inference | Witness / guard |
|---|---|
| A programme at every parameter is one parameter-independent programme | Two models with the same constant report and requested opposite labels: parameterwise feasible; joint constant-affine dual is 2 <= 1, false. |
| Sup inf equals inf sup / parameterwise readout is free | Predict a hidden deterministic bit with no information: oracle risk 0, common squared-loss minimax 1/4. Calibration theorem gives a nontrivial 4/5-state distinction. |
| A new adversarial model may be chosen at every call | Bernoulli p in {1/10,9/10}: one fixed model gives mismatch probability 9/50 over two calls; changing p between calls gives 41/50. These are different experiments. |
| Weak-star products always converge | Attainment proof instead integrates each finite-dimensional operator first and only then multiplies finite moments. No claim for arbitrary diagonal or infinite-dimensional products. |
| Approximate model implies exact stopping | A newly possible report path can create an early or late halt at arbitrarily small mass. Common support and signature-preserving implementation are explicit prerequisites. |
| A finite parameter net yields a global lower/upper automatically | Lower uses net inclusion plus all-programme compiler; upper needs a uniform raw-model modulus. Pointwise continuity alone gives no computed modulus. |
| Finite global obstruction is effective without supplied data | Compact finite-intersection proof gives no witness cardinality or method; effective theorem separately pays for complete candidate and model-net enumeration. |
| Phi for a family equals a sum of separately minimized oracle terms | Robust Phi is total risk with common readouts. No separate baseline/compression minima are taken. |
| Singular law can be renormalized after discarding rare reports | Tail/error weights and flag masses remain actual masses; tail cell is retained. |
| Fixed M counts all computation | Programme constants, table access, scratch, time and live simulator state have separate accounts. |
| Source calls bounded by C mean an exact-C machine | Source interface is explicitly at-most; exact conversion requires clock and padding certificate. |

All original stationary-reuse, clock, blind bottleneck and calibration/erasure counterexamples remain in the native inherited sections and the unchanged predecessor sources.

An erasure symbol seen only at the first phase breaks the cross-phase common-null-set hypothesis. The seven-state attained-risk construction does not inherit the binary model's clock lower. Confusing these interfaces would incorrectly assert an unproved sharp memory threshold.
