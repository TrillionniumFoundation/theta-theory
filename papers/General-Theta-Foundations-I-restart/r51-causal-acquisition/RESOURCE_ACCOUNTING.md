# Resource accounting — R51

| Resource | Exact conventions and charges | Where checked |
|---|---|---|
| Raw acquisitions | N=Eτ only for c_a=1; rejected calls included | Actual mass lemma and geometric inverse |
| Priced scalar budget | EΣc_A≤N; counts x_a, positive c_a | General profile and dual |
| Persistent labels | Autonomous one live + m terminal = m+1; no free seed or phase | Exact realization and all-observer lower |
| Persistent bits | ceil(log2(m+1)); code selection and action policy are not hidden state | Experiment model and finite implementation |
| Clock | No prescribed horizon in new mean model; none carried free. A simulator clock belongs to its R states | Sections 2 and 8 |
| Program constants | Action/routing probabilities, codepoints, membership algorithms and threshold precision paid separately | Appendix B; Gaussian certificate |
| Workspace | Current report evaluation and rational sampling workspace separate; erased after update | Appendix B |
| Program-size region | O(A K_h (m+1) log Q + m d p + A log Q), plus membership data | Finite implementation; sufficient, not optimal |
| Execution time | One membership/evaluation and one finite routing sample per call; expected total ≤N times declared primitive mean cost | No worst-case claim for variable fair-coin sampling |
| Numerical errors | Routing and boundary mistakes need their own probability certificate; readout v adds at root excess only under same path law | Section 8 and Appendix B |
| Preparation/audit | Main core displays observer calls; joint theorem charges prep+bit+bundled audit, N=n+3 | Joint singular theorem |
| Joint-task labels | 1 core live + m bit-waiting +3m terminal =1+4m≤M, M≥9 | Attained δ/ε proof |
| Simulator state | Predictor M times simulator R; additional clock/internal labels included in R | Typed simulator proposition |
| Simulator calls | κN+c; composition κ1κ2N+κ1c2+c1 | Common-task composition |
| Physical quantum system | Part of instrument, not free observer memory; all observer decisions use classical labels | Quantum realization |

The Gaussian optimum charges two observer states; its rational threshold and decoder are readonly program descriptions, not free infinitely precise arithmetic. The finite certificate supplies attainable approximations and expected-budget inequalities. No table in this revision is a claim that label complexity equals total bit/time complexity.
