## New general mathematics

For a common m-point dictionary C, action counts x_a and terminal densities h_a, the profile minimizes

`sum_a integral dist(z,C)^2 h_a(z) nu_a(dz)`

subject to `0 <= h_a <= x_a`, `sum_a integral h_a = 1`, and `sum_a c_a x_a <= N`. The unnormalized measure h_a nu_a is an actual terminal submeasure; x_a is an expected paid action count. Lemma 4.1 proves the constraint for every all-history strategy. Lemma 4.2 realizes every feasible tuple exactly with **one live state**, action probabilities x_a/sum x_a and acceptance h_a/x_a. Thus, for the same protected quadratic task with audit noise B,

`R_cp(N,m;c)-B = Psi_m(N;c)`,
`R_aut(N,M;c)-B = Psi_(M-1)(N;c)`.
