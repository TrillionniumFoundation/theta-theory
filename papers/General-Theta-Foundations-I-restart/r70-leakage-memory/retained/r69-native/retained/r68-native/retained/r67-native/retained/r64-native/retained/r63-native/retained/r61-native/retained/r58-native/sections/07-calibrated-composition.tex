\section{One-task composition with calibration and simulation}
\label{sec:calibrated-composition}
Define $\underline Q_m(N)$ and $\overline Q_m(N)$ to be the lower and upper expressions in Theorem~\ref{thm:reference-stability} at a declared virtual or terminal width $m$, with the same effort and defect certificates; at $t_N=0$ put $\underline Q_m(N)=0$. These expressions are bounds, not new independently chosen geometric objectives.

\begin{corollary}[An attained-error task with an imperfect reference]\label{cor:calibrated-joint}
Take the calibrated class with the two-role gate, identity exports and a declared actual witness. Add one initial unit-cost observation of an independent fair sign $E_0$, erased with probability $2\eps$, $0\le\eps\le1/2$. The core kernels receive no information about $E_0$ other than its reported tag. They receive no information about a fixed unknown sign $s\in\{-1,1\}$ that influences only the last coordinate of the final unit-cost audit
$(Z,E_0,s\delta)$, $\delta\ge0$. All coordinates of the prediction are committed before that audit. Core certificates hold uniformly after every initial reported tag. For $N'=N-2$ in the feasible core range and
\[
 m_\st=\lfloor(M-1)/3\rfloor-2\quad(M\ge13),\qquad
 m_\evt=\lfloor M/3\rfloor\quad(M\ge7),
\]
one has, for either indicated interface,
\begin{equation}\label{eq:calibrated-joint}
 \underline Q_M(N')+2\eps+\delta^2
 \le R_{{\rm joint},\iota}^\Theta(N,M)
 \le \overline Q_{m_\iota}(N')+2\eps+\delta^2.
\end{equation}
The lower uses terminal width $M$, which is safe for both interfaces, not a free extra dictionary. Under the matched-geometry and two-sided defect regime of Corollary~\ref{cor:reference-geometry}, this yields
\[
 R_{{\rm joint},\iota}^\Theta(N,M)
 \asymp F(N'/\kappa_-,M)+\delta^2+\eps.
\]
The early interface's causal deficiency to the perfect-sign interface is exactly $\eps$, when its virtual sign must be delivered before any core call. The numerical and reference defects are separate from this attained erasure deficiency and from the unobservable calibration sign.
\end{corollary}
\begin{proof}
The tagged construction has one initial live role and three copies of the two core live roles. Its terminal roles are three copies of the core dictionary. Thus state stopping uses $7+3m$ labels, while event stopping uses $\max\{7,3m\}$. Run the common calibrated upper in each tag, output the known sign or zero on erasure, and output zero for the calibration coordinate. Uniform conditional core certificates give the upper in \eqref{eq:calibrated-joint} with exactly the core cost $N'$. No audit is available at prediction time.

For the lower fix the actual core witness and average the indistinguishable alternatives $s=\pm1$. Conditional on every erased pre-audit history, including the stopping event, $E_0$ remains fair by causal induction: no core kernel reads the unrevealed sign. The erased coordinate therefore contributes at least $2\eps$. The averaged calibration-coordinate loss is at least $\delta^2$. Under the same mixture, the core accepted comparison submeasure of Lemma~\ref{lem:comparison-submeasure} obeys the uniform row and occupation certificates and cost $N'$, with at most $M$ projected outputs. Its core risk is at least $\underline Q_M(N')$. These three bounds hold in the same risk calculation; different worst-case models are not added. The displayed width ratios are bounded on the stated ranges, proving the geometric consequence.

On erasure, any immediately produced virtual sign is independent of the hidden fair $E_0$. Thus the event that virtual and audited signs agree separates the perfect interface from every simulator by at least $\eps$. Completing erased signs with an independent fair coin gives a disagreement coupling of probability $\eps$, followed by the same causal continuation. This attains the reverse bound. This early-channel argument is the exact mechanism already proved in Theorem~\ref{thm:joint}; its use here does not assume that the core has an exact admitted reference. The additional kernel independence assumptions prevent leakage of the erased sign through the core.
\end{proof}

\begin{proposition}[Numerical execution at the prescribed physical budget]\label{prop:calibrated-numerics}
Fix a finite virtual dictionary, an intended acceptance function $q$, and the export readout $T_Jr$. Suppose a finite description supplies a measurable implementation $\widetilde q\in[0,1]$ and exported readout $\widetilde r_J\in H$ such that, on every physical report and within-call choice,
\[
 |\widetilde q-q|\le\zeta_q,\qquad
 \|\widetilde r_J-T_Jr\|\le\zeta_r.
\]
The implementation uses the same number of declared output codes and no new intercall state. Its expected cost and risk bounds are given by the upper construction of Theorem~\ref{thm:reference-stability} with
\[
 a_+\ \hbox{replaced by }a_++\zeta_q,\qquad
 e_+\ \hbox{replaced by }e_++L\zeta_q+2\operatorname{diam}(H)\zeta_r.
\]
Use the corrected design cap before evaluating $q$, so the final expected cost remains at most $N$. The certificate must be available uniformly for the selected corrected design. Program description, integration or threshold synthesis, temporary workspace, random-bit generation and evaluation time remain additional stated resources. Their finite bounds do not follow from Borel measurability.
\end{proposition}
\begin{proof}
The acceptance probability changes by at most $\zeta_q$. For $z,r,r'\in H$,
$|\|z-r\|^2-\|z-r'\|^2|\le2\operatorname{diam}(H)\|r-r'\|$.
Thus each unnormalized task contribution changes by at most $L\zeta_q+2\operatorname{diam}(H)\zeta_r$. The conditional-hazard summation in the central proof applies with these enlarged errors. The code indices and command routing are unchanged by hypothesis, so no extra labels have been granted. A description certifying the evaluation errors may be expensive; only Proposition~\ref{prop:finite}'s explicit computational hypotheses, or a concrete implementation with the same guarantees, supplies the additional bit and time bounds.
\end{proof}

Complete stopped-law simulation composes with these estimates through Propositions~\ref{prop:simulation}--\ref{prop:role-composition}: a bounded common loss incurs at most $L_{\rm task}\eps_{\rm sim}$ in that direction, and actual expected cost needs its own certificate. Live simulator states and terminal export classes are charged before event-role reuse is allowed. Lower transfer through a different physical presentation requires a reverse resource-certified simulator or a separate actual witness; a one-way approximation is not a lower bound. The row defects above compare current productive tasks along actual histories and should not be renamed full-path deficiency.
