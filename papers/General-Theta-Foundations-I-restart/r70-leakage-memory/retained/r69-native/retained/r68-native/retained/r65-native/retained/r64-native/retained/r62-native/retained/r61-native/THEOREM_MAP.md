# Theorem and dependency map — current R61
Numbers below are resolved from the actual native build. Logical dependencies are stated by layer; the final table is a source cross-reference index, not a mechanically verified proof graph.
## Mathematical layers
1. Prepared causal kernels, full-report task coordinates, commitment semantics and paid costs precede the actual-occupation lower and common-program upper (3.1, 3.3). The lower uses one actual model against every competitor; the upper is one program for every model. Event and state stopping remain distinct.
2. Compact decision-continuous losses give attained width defects and the general transfer (5.1, 6.1). The same dictionary is used across actual histories. Squared-task equality does not require equality of the entire second-moment matrix.
3. Profile attainment and zero-loss sets give the exact zero-risk criterion (7.1), the atomic width spectrum (7.2) and the corrected single-atom scope (14.5). Matching physical thresholds additionally require exact paid transfer certificates. The tied threshold dual (7.4) is classical selection geometry used explicitly, not a novel minimax principle.
4. Common sequence-form weights, positive conditional cost floor, bounded terminal scores and compactness give finite-obstruction synthesis (8.3), its strict finite dual and fallback. The finite-memory certificate (9.2) additionally fixes time-homogeneous finite physical models and tests only reachable Hilbert supports. Algebraic decidability requires algebraic primitive data and a finite model list.
5. Rejected-return task measures and allowed preparations generate a report-resolved Hermitian span. Invariance and finite dimension give 10.1; conditional hazard and separately paid return compile its equalities in 10.2. Signed-measure uniqueness and an invariant-span event selection give the standard Borel extension 10.5. Explicit positive Choi perturbations and Vandermonde interpolation prove the sharp dimension-dependent obstruction 10.6. This is not a new claim of priority for Hermitian reachable spaces.
6. Primitive reset branches produce a finite absorbing control problem. Absence of a closed failure set, monotone Bellman iteration, spectral separation and residual telescoping prove 11.1. Equality of Bellman slacks gives conditional memory lower certificates in 11.2. The rank-one family corollary has its own scope. The inherited arbitrary-rank two-projection frontier 12.1–12.4 remains separate.
7. Raw singular task order, acquired geometric estimates, classical/quantum post-command realizations, computation/calibration and the predictive quotient are retained with their original assumptions. The current supplement supplies restricted preparation-face potentials, domain/deadlock treatment, return/audit compilation and tail-integrability boundaries. A1, A2, communication/ordered-measurement legacy lines are preserved, not assumed as hidden premises.
