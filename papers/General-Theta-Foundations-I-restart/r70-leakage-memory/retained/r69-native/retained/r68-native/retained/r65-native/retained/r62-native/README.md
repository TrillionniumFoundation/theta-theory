## New mathematical work

The current primitive-instrument theorem derives a common proper fallback for a finite family of time-homogeneous, finite-dimensional instruments, then gives a constructive two-sided approximation of actual constrained task risk at the **same expected-cost budget** N whenever N exceeds a certified fallback cost kappa. A preliminary two-sided cost hierarchy constructs a sufficiently inexpensive finite fallback for every N strictly above the least feasible cost, removing the restriction to the initial one-row bound. A finite semidefinite plan, a real open-path cost reserve, fallback completion and a counted initial mixture give an explicit O(1/T) gap. Fixed decoder cardinality survives compact decision-net approximation. The instruments need not reset the input, commute, or possess a balancing group. The qualitative invariant-subspace termination obstruction is established quantum reachability theory and is explicitly credited; the assertion is the quantitative same-budget risk and implementation theorem with its precise common-model quantifiers.

A second new result solves the selected-mass comparator for two different geometric strata in six regimes, including two nonsmooth crossover intervals. This is an exact comparator phase diagram, not an exact physical risk formula with the inherited comparison constants silently set to one. The literature comparison uses Liu–Verdu, Goc–Flamich and the updated Li–Liu multistate preprint, not only the older binary version cited by the referee.
