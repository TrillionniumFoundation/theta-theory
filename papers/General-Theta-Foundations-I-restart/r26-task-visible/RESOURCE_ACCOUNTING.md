# Resource accounting

| Resource | Charged object / proof | Not silently supplied |
|---|---|---|
| Persistent labels M | All action/update/decision/stop state; common same-M comparisons | No hidden seed, full history or exact posterior |
| Predictor-control product | QJ in `thm:geometry`; 2 floor(M/2) in joint law | Control coordinate is not erased by physical preparation |
| Simulator state s | Joint sm state in `prop:defect`, with its actual clock | Recurrence or compatibility of predictor alone is insufficient |
| Acquisition count | Every raw call; quantum N=2n; joint N=4n | Preparation, failures, load and audit are not free |
| Physical time | Duration tau and joint duration–exit T; classwise normalization | Not boundary count, pooled duration, or virtual call count |
| Program description | Finite row/center descriptions; J q p-bit center storage upper | Real constants depending on unknown theta are disallowed |
| Temporary workspace | Explicit distance-scan upper O(qp+log J), plus sampler | Not persistent label count |
| Numerical precision | Root errors then square; candidate validity preserved | No automatic exact real comparison or arbitrary precision |
| Calibration delta | Fixed inaccessible sign, common observable law, delta^2 lower | Parameter not redrawn along the path |
| Deficiency epsilon_* | Actual early-report scored interface; e/2<=epsilon_*<=e | Not any allowed tolerance, not fabricated ground truth |
| Computation time | O(Jq) fixed-precision distance operations per load for the explicit scan | No claim of optimal all-resource region or efficient QE |

Protocol phases used by the examples are visible types of actual physical calls. An autonomous machine required to reconstruct an unprovided clock would need additional states. No finite-time argument is extended to arbitrary stopping without a new certificate.
