# Notation audit

- theta: one fixed inaccessible experimental parameter; gamma: one parameter-independent program; x=(theta,gamma), optionally with a test f.
- P: retained boundary transition matrix only. K_call / call kernels and mathcal K: physical/complete-cycle probability kernels, never the same P symbol for a law.
- T_ij: joint duration–exit expectation; d=T1, D=diag(d); T is NOT D or DP.
- S=I-D^(-1)(I-P): time-changed stochastic matrix; d_i>=1 is explicit.
- Pi_A: Cesaro projection of a finite stochastic matrix; G_P: group inverse of I-P.
- g: vector physical-time task gain; scalar initialization pairing explicitly specified in robust corollary.
- b=r-Tg: marked centered reward; u: proof corrector, not stored by the machine.
- S_k: cumulative physical boundary times; K_N: bounded crossing-cycle index. Distinct from the predictive image S by local context.
- C_X(a): approximate task-corrector oscillation price; not a uniform all-cost recurrence H.
- B_N: physical overshoot-tail bound; B_*: irreducible baseline in optimized geometry.
- nu_N, nu_infinity: actual scored submeasures; preparation and audit calls remain in denominator.
- q_J: fixed-codebook quantization infimum for a specified law; common robust codebook required for an upper.
- Q: control labels, J: predictor centers, M: total retained labels; s: simulator labels when used in composition.
- delta: calibrated/numerical quantities are separated by theorem. Joint law delta is a fixed hidden-sign offset.
- e: actual loss of revealing probability; epsilon_*(e): true common-task deficiency, only bracketed e/2 to e.
- k: revelation power; d: acquired dimension; neither is an ambient parameter-space rank.
- Quantum vacuum v is orthogonal to a two-dimensional sector; there is no ambiguous third qubit basis vector.
