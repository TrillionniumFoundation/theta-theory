# Counterexamples and excluded inferences

| Boundary | Explicit witness | What is prevented |
|---|---|---|
| Exact finite primary row | ex:closure: two histories in same visible gate phase have different hidden-sign posterior and therefore different gate probability | replacing actual acquisition counts by a fixed report row |
| Uniform current-report mark | ex:calibration-failure: repeated noisy observations of a static bit yield vanishing variance and incompatible means at same current report | treating positivity alone as uniform calibration |
| Vanishing floor | prop:q-sharp: a_q=q gamma/[(1-q)(1-gamma)+q gamma], radius/variance >= c/q | uniform constants at q=0 or projective weak-effect limit |
| Action aliases | ex:alias: two names for one legal physical advance do not create two compulsory states | presentation-dependent action-signature lower |
| New phase-aware command | physical advance that detects phase replaces incompatible ports | counting its external phase state as free |
| Critical atom | thm:atomic: r=(1-b lambda)+ and r Q(b(1-lambda)/r) | constant-factor identification of Q(cb) and Q(b) near a threshold |
| Phantom circulation | unreachable absorbing self-loop added to finite occupation | identifying an arbitrary balanced occupation with the actual first run |
| Discrete vs continuous TV | dyadic same-report coupling uses boundary mass | claiming digitized continuous reports are TV-close |
| Rare herald fixed budget | constant p_minus member requires N>=1+1/p_minus | treating an infeasible fixed N as a uniform small-p theorem |
| Universal synthesis | arbitrary finite-memory POMDPs differ from the certified two-port class | deriving efficient optimal programs from label bounds |
