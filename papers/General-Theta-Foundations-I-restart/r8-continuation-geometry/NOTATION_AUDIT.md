| Symbol | Meaning and scope |
|---|---|
| H, U | Complete pre-cut visible history and complete post-cut side information; includes required public coins/action/phase/cost coordinates |
| Y, z | The one bounded scored task and its full-history conditional mean z(h,u) |
| B_T, B, B_* | Bayes baselines in the general, chart, and regression statements respectively; the sphere-valued query B occurs only in the regression section, with its baseline always B_* |

| mu_-, xi | Finite, unnormalized dominated measures; q_M scales linearly with their mass |

| d, r | Chart dimension and ball radius; noisy test response rank is proved using the query frame; no universal ambient-dimension assertion |
| alpha, p, l, b | Chart domination, acquired mass, response lower modulus and acquired density upper |
| K_tau | Number ceil(tau/m) of entered stopping blocks; no longer sigma |
| sigma_i | Virtual source completion time in the morphism theorem |
| sigma, tau | Positive Gaussian noise standard deviations only within the regression/filtering realization |
| ell_(j,k), s_j(k) | Physical cylinder length and weighted coordinate length; ball projection diameters are explicitly in weighted coordinates |
| R_b | Largest remaining weighted scale after b greedy reads; not a simulator state count |
| R | Simulator cardinality in the resource theorem; locally distinguished from the regression compact-window radius |
| M, Q, Cctr | Data-dependent full tuple, separately stored phase/clock, controller alphabet; products explicitly charged |
| p in thm:digital | Common precision per coefficient and output coordinate, not one bit budget for the vector |
| delta, u, v, epsilon | Declared calibration, local numerical/readout root errors, and complete-law TV defect; not interchangeable norms |

Formal labels are unique and all references/citations are checked per source manifest. The supplement has intentionally local labels in its own separately compiled document. Its section numbers are always cited with the prefix Supplement S.
