# Resource accounting

| Resource | Meaning | Proved account | Not silently included |
|---|---|---|---|
| N | Actually executed preparation, acquisition, idle, packet, audit calls | Progressive N=n+2; erasure N=n+3; noisy regression d+3; singular B+T+2 | Virtual calls or an unread physical tail |
| M | Entire data-dependent alphabet crossing a cut | Hard every-cut bound; noisy compander prefixes have at most m^j<=M | Rereadable history, hidden predictor/controller registers |
| Q | Separately stored deterministic phase or stopping clock | Serial count multiplies to M Q; noisy pre-audit phases d+2 | Free data-dependent phase |
| R, Cctr | Simulator and controller retained alphabets | General serial upper M R Cctr Q; reverse certificate needed for necessity | Claim that every register product is minimal |
| Workspace W | Temporary bits erased before next cut | Progressive explicit sequential-tape bound O(p+log(K+d)); noisy exact-Borel upper does not quantify arbitrary integral evaluator | Past output coordinates or arbitrary exact real arithmetic |
| Program | Known parameter-independent certified descriptions | Progressive O((K+d)(p+log(K+d+N))) feasible upper | Free coefficient/schedule oracle |
| Precision p | Common bits per coefficient and output coordinate | Progressive root Gamma=(K+1)2^(-p) | Treating p as one vector-wide bit count |
| Calibration delta | Declared physical perturbation or unknown sign | Noisy response root upper; progressive inaccessible sign gives matching delta^2 | A lower from an error allowance |
| Numerical u,v | In-task root errors for specified legal implementation | Added to root geometric error before squaring | Relation-violating wrong-state routine |
| Deficiency epsilon | Complete-law discrepancy with common task and allowed stopped strategies | Bounded loss times epsilon added to absolute risk; exact early erasure attains epsilon | Replacing source and target Bayes baselines without a proof |
| Time | Physical acquisition and actual bit operations | All calls paid; progressive sequential-tape feasible runtime | Unit-cost arbitrary big integers or free random access |

## New noisy implementation

A paid report H_j is quantized immediately into at most 2k-1 values. The retained prefix has at most (2k-1)^j<=M values. At the single packet call, the response is computed using only this tuple and current (V,B), and an M-grid scalar label replaces the old tuple before the next cut. All packet arithmetic is temporary. This is a mathematical finite-label Borel construction, not a claim that Gaussian integral evaluation or arbitrary parameter descriptions cost no bits.

Causal report perturbation at most delta preserves the required marginal moment bound and adds at most a constant times delta to root risk. Certified response evaluation adds u. A complete causal simulator adds its full state factors and an absolute bounded-loss epsilon term. The full optimal program/workspace/time/simulator-state region remains unproved.
