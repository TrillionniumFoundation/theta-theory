# Proof audit — submitted arguments, not formal certification

**Quantifier order.** The acquired common submeasure is fixed before choosing the starting state or b-step feedback policy. The Bellman range proof uses this common interval before taking the policy infimum. An action-dependent submeasure chosen after the policy would not prove the displayed uniform contraction. Gaussian uses a fixed output core for all sensors; quantum uses quiet-report events uniform over every chosen unitary, followed by one common target ball.

**Actual calibration.** Conditional action coins are independent of the hidden state given the old label. Affine unnormalized moments give the reweighted W. Every predecessor/action/report edge into the new label contributes to Q. This proves, rather than assumes, Q=E[X|label]. The Bellman/Jensen telescoping compares with the same-task full-history optimum.

**Nonsmooth boundary.** The convex extension agrees on K, including its boundary. Distributional Laplacian mass is controlled in a fixed neighborhood by a cutoff and bounded gradient. Bounded actual density supplies the second power of grid scale. No optimal-action differentiability is used. All slopes are bounded by the buffer and Bellman oscillation, not by a hypothesized stable oracle policy.

**All-policy lower.** The last true-history law and the last unpooled retained row law are mixtures of uniformly bounded densities. The same union-of-balls bound applies to any finite code; fractional assignments cannot beat its pointwise minimum. The exact final Jensen term is nonnegative independently of prior action mistakes.

**Clock.** A finite actual report/action/label trace is equivalent to its reference trace at every possible incoming physical history. A repeated nonhalt label would transfer a later halting event to an earlier cut. No argument conditions on a continuous report point. Action choices belong to the fixed label programme, so reuse does not create a free phase variable.

**Raw models.** Gaussian log-odds density bounds include untruncated tails and name the likelihood determinant. The common output core has positive acquired probability uniformly in all incoming beliefs. Quantum congruence inversion is finite-dimensional and has a nonzero Jacobian on compact positive domains. The quiet corridor counts every failed path and every call; it is not a free reset or conditioning argument. Both have complete executable-test separation and actual preparations.

**Singular small budgets.** Fixed visible-mark allocation uses relative dimension and actual probability. Widths too small for all marks use one merged label, with error bounded by continuation oscillation. Thus no extra unproved `J*n` clock tax is inserted into the rate. Coarea uses bounded fibers and nonzero singular values for each fixed rank.

**Numerical implementation.** Compare first with a reference process with ideal labels and rounded committed outputs. Unconditional conditional-mean orthogonality gives the readout-square error there. Only then couple the actual process; the first-mismatch event is bounded using UNCONDITIONAL ideal row mass, not a no-earlier-error conditional density. Rounded-action errors are represented as declared Bellman slack, not as an unproved action-margin condition.

**Joint task.** A bit acquired before feedback can be stored in the physical core. The new proof therefore prepares it after all controls; it cannot reveal lost core information or be stored by later core actions. The final cost-four construction, small-budget coarse alternative, product-prior calibration lower and exact deficiency are explicit. An arbitrary error tolerance is never treated as an attained lower bound.

**Scope checks.** No minimax exchange, no infinite stopping extension, no TV-to-LDP leap, no unbounded-operator closure, no rank-only statistical law, and no unrestricted unknown-model claim appears. Programme/workspace/time upper certificates are not optimality claims. Finite tests check arithmetic and inventory only.
