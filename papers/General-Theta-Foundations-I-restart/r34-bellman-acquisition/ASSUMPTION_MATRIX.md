# Assumption matrix and quantifier audit

| Layer | Required input | Quantifier | Not assumed / not implied |
|---|---|---|---|
| Primitive experiment | Known positive standard Borel kernels; finite action set; bounded protected audit | One declared family and task, all legal adaptive strategies | Unknown-model learning or arbitrary interventions |
| Predictive quotient | Finite affine executable tests; separating coordinates; attained Borel image and section | All future executable finite continuations at fixed interface phase | Arbitrary measurable quotient automatically standard Borel |
| Raw update | Affine numerator and likelihood; common null set per `(t,a)` | All `u in D`, simultaneously off that null set | Exchanging normalized update and old expectation |
| Exact identities | Raw closure, private-coin independence and all-incoming calibration | Every legal randomized finite observer | Stability, density or common report support |
| Actual row geometry | Density `<=Lambda` on `K`, buffer `K+B_r subset D`, global Borel grid | Every phase, action and barycenter in D | Only the terminal full-history density is insufficient |
| Continuation | A common submeasure of mass epsilon in every b-step output law | Every start in D AND every b-step feedback policy | Same-action coupling, one-step W1 contraction, necessary compressibility condition |
| Raw corridor | Intermediate event masses uniform in all actions; last common submeasure | Conditional at every reached corridor state | Conditioning on success / free retries |
| Clock | Report laws equivalent to fixed actionwise reference at all histories | Every possible history of every legal programme, every phase | Free timestamp, end marker or external stopping signal |
| Uniform rates | Fixed dimension, volume/buffer/overlap constants | Constants uniform in n,M | Uniformity as overlap/rank/positivity degenerates |
| Gaussian | Fixed positive invertible P; finitely many full-rank Gaussian log-odds maps | Uniform on the displayed compact parameter subfamilies | Free tail truncation, unknown P/means, zero mixing floor |
| Quantum | Finite D, `0<eta,lambda<1`, finite unitary action family, complete POVM | Every prepared interior state and feedback strategy | Shared basis, unbounded operators, quantum controller memory |
| Strata | Finitely many current visible affine marks, fixed actual weights, relative densities | Every action and retained barycenter | Pure curved orbit automatically satisfies affine-stratum assumptions; vanishing weights uniformly |
| Precision | Certified global programme/integration, primitive and arithmetic coupling, actual boundary mass | Every ideal incoming row; unconditional mixture | Discrete numeric output TV-close to raw continuous report |
| Joint errors | Fresh independent bit after all core controls; invisible fixed offset; protected audit | All legal autonomous machines and both offset signs | Arbitrary tolerance automatically creates a minimax lower |
