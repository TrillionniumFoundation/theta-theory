# Resource accounting

| Resource | Native construction | Separate obligation |
|---|---|---|
|Persistent dynamic labels|M=m+1 including the erasure row; same labels at all dates|No exact posterior, hidden phase, previous report or retained RNG seed|
|Persistent dynamic bits|ceil(log2 M)|Not total memory or total description complexity|
|Program/codepoints|M fixed predictive vectors, action probabilities, grid/primitive rules and readouts|Finite description bound in Proposition `prop:compilation`; rare-label output precision counted|
|Temporary workspace|Primitive evaluation plus coordinate arithmetic/cell search/fresh coins|W_primitive(p)+O(dp+log M+|A| log Q); not free|
|Planning|Finite enumeration and certified invariant integration|Explicit cardinality, not efficient or optimal|
|Raw acquisitions|At most n report calls; expected (n+1)/2 for hidden uniform T|Every quiet/erased/numerical-fallback call is paid|
|Preparation and audit|One initial preparation and one protected audit|Core pathwise N=n+2; bit extension N=n+3|
|Audit clock|Independent uniform T and ceil(log2(n+1)) counter bits|External controller not given counter; physical elapsed time paid|
|Erasure|One label, independent dyadic rate alpha|No physical reset; risk alpha H, mixing alpha eta|
|Numerical/calibration|Weighted output error; kernel mismatch divided by alpha eta|To keep rate, tau_total <= const alpha eta M^(-2/d); no error floor without attained alternatives|
|Causal simulator|R labels times observer M|Parameter-independent actions/reports/strategy lift/clock/task compatibility; compose physical call maps|

Hard-state upper and lower are matched in stationary risk and the declared finite entrance region. Optimal workspace, program length, planning time and entrance-time lower bounds are not proved. Classical controller labels are not interchangeable with physical quantum-state dimension.
