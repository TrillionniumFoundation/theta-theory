# R66 author proof audit

This is an author-side audit, not an independent referee or formal proof certificate.

| Claim | Load-bearing proof | Boundary / limitation |
|---|---|---|
| Weighted cost identity | H=G+T*H, finite-horizon telescoping, bounded remaining potential, nonnegative residual | One command; full declared report input; no free state inspection or reset |
| Robust first-herald rigidity | Tight cost-maximizing models cover every possible first-herald word | Support coverage is sufficient, not necessary; explicit cheaper-model counterexample without it |
| Tied optimal face | Uniform geometric tail; compact minimax; nonnegative unnormalized slack | Model-specific inequalities are retained; zero-average words allow all decisions |
| Exact stochastic memory | Anchored invariant convex family iff stochastic transitions and decoder rows | Classical positive-realization machinery; criterion is not by itself a generic effective construction |
| Calibration optimum | Opposed losses and a power series vanishing on an interval force every coefficient | Fixed dictionary {0,1}; known protected channel; unknown horizon rate and audit sign |
| Exact k-label family | Binomial survival; exponential-polynomial shifts; normalized Hankel rank k | Live memory, not protected state measurement; one-label formula separately proved |
| Damped qubit realization | Invariant regular polygon, stochastic barycentric rows and bounded decoder | Strict retention alpha<1; no claimed sharp asymptotic label rate |
| Undamped obstruction | Cayley-Hamilton forces irrational unit-circle eigenvalue; stochastic peripheral cycle proof | Finite rank alone insufficient; no numerical argument used for impossibility |
| Sharp three-label threshold | Circulant upper; universal three-state generator trace/minor lower | alpha=0 handled separately; all stochastic matrices and random decoder rows included |
| Exact algebraic size test | Block linear reachable span stabilizes by M+r-1 | Supplied all-word representation; fixed-M decidable; unbounded generic realization not claimed decidable |

All existing R65 theorem/proof bodies remain current or fully retained with their exact hypotheses. No accepted closure is reopened merely to create a new revision. The old general-M squared-sign risk and timing curves remain distinct unsolved targets; the new exact realization threshold is not relabelled as their solution.

Finite diagnostics independently check raw weighted potentials, rational chain probabilities and Hankel ranks, random-horizon resolvents, algebraic circulant intertwining, three-state necessary inequalities, polygon probabilities and direct protected-qubit evolution. They are finite checks, not proofs of continuum or infinite-word conclusions. The analytic proof establishes those conclusions directly. Ordinary/-O parity prevents Python assertions from silently removing checks.

The full historical corpus is scanned and rehashed, but not every intermediate commit or historical proof is rederived. Literature priority and top-four significance remain independent assessment questions.
