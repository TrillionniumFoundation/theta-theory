# Theorem dependency graph

```text
raw preparation / legal kernels / executable tests
  -> prop:quotient or direct kernel realization
  -> actual histories, conditional task mean and law
       -> lem:cut (projection + dominated continuation geometry)
            -> lower side of thm:transfer
            -> cor:necessary -> ex:query (classical entropy witness)
       -> static relation-preserving cover + raw block pair/drift bounds
            -> upper side of thm:transfer -> prop:repair
            -> prop:stopped
raw independent multiscale bits + progressive sensing interface
  -> lem:greedy (global physical small balls and covering)
  -> lem:acquisition (all adaptive history variances)
       -> thm:adaptive (same-task optimized acquisition and memory)
       -> thm:joint (calibration + explicit erasure deficiency)
       -> thm:digital (finite implementation resource region)
raw primitive sparse Gaussian kernel
  -> lem:filtercover + lem:filterblock
       -> thm:transfer upper
  -> actual final-report Jacobian submeasure
       -> thm:transfer lower -> thm:brier
raw nonreset completed Cantor kernel (retained companion)
  -> completed-domain gains + full relation + prefix cover
       -> thm:transfer / independent-hold extension
       -> retained actual-depth law
parameter-independent causal implementation + common scored task
  -> thm:morphism
       -> transfers either cut lower or block upper at charged resources
       -> explicit verification in thm:joint
```

No realization is used to prove the general quotient, cut or block theorem. The progressive sensor uses the common projection/cut geometry and an independently proved exact-refinement construction; it is not falsely presented as a strictly contracting filter. The Gaussian and retained nonreset Cantor models are the two direct verifications of the block theorem.
