# Resource account

| Coordinate | New effective construction | Lower/qualification |
|---|---|---|
| Persistent labels | Exactly the chosen M-state tuple, including start/stop/actions/programme reuse; no attached phase | Risk lower compares every Borel M-state tuple in the same interface |
| External widths | Explicit phase rows m_t, free stage supplied only by that model | Separate frontier, not M-n universal penalty |
| Raw acquisitions | Fixed n physical controller calls; scored audit separately counted | No free reconstruction calls: averaging is an offline identity |
| Report resolution | B_a bins, tails retained; raw d_(t,h) certificate | Risk loss <= H min(1,sum d); no acquired-law renormalization |
| Probability precision | Denominator Q=2^b, shared row rounded once | Risk loss <= H min(1,n(A+M)/Q); only support removed |
| Decisions | K_rho loss-net codes | Uniform loss error rho, separately charged output encoding |
| Programme | O(P log(Q+1)+M log(K+1)+M+log M)+classifier+output tables | Feasible description upper; physical model/integrator/interpreter not silently included |
| Scratch | b, row indices/sums, classifier and readout workspace | Erased before next call; no retained random seed |
| Runtime | Exactly b fresh random bits per row; finite scans + physical report/classifier costs | Dyadic sampling no rejection loop; offline enumeration may be prohibitive |
| Planning | At most M 2^M K^M (Q+1)^P candidates with certified risk calculations | Computable finite bound, not polynomial or optimal search complexity |
| Numerical reports | Ideal-prefix mismatch chi with support signature preserved | Adds H chi; exact deadline would not follow from mismatch bound alone |
| Causal simulator | Explicit strategy lift and complete scored law; R_sim times M states | Adds H epsilon, no reverse lower from a one-way simulator |

Regular and blind acquired-geometry laws and attained N,M,delta,epsilon task extensions remain with full proofs. A complete jointly optimal programme/workspace/time/simulator region remains unproved.
