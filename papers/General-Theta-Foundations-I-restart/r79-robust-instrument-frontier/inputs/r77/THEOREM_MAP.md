| Horizontal joint Fourier blocks → permutation-module cover → simultaneous small-contrast synthesis | An attained exact shared-core formula at sufficiently small positive contrast with a common group mean, robust weighted singular certificates, and arbitrary shared overhead even for C2. Unequal means have an explicit nonnegative-rank obstruction. |
| Bellman equality → exposed first failures → tied-action transversal | Necessary and sufficient pure-start optimal controller memory with positive failure effects. A finite variational residual is positive exactly below that memory threshold, but is not the full constrained value frontier. |

| Robust support antichain → heralded complete-record fidelity → algebraic phase separation | Arbitrary terminal decoder tables obey finite memory certificates. The original algebraic qubit instrument has unbounded approximate memory with an explicit log-log lower; the retained upper is logarithmic. No unrestricted matching rate or pure-start extra-label lower is asserted. |
| Identity-word averaging → recurrent projection → convex specification | Every finite group and fixed finite output simplex; all-word closed convex constraints reduce to a finite permutation action with exact start-resource accounting. The original stochastic machine need not obey the group relations, and the projected action may have a kernel. |
| Convex balls → finite action optimization → singular-value certificates | Attained unrestricted uniform approximation, Lipschitz robustness, algebraic synthesis and explicit multiplicity/initialization lower bounds. Infinite-word error is not an expected-cost error. |
