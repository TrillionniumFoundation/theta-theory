# Theorem dependency graph

Raw prepared cycle + finite-history product domination
→ `lem:tensor` (reused-row finite response continuity)
+ actual uniform return envelope
→ `thm:renewal` (attainment, finite-model determination, N/discount/average transfer).

`prop:time-sharp` independently verifies the sharp uniform orders and the failure of mean-only tails.

Actual completed scored-cycle coupling + tail envelope
→ `thm:defect` (tail-dependent morphism error, MS state product).
Complete marked-kernel / unnormalized instrument norm errors
→ `lem:primitive` → `lem:cells`
+ computable model/decision nets and finite integrals
→ `thm:compile` (same-M all-Borel lower / finite-table upper).

Raw executable future tests → `prop:quotient` (minimal evaluation, Borel-image realization).
Fixed exploration + actual posterior occupation
→ projection identity / checkpoint q_M
+ all-candidate global cover and occupation stability
→ `thm:geometry` → `cor:noncontractive`.

`lem:rn` → `thm:hidden` verifies the central exact/effective theorem.
Raw CP instruments → `thm:quantum` independently verifies that same theorem.
`thm:hidden-geometry` and `thm:quantum-geometry` each verify the same geometric theorem from their own raw kernels; neither is a premise of the foundations proof.

`thm:holding` is a separate direct exact occupation theorem, including nondominated preparation; it does not prove general nondominated controller compactness.
`cor:singular` verifies common singular references, clock moments and changing ranks.
`prop:joint` combines a sharp occupation quantization lower with attained calibration and attained cycle deficiency; it proves sharpness of the recurrence-defect exponent, not a full complexity region.
