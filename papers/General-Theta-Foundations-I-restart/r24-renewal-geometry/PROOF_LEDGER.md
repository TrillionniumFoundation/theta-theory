# Proof ledger

Status means a proof is written in the native manuscript, not that it has received independent verification.

| Statement | Proof mechanism | Essential boundary |
|---|---|---|
| `prop:quotient` | Determining tests, Borel factorization, disintegration | Borel image required for standard Borel realization; no automatic smooth quotient. |
| `lem:tensor` | Weak-star compact rows, rectangle L1 density, causal expansion | Finite product-history domination, not marginal or infinite-path domination. |
| `thm:renewal` | Uniform tail truncation, compact minimization, FIP, stopped centered cycle sum, Abel identity | Compulsory joint physical/observer reset; uniform all-program tail before optimization. |
| `prop:time-sharp` | Rare long cycles with explicit finite and discounted rewards | Uniform moment-class sharpness, not a worst rate for every fixed experiment. |
| `thm:defect` | Truncated reward/length ratio and maximal coupling with Holder | Complete performed scored-cycle law, common clock convention. |
| `lem:primitive` | First-discrepancy coupling / CP hybrid telescoping on alive mass | Full marked transition, not only marginal emissions. |
| `lem:cells` | One conditional reference cell-average row reused on each call | Exact physical/cell law retained; visible tags never merged. |
| `thm:compile` | Covers every Borel row by same-M finite table; finite nets and rigorous intervals | Effective data explicit; no efficient complexity claim. |
| `thm:geometry` | Conditional square projection, actual occupation, all-candidate recursion, small-ball union bound | Fixed exploration; global cover; actual mass; no hidden exact-state register. |
| `cor:noncontractive` | Data-age error and third-moment renewal occupation | Exact first prior and nonexpansive subsequent updates. |
| `thm:holding` | Pointwise finite-readout lower and tagged nearest-center holding | Direct nondominated preparation theorem only, not general controller compactness. |
| `lem:rn` | Generating partitions and conditional-expectation martingale | Joint density, parameterwise null set; no false universal exceptional set. |
| `thm:hidden` | Sequential hidden disintegration + primitive entrywise integration | General exact / stronger effective subclasses distinguished. |
| `thm:hidden-geometry` | Explicit likelihood inverse, density, nonexpansive stochastic matrices | Known preparation and fixed exploration; independent lifetime. |
| `thm:quantum` | Unnormalized CP products, trace-norm Kraus estimate | Finite quantum dimension, actual audit back-action, classical observer memory. |
| `thm:quantum-geometry` | Affine positive load, IC audit, trace-norm nonexpansion, genuine rank mass | Continuous branch weight positive; no q^2-1 lower at weight zero. |
| `cor:singular` | Product probability references and actual tails | Common reference, not arbitrary singular translations. |
| `prop:joint` | Finite-readout lower + fixed-parameter two-point averages + attained erasure deficiency | Reset interface and first-report timing; selected multiresource slice. |

Every general proof precedes its raw realizations. No raw realization is invoked to prove the foundations theorem. Finite regressions test algebra and constants, not the continuum assertions in this table.
