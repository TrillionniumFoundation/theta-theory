\section{The causal acquired-flow theorem}
\label{sec:central}
For a dictionary $C=(r_1,\ldots,r_m)\in H^m$ put
\[
 d_{ia,C}(j,y)=w_{ia}(j,y)+\min_{1\le b\le m}\|f_{ia}(j,y)-r_b\|^2.
\]
The \emph{acquired-flow profile} $\Psi_m(N)$ is the minimum of
\begin{equation}\label{eq:objective}
 \sum_{i,a}\int d_{ia,C}\,h_{ia}\,dP_{ia}
\end{equation}
over $C\in H^m$, counts $x_{ia}\ge0$ and Borel densities $h_{ia}$ satisfying
\begin{align}
 &0\le h_{ia}\le x_{ia}\quad P_{ia}\text{-a.e.},\qquad
 h_{ia}=0\quad\text{off }D_{ia},\label{eq:flow-box}\\
 &x_j:=\sum_{a\in A_j}x_{ja}
 =\one_{\{j=i_0\}}+
   \sum_{i,a}\int_{\{j\}\times Y_{ia}}(x_{ia}-h_{ia})\,dP_{ia},\label{eq:flow-balance}\\
 &\sum_{i,a}\int h_{ia}\,dP_{ia}=1,\qquad
   \sum_{i,a}c_{ia}x_{ia}\le N.\label{eq:flow-cost}
\end{align}
The mass equation is redundant after summing the finite balance equations, but is displayed to prevent unnormalized terminal mass from being mistaken for a probability law. Empty feasible sets have value $+\infty$. The variables $h_{ia}P_{ia}$ are indexed by the \emph{departing} mode and action and include the next reported mode.

Set
\[
 k_-:=\left[\max\left\{2,\frac{1+2a_b}{a_v}\right\}\right]^{-1},
 \qquad k_+:=\max\{2,A_v+2a_b\}.
\]

\begin{theorem}[Acquired geometry with a paid causal protocol]\label{thm:transfer}
Under \eqref{eq:projection} and Definition~\ref{def:calibration}, for every finite $N$ and $m\ge1$,
\begin{equation}\label{eq:cp}
 k_-\Psi_m(N)\le R_\cp^\Theta(N,m)-B_0\le k_+\Psi_m(N).
\end{equation}
For $M\ge L+1$,
\begin{equation}\label{eq:aut}
 k_-\Psi_{M-1}(N)\le R_\aut^\Theta(N,M)-B_0
       \le k_+\Psi_{M-L}(N).
\end{equation}
Every finite upper is implemented at the original budget by one common program with at most $L$ live labels and the prescribed terminal labels. The profile minimum exists whenever its feasible set is nonempty. Every finite feasible flow admits a realization with exactly its terminal submeasures and no larger counts in any mode--action pair; unvisited circulation is not represented as acquired data.

If all $L$ modes are visited before commitment with positive probability by every legal program under at least one common admitted model, and their action sets are pairwise disjoint, the first profile in \eqref{eq:aut} can be replaced by $\Psi_{M-L}(N)$. Thus both architectures have matching profiles at the same paid terminal width. If additionally the exact conditional task identity
\begin{equation}\label{eq:exact-risk}
 \E[\|Z-r\|^2\mid\text{full pre-audit history}]
   =B_0+w_{ia}(j,y)+\|f_{ia}(j,y)-r\|^2
\end{equation}
holds for every $r\in H$, then \eqref{eq:cp} is an equality with coefficient one; under the mandatory-mode condition the autonomous equality with width $M-L$ also holds.
\end{theorem}

The theorem does not optimize over a separate program for each hidden model. The lower bound is valid for every history-dependent procedure in each model; the upper is a single program that ignores $V$ and uses only the common raw projection and certificate. It is the task comparison that permits this omission of information, not an assertion that $V$ is uninformative.

\begin{corollary}[Zero-risk boundary and several additive resources]\label{cor:zero}
For a feasible finite budget, baseline risk with $m$ checkpoint values is attainable if and only if a feasible flow can be supported where $w=0$ and $f$ belongs to a dictionary of size $m$. The same equivalence holds for autonomous width $M-L$ under the mandatory-mode hypothesis. The theorem remains valid with finitely many nonnegative additive cost constraints, provided one constraint bounds the expected number of calls by a finite constant. All constraints retain their original units.
\end{corollary}
\begin{proof}
Existence and positivity imply that $\Psi_m=0$ exactly when a minimizing terminal measure has the asserted support. Apply the two positive constants in \eqref{eq:cp}, or the sharpened version of \eqref{eq:aut}. For several resources the compact count bound comes from the call-count constraint. The realization in the theorem decreases each count, so it satisfies every nonnegative cost constraint simultaneously.
\end{proof}

Local calibration without \eqref{eq:flow-balance} is not a recursive-compressibility criterion. A low-risk report in a mode that cannot be entered from $i_0$ contributes no terminal mass in a feasible flow. Nor does the existence of the present finite observable projection follow from positivity of the original kernel; it is an explicit theorem-class assumption.
