## Source / publication handshake

The new source has its own full file manifest and computed Git tree. Its source commit is created before final verification. Strict verification requires that actual Git HEAD equal the declared full SHA and that the computed source subtree equal the committed subtree. It checks the unchanged R76 tree, ancestry, full-file preservation, current-only changed paths, diagnostic script identities, native statement index, and source immutability during execution.

A separate publication child records the source SHA, source tree, all document hashes, actual commands/results, visual inspection and hosted CI state if any. Source files do not contain a fabricated future self-SHA. The publication receipt and remote readback identify the delivered state. The GitHub branch is independent; no historical author, report or other-paper ref is overwritten.

Git transport and API transport are delivery mechanisms. In this environment, ordinary authenticated Git push was unavailable, so GitHub's authorized blob/tree/commit/ref API supplies remote objects; the resulting source commit is fetched and verified locally. A failed transport probe is not reported as a successful push or CI run.

No repository filename or machine-authenticated commit certifies human reviewer identity, journal commissioning, proof correctness, originality or acceptance. Those evidentiary categories remain separate.
