# Notation audit

| Symbol | Fixed meaning | Disallowed conflation |
|---|---|---|
| X_t | full-history predictive vector | raw hidden state or a runtime register |
| V_t | conditional mean given finite label | full-history posterior |
| W | after-current-report, before-new-label conditional prediction | a state-independent transform when likelihood is informative |
| ell_t, U_t, F_t | likelihood, unnormalized affine test numerator, normalized update | likelihood does not disappear from conditional expectations |
| Phi_t | integrated normalized quadratic potential | assumed Fisher/covariance geometry |
| ell_t^0(y) | affine likelihood intercept | distinct from scalar curvature b_t |
| b_t, a_t | curvature or same-report stability coefficients | coefficients can depend on phase; products are the assumption |
| B_n | actual full-history audit residual for same protocol | an unrestricted optimal-control or static-learning baseline |
| nu_t, mu_t,u | actual full-history law and actual row law | uniform geometry chosen on a reachable set |
| d | derived acquired exponent for the stated certificate | arbitrary ambient parameter dimension |
| d_f,d_p | full/pure acquired dimensions | do not normalize stratum weights |
| n,N | core report count and physical calls including preparation/audit | N=n+2 core; N=n+3 joint experiment |
| M,m_t | total autonomous labels and scheduled phase widths | persistent labels are not total computational bits |
| Q(n,M) | max(1,M-2n-1) for joint bit task | not M-n; independent bit consumes phase capacity |
| delta | actual inaccessible offset radius in thm:joint | arbitrary numerical error tolerance |
| epsilon | actual a/2 deficiency in thm:joint or declared complete-law comparison elsewhere | error allowance is not unavoidable risk |
| k_s,k_q | inherited spherical coordinate vs quantum audit counts | neither equals all intrinsic orbit dimensions |
| TV | sup event difference, half L1 | [-1,1] expectation requires factor two |
| C_N,K_N | unshifted and shifted preserved excursion crossing indices | C_N<=N, K_N<=N+1 |

Only local finite-dimensional derivatives are used. All ties and zero-mass cells have declared conventions. Compiled label numbers are extracted into the build receipt; stable source labels in this audit are authoritative before compilation.
