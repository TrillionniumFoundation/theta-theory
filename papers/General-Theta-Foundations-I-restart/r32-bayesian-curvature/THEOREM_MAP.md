# Theorem map and dependency graph

The main article has one central transfer theorem with explicit alternatives, not a collection of realization definitions posing as a foundation.

```
raw kernels + declared finite executable tests
  -> lem:quotient (measurability/realization/minimality with stated image condition)
  -> eq:bayes-barycenter (likelihood reweighting)
  -> eq:main-identity = Jensen + row + pooling
  -> eq:hessian (perspective curvature, under domination)
  -> eq:main-converse (all randomized finite observers)
actual row small-ball + global cover
  -> eq:checkpoint
(C) curvature product -> eq:curvature-recursion
(P) same-report transport -> eq:pathwise-recursion
common report null sets -> lem:clock
integer allocation + either recurrence -> thm:main (joint n,M matching)
  -> thm:gaussian [raw positive transition + Gaussian likelihood rank]
  -> thm:quantum [raw positive effect + channel + congruence Jacobian]
       -> cor:quantum-block [bounded-gap improvement]
(C) + weighted row strata -> prop:strata -> thm:singular [raw rank-changing instrument]
common scored law -> prop:composition; boundary certificate -> prop:precision
thm:main + erased bit + action/phase count -> thm:joint
```

No realization is an input to the general theorem. Lemma `lem:congruence` is an inherited matrix identity re-proved in place. Lemma `lem:orbit-gap` is a modular restatement of a preserved R29 argument, not a new claimed spectral theorem. The exact circle and temporal theories remain complete companions, not hidden premises.
