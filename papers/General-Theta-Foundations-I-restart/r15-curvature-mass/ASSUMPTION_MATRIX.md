| Input | Exact quantifier | Used for | Failure is not concealed by |
|---|---|---|---|
| Known preparation and kernels | fixed experiment, all admitted policies | actual laws and programmed integration | choosing a code separately for unknown true parameters |
| Common finite action family | every phase, every predictive state | Bellman minimization and label-only control | comparing only a fixed sensor schedule |

| Report equivalence to m^a | every phase/state for each common action | internal-clock support converse | a free time stamp/terminal request |
| W1 beta bound | every pair of incoming states and every same legal action | optimal-value sensitivity, not pathwise filter contraction | a single typical contraction coefficient |
| Uniform block products | all consecutive complete b-blocks; beta <= B | uniform horizon constant | a fixed-horizon constant renamed uniform |
| TV continuity | jointly Borel kernels, uniform finite actions | report compatibility and certified execution | joint scored-law calibration from marginals only |
| Concave Lipschitz Bayes risk | fixed bounded affine-in-state task | Jensen and curvature upper | Hessian smoothness or no-switch margin |
| Strong task concavity | alpha > 0 in every acquired direction | full-dimensional matching lower only | an insensitive/lower-rank task |
| Internal exact n deadline | every admitted path almost surely | M-n state count | external phase registers |
| Finite typed strata | actual component laws, fixed convex carriers | singular upper | normalizing away rare mass |
| Final r-component | mass >= w, subdensity <= rho* conditional before last action | singular lower | merely reachable r-dimensional points |
| Numerical certificates | specified error norms, actual programmed law, complete physical coupling | finite-bit risk upper | exact-real cardinality implying cheap computation |

Gaussian verification: d log-likelihood coordinates from m_obs >= d actual reports; affinely independent means; positive covariance; T entries >= tau; at least one invertible legal T per phase for minimality; 3*kappa obeys the block bound. Covariance here is a specified **raw observation noise law**, not an assumed acquired geometry.

Quantum verification: fixed finite D; positive full-rank preparation mixture; positive effects spanning all traceless Hermitian directions; alpha bounded away from zero and one; 3*max alpha obeys block bound; informationally complete paid terminal audit. No shared basis or infinite-dimensional closure assumption is used.
