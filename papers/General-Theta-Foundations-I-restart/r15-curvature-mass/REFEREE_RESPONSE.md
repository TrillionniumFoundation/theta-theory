## Principal change: a sharp joint horizon–state theorem

The prior construction allocated the same resolution to all phases and gave a fixed-horizon M^(-2/d) exponent with a growing n-dependent constant. The new `thm:main` proves, in a block-stable finite affine predictive class,

```
R_cp(n,M)-B_n*  ~  M^(-2/d),
R_aut(n,M)-B_n* ~ (M-n)^(-2/d),  M >= n+1,
```

with constants uniform in n and M. The autonomous class is empty for M <= n under the precisely declared internally exact-n, clock-neutral interface.

This conclusion has two independent load-bearing steps. First, `lem:allocation` uses the actual continuation-sensitivity profile and retains the baseline state at every phase. Second, `lem:clock` proves that report-support equivalence forces disjoint phase supports for **every** admissible autonomous observer, even with fresh transition randomness. Thus the clock overhead is not merely a safe construction; its necessity is proved for that class. The full-history last-step acquired-density converse then applies to the remaining M-n terminal labels. An external stop request or time-stamped report would change the conclusion, as explicitly demonstrated.
