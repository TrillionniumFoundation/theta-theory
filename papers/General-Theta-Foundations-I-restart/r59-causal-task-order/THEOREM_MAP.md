# Theorem and dependency map

The single main result is `thm:transfer` in `sections/03-main-theorem.tex`, proved completely in `sections/04-proof.tex`. Hypotheses and quantifiers are in Section 2; exact width formulas are in (3.1). The center is not a realization theorem.

| Dependency | Statement | Proof location / use |
|---|---|---|
| Raw positive kernels and tests | `thm:quotient`, `prop:raw-quotient` | Appendix A; constructs Borel image/section on positive-evidence compact patches, with almost-sure continuation |
| Physical comparison preparation | `eq:derived`, `eq:profile` | Section 2; actual report law produces task coordinates, never ambient parameter geometry |
| Compactness | `lem:attainment` | Section 4; compact tuples × weak-star density cap |
| Actual causal occupation | `lem:comparison` | Section 4; compares current rows on actual prehistories, not a comparison execution |
| Physical role accounting | `lem:roles` | Section 4; event max, typed sum, physical command-intersection lower |
| **General center** | **`thm:transfer`** | **Section 4; one-witness all-strategy lower and one common all-model upper** |
| Raw task order | `prop:matrix-order`, `thm:singular-order`, `prop:positive-order` | Section 5; exact affine-test order and measurable changing-rank range test |
| Raw predictive continuity | `prop:continuity` | Section 5; positive instrument and mass-weighted update, including stopped output law |
| General scale geometry | `prop:sublevel`, `prop:regular`, `thm:stratified`, `prop:atom` | Section 6; actual acquired sublevels, global small balls, retained stratum masses |
| Nonuniform errors | `lem:drift`, `cor:metastable` | Section 6; killed potential on actual prepared mode occupancy |

No edge from a realization theorem is used to prove the general center. The matrix-order criterion is an alternative primitive verifier for sufficient inequalities, not a necessary classification of all adaptive programs. See `theorem_dependencies.dot` for the graph source.
