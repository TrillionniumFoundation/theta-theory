|---|---|---|

| Complete scored stopping and cost certificate | Same final output after arbitrary independent waiting | Terminal TV=0 says nothing about expected duration |
| Counted pilot guard | Rare false calibration could choose a zero-acceptance set | High confidence is not almost-sure termination; add T guard and its memory |
| Observable task geometry | Latent component means used instead of actual conditional means | Mixture theorem applies only to a decomposition of the actual marked task law |
| Quotient regularity | Arbitrary Borel equivalence relation | Countable tests alone do not prove Borel image/section; use positive-evidence compact patches |
| Finite computation | Arbitrary Borel acceptance set | Require effective primitive approximation; labels alone do not count a finite source description |

These witnesses delimit actual proof steps and motivate the strengthened general theorem; they do not change the research topic or replace the positive results.
