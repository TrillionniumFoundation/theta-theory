# Resource-accounting table

| Resource | What is charged | Proven account / limitation |
|---|---|---|
| Raw acquisition | Preparations included in each specified primitive, failed gates, rejected productive reports | Expected core N; gate kappa = 1+1/p0 in matched case; p0=1 still costs 2 |
| Final audit | Physical call after commitment | Add 1 when executed as a separate primitive; the joint extension adds initial sign and final audit, 2 calls total |
| Persistent observer labels | Every intercall routing phase, retained task tag, coin, index | B+m typed versus max(B,m) event with identity exports; not B+m in both |
| Simulator memory | Continuing state including clock and terminal sufficient export classes | ell*K+t*E typed or max(ell*K,t*E) event; serial K,E factors multiply |
| Decoder/read-only program | Dictionary coordinates, finite partition tables, constants and instructions | Supplied descriptions; O(mkp) sufficient for stated coordinate/box program, not free total memory |
| Temporary workspace | Current report registers, comparisons, sampling, arithmetic, partition index | O(kp+log m) sufficient in stated implementation; cleared at the call boundary unless retained label encodes it |
| Numerical precision | Acceptance error, dictionary approximation, integration suboptimality | Restored hazard in Proposition numerics; acceptance error amplified by actual attempts, readout error added in stopped RMSE |
| Calibration | Physically acquired calibration draws and actual conditional relative/absolute task certificate | n calibration calls; rational outward interval; arbitrary kernel calibration not claimed |
| Calibration memory | Count vector, branch decision, forced-stop counter | At most (n+1)^J pilot labels plus counted deployment roles; guard multiplies live roles by at most T |
| Physical time | Whole-attempt preparation, pulse, report, arithmetic and audit duration | Independent conditional cost/potential bound; not inferred from bounded TV |
| Quantum resource | Physical d-dimensional system and its pulse/instrument | Part of experiment, not uncharged observer quantum RAM; a separate pulse interface adds call/phase costs |

M counts labels. ceil(log2 M) can encode a label; it is not the sum of program, scratch, calibration and physical resource costs. A profile equality in the Borel class is not automatically an optimal machine-bit or running-time theorem.
