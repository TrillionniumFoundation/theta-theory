## Deliberate mathematical checks

1. Lower comparator histories stay actual; no termination or expected cost is assumed for a substituted comparison execution.
2. Random command conditioning is lower-side; upper randomization is averaged only after proving independence from hidden current input.
3. A final event is not a continuing memory bit. Fixed typed halt maps alone force disjoint live/output roles.
4. Main proof uses the full current report conditional task moments, not merely mark marginals.
5. Zero singular directions stay zero only under relative task order; fixed positive absolute error can create a real risk floor.
6. Positive-evidence quotient updates agree only almost surely for compared representatives; impossible reports are not assigned a claimed canonical posterior.
7. Pilot r_n is a certified rational outward bound. Fixed sampler and fresh-draw assumptions are not replaced by observed empirical frequencies.
8. Core, erased sign and unknown calibration sign lower bounds hold in the same experiment; error tolerances alone do not force a lower bound.
9. Numerical acceptance errors and total variation are not used to infer expected physical time.
10. Finite tests, optimized execution, PDF build and source hashes do not settle continuum correctness, priority or mathematical-four significance.
