\begin{abstract}
We determine persistent finite-state memory for positive sparse monomial
experiments, uniformly through additive exponent collisions. The sharp
regret profile is a maximum of fractional powers of Vandermonde products,
truncated by the attainable past dimension and maximized over checkpoints.
For certified finite moment data, one causal filter realizes this profile
using integer transition tables and dyadic outputs. Its numerical scale
is selected from a two-sided covering certificate computed on approximate
feasible histories, without determining exponent equalities or receiving
the profile as input. If the profile is $\Xi_N(M,a)$, the selected
precision is $\frac12\log_2(1/\Xi_N(M,a))+O(1)$ binary places.
A separated future chain bounds this uniformly by
$\log_2(M+1)/((r-1)\lfloor N/2\rfloor)+O(1)$.
The proof combines collision-uniform attainment with finite numerical
compilation and an a posteriori stopping rule. Persistent state, numerical
advice, and read-only program size are accounted for separately.
The intrinsic classification holds for every full-support prior;
effectiveness requires the stated numerical input interface.
\end{abstract}
