\begin{abstract}
We study memoryless ordered binary quantum measurements that consume
their input and return a classical label.  A regularized midpoint
Sylvester form is comparable to the finite-use adaptive distance on
the complete effect body, with explicit dimension-dependent constants.
At fixed dimension $d$, the small-error covering number has order
\mbox{$N^{d^2/2}[\log(N+2)]^{\lfloor d/2\rfloor}\delta^{-d^2}$};
all spectral boundaries are included.  A common learner attains
$Cd^4N\delta^{-2}\log(d/\eta)$ calls, and a finite exact rational
code attains the optimal reusable description order.
We determine how a cap $b\le N$ on independent quantum training
blocks changes this cost.  For fixed $d\ge2$ the minimax order is
$\Theta_d((N^2/b)\delta^{-2}\log(1/\eta))$, allowing classical
feedback and collective processing of completed outputs.
A conditional fidelity argument gives the finite-confidence converse.
Separately, an information bound for weak binary measurements proves
$\Omega(d^2N\delta^{-2})$ calls even with coherent adaptive training.
On the fixed interior $I/4\preceq E\preceq3I/4$, a dimension-free
metric comparison and a reanalysis of an existing Choi estimator give
the joint order $\Theta(d^2N\delta^{-2})$ at fixed confidence.
On the same interior we prove a dimension-uniform covering law,
a finite exact index length
$(d^2/2)\log_2N+d^2\log_2(1/\delta)+O(d^2)$,
and simultaneous query-optimal learning and transmission.
Allowing shared randomness and failure probability $\eta$ changes
the leading optimal expected prefix length by the factor $1-\eta$.
Thus independent one-call acquisition has linear future-horizon cost
in this interior and quadratic cost uniformly on the full body.
Our common learners also admit finite trusted preparation specifications
with unchanged loss, confidence, and call orders.
The full-body learning laws hold for sufficiently small absolute
$\delta$ and $0<\eta\le1/8$; the scalar case is stated separately.
\end{abstract}
