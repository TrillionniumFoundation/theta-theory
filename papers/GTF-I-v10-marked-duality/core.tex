\section*{Supporting theory and model verification}
\addcontentsline{toc}{section}{Supporting theory and model verification}
The following sections give the complete proofs used above. Unless a
more detailed signature is specified, they use the cardinality
signature of Section~\ref{sec:v8-spectrum}: only persistent states or
physical terminal outcomes are bounded, with arbitrary transient
computation and independent reconstruction randomness. In the tree
application, Theorem~\ref{thm:v8-certified} additionally replaces the
full-word acquisition by a charged finite-prefix interface. In the
measure application the new matching lower bound is for the uniform
realized-law presentation task, not for a single marginal probe.
The Gaussian and Poisson inequalities concern the indicated terminal
experiment family. These local conventions are part of their use here.
