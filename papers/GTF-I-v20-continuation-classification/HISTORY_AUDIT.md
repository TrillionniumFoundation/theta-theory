## B4: retained obligation, no false inheritance

The historical B4 theorem displays R_lambda-R_mu=(mu-lambda)R_lambda R_mu for a normalized discounted nonlinear value. Testing the constant-one payoff already contradicts this displayed identity. Its downstream graph-independence and nonlinear Trotter–Kato claims cannot be consumed here on that basis.

A correctly typed nonlinear resolvent identity, **provided** a justified graph H and single-valued resolvents R_lambda=(I-H/lambda)^{-1} have already been established, is

R_lambda h = R_mu[(lambda/mu)h + (1-lambda/mu)R_lambda h].

Indeed, if u=R_lambda h, then lambda(u-h) is in H(u); the displayed input to R_mu has mu times u minus that input equal to the same graph element. Uniqueness of the mu-resolvent gives the identity. This elementary conditional graph calculation does not establish existence, range, comparison, compact action sublevels or the kinetic corrector for the historical physical problem. It is recorded as a repair target, not credited as a B4 closure. Nor is a linear resolvent difference formula substituted into a nonlinear argument.

## Preservation versus proof credit

No original repository path, review report, old manuscript or old pipeline target is deleted. Preservation means reproducible availability. Proof credit means that a specific written argument uses a specific established input under discharged hypotheses. Those two notions are recorded separately in the map, response letter and build receipt.
