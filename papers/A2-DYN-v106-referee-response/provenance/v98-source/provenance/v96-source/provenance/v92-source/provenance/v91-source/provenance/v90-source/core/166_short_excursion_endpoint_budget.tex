\section{The exact-label short-excursion budget}
\label{sec:v74-endpoint-budget}
We now apply the preceding theorem to the complete original scalar
source $b=b^\varepsilon_{n,k,m,R}$. In particular the level components
are formed after all physical contributions have been summed.
The threshold superposition is used to prove $BV$ membership only;
no level component is matched separately inside that signed
superposition.

For fixed $M,B,\delta>0$ let
\begin{align}
 \mathcal S_M(B,\delta)
  &=\limsup_{m\to\infty}\sup_{R,n,k}m^2
       \operatorname*{ess\,sup}_{t\in\mathcal C_{m,R,n,k}(M)}
             S_\delta b^{\varepsilon(B)}(t),\label{eq:v74-S-budget}\\
 \mathcal T_{\varepsilon,M}(r)
  &=\limsup_{m\to\infty}\sup_{R,n,k}m^2
       \operatorname*{ess\,sup}_{t\in\mathcal C_{m,R,n,k}(M)}
             T_{b^\varepsilon}(t,r).\label{eq:v74-T-budget}
\end{align}
Here $\mathcal C_{m,R,n,k}(M)=\{t:|Z_{m,R}(k,t,n)|\le M\}$;
an empty set contributes zero. These are extended nonnegative
quantities. The radius supremum is outside the roof essential
supremum. No common exceptional roof set over uncountably many
radii is required.

\begin{theorem}[Comparison with the original pointwise error]
\label{thm:v74-endpoint-equivalence}
For sufficiently large fixed $B$, $\varepsilon(B)=A_0B^{-1/12}$
and every fixed $\delta>0$,
\begin{align}
 \mathcal S_M(B,\delta)&\le\mathcal E_M+C_MB^{-1/192},\notag\\
 \mathcal E_M&\le\mathcal S_M(B,\delta)+C_MB^{-1/192}.
                                      \label{eq:v74-error-sandwich}
\end{align}
The constants can be chosen independent of $\delta$. Consequently,
for every choice $\delta(B)>0$ made before the collision limit,
\begin{equation}\label{eq:v74-error-limit}
 \lim_{B\to\infty}\mathcal S_M(B,\delta(B))
               =\mathcal E_M=\mathcal E_M^{\mathrm{path}},
\end{equation}
where equality with the path error uses the common positive
path-remainder theorem in the dependency statement. The limit is
understood in the extended nonnegative reals. It refers to the
original exact labels and the full arithmetic reference, including
its zero classes.
\end{theorem}
\begin{proof}
Write $P=m^2p$, $G=\mathcal L_{m,R}$ and
$P-G=m^2b^{\varepsilon(B)}+e_B$, with the scalar error from the
positive-remainder identity. Since $0\le S_\delta b\le b$,
\[
 m^2S_\delta b\le m^2b\le |P-G|+|e_B|.
\]
This proves the first inequality after the indicated limits.
Conversely, Theorem~\ref{thm:v74-level-bound} gives
$b\le2A_\delta b+S_\delta b$. The inherited fixed-width bound
and $\varepsilon(B)^{1/16}=A_0^{1/16}B^{-1/192}$ yield
\[
 |P-G|\le m^2S_\delta b+2m^2A_\delta b+|e_B|,
\]
which proves the second inequality. The auxiliary spectral band
used in the fixed-width bound is held fixed before $m\to\infty$
and is enlarged only afterwards. This is valid for each previously
chosen $\delta(B)$ and does not evaluate a spectral estimate at a
collision-dependent width.

For finite $\mathcal E_M$ the two bounds squeeze
$\mathcal S_M$ to that value. If $\mathcal E_M=+\infty$, the second
bound forces $\mathcal S_M(B,\delta)=+\infty$ for every such fixed
$B,\delta$, which proves the extended assertion. Equality with the
path error is proved in Section~\ref{sec:v74-normalization}.
\end{proof}

\begin{theorem}[A length-tail estimate sufficient for closure]
\label{thm:v74-tail-criterion}
Suppose that for the original Lorentz source there exist
$A<\infty$, $q\ge0$, $\beta>0$, and fixed $\varepsilon_0,r_0>0$
such that
\begin{equation}\label{eq:v74-tail-premise}
 \mathcal T_{\varepsilon,M}(r)
        \le A\varepsilon^{-q}r^\beta
       \quad(0<\varepsilon<\varepsilon_0,\ 0<r<r_0).
\end{equation}
Then, for every $\delta<r_0$,
\begin{equation}\label{eq:v74-tail-consequence}
 \mathcal S_M(B,\delta)
       \le\frac{A}{\beta+1}\varepsilon(B)^{-q}\delta^\beta.
\end{equation}
For any $a>0$, the legal choice
$\delta(B)=\varepsilon(B)^{(q+a)/\beta}$, for sufficiently large $B$,
gives
\[
 \mathcal E_M\le C_MB^{-1/192}+C_{M,a}B^{-a/12},
\]
and hence the original scalar endpoint and the same-roof path
numerator. The displayed power estimate is a hypothesis of this
theorem, not a conclusion about the Lorentz family.
\end{theorem}
\begin{proof}
We justify the order of limits rather than invoking an unjustified
interchange of a limsup and an integral. The function $T_f(t,r)$
is nondecreasing in $r$. For every positive integer $N$,
\[
 S_\delta f(t)\le\frac1N\sum_{j=1}^N T_f(t,j\delta/N).
\]
Fix $N,\delta,\varepsilon$ before $m$. Taking the essential suprema
and then the collision limsup, the finite sum gives
\[
 \mathcal S_M(B,\delta)
 \le\frac1N\sum_{j=1}^N\mathcal T_{\varepsilon(B),M}(j\delta/N)
 \le A\varepsilon(B)^{-q}\delta^\beta
                         \frac1N\sum_{j=1}^N(j/N)^\beta.
\]
Now, and only now, let $N\to\infty$. Its Riemann sum tends to
$1/(\beta+1)$, proving \eqref{eq:v74-tail-consequence} without
an integrability assumption on a collision-dependent envelope.
Substitute the chosen width and apply
\eqref{eq:v74-error-sandwich}. Finally enlarge $B$.
\end{proof}

There is also a moment version: an ordered bound
$\limsup_m\sup_{R,n,k}m^2\esssup_{\mathcal C(M)}
\Lambda_\beta b^\varepsilon\le A\varepsilon^{-q}$ implies
\eqref{eq:v74-tail-consequence} with its constant replaced by
$A\beta^\beta/(\beta+1)^{\beta+1}$, directly from
\eqref{eq:v74-tail-moment}. This too is a sufficient dynamical
hypothesis, not a consequence of fixed-count finite variation.

\begin{proposition}[The controlled source remains present]
\label{prop:v74-preserved-capacity}
On the common physical roof kernel write
$b=s+r$, where $s=s_{71,1}$ and
$r=d_{71,1}+b^{\varepsilon,\mathrm{inc}}+e_{70}$.
There are complementary physical weights retaining $s$ in the
controlled part, whose residual density is bounded by $S_\delta b$.
All exact labels and every original physical contribution are retained.
\end{proposition}
\begin{proof}
Put $q_\delta=A_\delta b$ and, on $\{r>0\}$, set
$\alpha=\min\{1,(2q_\delta-s)_+/r\}$; set $\alpha=0$ elsewhere.
The new densities are $s+\alpha r$ and $(1-\alpha)r$.
Their sum is $b$, and
\[
 0\le(1-\alpha)r\le[b-2q_\delta]_+\le S_\delta b.
\]
The coefficient is Borel. Multiplying the original residual weight
by $\alpha(L)$ and $1-\alpha(L)$ realizes these densities on the
same trajectory space and common kernel. No orbit, label or
conditioning event changes. The term $e_{70}$ is first clearance
outside the selected disks; it does not include first incidence.
The allocated weights are not asserted to have $BV$ densities.
\end{proof}

The comparison \eqref{eq:v74-error-sandwich} is a theorem for the
full source. It eliminates the charge for mismatched height layers
and identifies exactly the short excursions relevant to the
pointwise error. Neither \eqref{eq:v74-tail-premise} nor its moment
alternative has been derived here from collision dynamics.
In particular the fixed-count constant in \eqref{eq:v74-bv} and
the integrated bound \eqref{eq:v74-integrated} do not prove either
hypothesis. The original pointwise theorem remains the organizing
target; no interval theorem or reduced label is substituted for it.
