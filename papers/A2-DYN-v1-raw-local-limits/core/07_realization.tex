\section{Analytical realization still required}
The first-return set in \eqref{eq:Y} is explicit, preserves a specified measure, and has proved periodic records. It is not here asserted to be a Young magnet. A usable spectral realization must either construct a suitable return model containing these records or prove the needed estimates directly for this first-return process. Any change of inducing set must recompute the augmented records, rather than reuse their return periods silently.

The remaining requirements for applying Theorem~\ref{thm:LLT} to the full billiard are: a common strong/weak perturbation framework for the actual weighted return observables; the joint roof-frequency obstruction and returned nonintegrability; and a summable decomposition of all relevant singular and critical branch contributions with the residual frequency bounds and constant margins in Lemma~\ref{lem:splice}. The explicit normal-edge term is necessary but not an exhaustion of these contributions. The weighted versions needed by Proposition~\ref{prop:conditioning}, and the residual-clock and correlation hypotheses needed for the later interfaces, must also be established in their printed norms.

The geometric, arithmetic, and edge results above do not depend on these outstanding estimates. The long-time target remains the raw mixed-density local limit and its uniform geometric response, not a smoothed surrogate. This separation makes each present result usable without treating the remaining realization as an assumption hidden inside a proof.
