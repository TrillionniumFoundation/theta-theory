## E12.1 — Intrinsic resource-deficiency spectrum

**The optimized invariant from v13 is retained and receives an effective, same-budget converse.**

The inherited `thm:v13-main` optimizes over the simulator itself and separates private, hidden-selector and visible-selector error. Its convex hidden testing dual includes the cost of realizing a selector. This is not recast as an ordinary same-width private randomization theorem.

New `thm:v14-local` gives a complete local testing characterization for the actual private feasible set. At a fixed horizon, parameter alphabet, output/state budget and finite selector budget, expand the actual marked feedback tests into polynomials that are affine separately in each time-indexed stochastic row. Intersect each row simplex with a rational coordinate mesh. For each product cell, choose a test whose minimum over that cell gives a local lower bound. Separate affinity makes that minimum exactly a finite vertex computation. A vertex of the same product simplex is also an actual row table, yielding an original-budget upper witness.

The theorem proves `L_M <= delta <= U_M`, monotone dyadic convergence, and an explicit gap bound. In the private case it is `1-product_t(1-rho_t)`, where `rho_t <= d_t/(2M)` is the total-variation diameter of one output/state row. This bound counts depth and row alphabets, not histories or the number of row-table entries. It is not a running-time bound: enumerating the cover and all feedback tests can be large.

The hidden finite-selector bound couples the selector once. For a **visible** selector, the fixed event test changes on both sides when its selector law changes, so the local oscillation uses `2s+(1-s)b` rather than the hidden `s+(1-s)b`. The proof keeps that distinction. The diagnostic suite includes a signed-event example rejecting the missing second selector term.

New `cor:v14-converse` states the actual converse: private deficiency is at most epsilon exactly when no finite local test-cover certificate has value greater than epsilon. Strict infeasibility has a finite rational certificate; strict feasibility has a rational simulator at the original budget. Boundary equality is decided by classical real quantifier elimination for rational finite data. The minimum is algebraic and an algebraic optimum exists. The implementation does not pretend to implement quantifier elimination: it generates and independently checks the finite local certificates.

For the inherited rank-three delayed channel, hidden deficiency at width two is zero but private deficiency exceeds 1/8. A local certificate eventually proves the latter. A convex separator cannot do so because the target is in the hidden convex hull. Thus the local converse answers a genuinely different resource question, without a free selector.

New `thm:v14-stability` optimizes the comparisons on both sides of a presentation change. Two-sided stateless marked bridge errors a and b transfer an intrinsic interval to `[max(0,L-a-b), min(1,U+a+b)]` without increasing persistent widths or selector cardinality. The upper statement constructs an actual simulator; the lower statement excludes every simulator at that budget, also when the original carrier is nonfinite. No nonfinite attainment assumption is needed for the lower implication.
