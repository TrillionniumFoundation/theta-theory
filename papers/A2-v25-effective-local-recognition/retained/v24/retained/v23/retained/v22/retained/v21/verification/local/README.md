# Actual local execution evidence

`receipt.json` is the unmodified receipt of the current primary-only source-content execution. `execution-logs.zip` contains the eight command logs with exactly the filenames and SHA-256 values recorded in the receipt, including both ordinary and optimized runs. Extract the archive in a temporary directory before comparing these relative log names. No command output has been relabelled as a hosted result.

The receipt records null checkout and GitHub-run identities. Complete mathematical/tool sources are bound by `SOURCE_PINS.json` and `PUBLICATION_BINDING.json`. The primary PDF is supplied with the conversational delivery and is independently rebuilt by the exact-commit workflow. Retained-volume and hosted execution must have separate receipts.
