\section{Operational changes of the finite-memory interface}
\label{sec:v6-operational}
The following comparison is distribution-free. In particular it applies
to both realization mechanisms above.

\begin{theorem}[Finite interface equivalence]\label{thm:v6-interface}
Consider any sequential experiment with a standard Borel update input.
Suppose an event $E_t$ in an alphabet of size $K<\infty$ is available to
the update. Let $R_M^{\rm side}$ be the optimum when the post-update
decoder also receives $E_t$, and let $R_M^{\rm reg}$ be the optimum when
it does not. With the same choices of time and independent randomness,
for every nonnegative path loss and every horizon, and likewise for
upper or lower limiting average loss,
\begin{equation}
             R_{KM}^{\rm reg}\le R_M^{\rm side}\le R_M^{\rm reg}.
                                                        \label{eq:v6-interface}
\end{equation}
These inequalities arise from exact pathwise simulations.
An $M$-value register has an equivalent binary checkpoint encoding in
$\lceil\log_2M\rceil$ bits with unused strings allowed. Several finite
registers of sizes $M_1,\ldots,M_s$ are equivalent to one register of
size $\prod_iM_i$.
\end{theorem}
\begin{proof}
An observer can ignore a free event, giving the second inequality.
For the first, store the pair $(I_t,E_t)$. Its transition discards the
previous event, performs the original update using the current input,
and stores the new event. The original decoder is then evaluated on
this pair. The outputs agree for each input and each realization of
all coding random variables. Thus all path losses and their expectations
agree, not just a selected one-time distortion. Applying a fixed
bijection to the finite state set transports the transition kernels
and decoder to binary strings or to a product state set. The inverse
bijections give the remaining assertions.
\end{proof}

Consequently a positive squared-error exponent is invariant under any
fixed finite event interface, fixed regrouping of finite registers,
and finite-state renaming. When the risk or its Bayes excess satisfies
a fixed-budget-dilation comparison, its full order is invariant as
well. For a binary checkpoint budget $B$ the corresponding register
scale is $M=2^B$; this changes a polynomial in $M$ to an exponential
in $B$, rather than changing the theorem's physical resource silently.

\begin{example}[An unbounded side interface is a different experiment]
\label{ex:v6-interface}
Let $X_t$ be independent uniform random variables on $[0,1]$ and let
the current update input be $Y_t=X_t$. A decoder with the real-valued
$Y_t$ as a free post-update side input has zero loss with one persistent
state. Without that side input the optimal $M$-state loss is
$1/(12M^2)$: midpoint quantization attains it, and for cells of masses
$p_i$ the uniform interval moment inequality gives
$\sum_i p_i^3/12\ge1/(12M^2)$. Randomization does not improve the
pointwise nearest-centre minimum. A finite $K$ in
\eqref{eq:v6-interface} cannot be replaced by an arbitrary standard
Borel alphabet. The distinction is the presence of a new measurement
at the decoding boundary, not a hidden age-state convention.
\end{example}
