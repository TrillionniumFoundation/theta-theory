## 2. The additional mathematical response

On the same fixed full-dimensional interior
\[
 \mathfrak I_d=\{E:I_d/4\preceq E\preceq3I_d/4\},
\]
Section 62 proves, with absolute constants,
\[
 M^\star=\Theta\!\left[
 \frac{N}{\delta^2}\left(d^2+d\log\frac1\eta\right)\right],
 \quad d,N\ge1,\quad 0<\delta\le2^{-13},\quad0<\eta\le1/8.
\]
The lower permits arbitrary coherent adaptive training, retained references and bounded public stopping. The upper uses independent one-call Choi preparations and collective processing of completed outputs. The same order therefore holds for every fresh-block cap `1<=b<=N`.

The dimension term is the retained weak-measurement-information packing bound. A new explicit diagonal confidence argument gives the `d log(1/eta)` term: revealing the consumed input's basis label yields an amortized cq relative-entropy bound even when the two current input states differ. Testing each coordinate perturbation against the same null effect and summing null expected coordinate counts gives the converse. The upper credits the Mele–Bittel estimator and amplifies its dimension-dependent seed confidence, rather than multiplying a constant-confidence sample bound by an unnecessary dimension-independent number of repetitions.

The one-use specialization gives joint binary operator-norm learning cost
\[
 \Theta\!\left[\epsilon^{-2}
       \left(d^2+d\log\frac1\eta\right)\right]
\]
on the complete binary effect body. The future-horizon joint law is an interior theorem. On the complete body the stronger combined lower is
\[
 c\delta^{-2}\left[d^2N+
       \left(dN+\frac{N^2}{b}\right)\log\frac1\eta\right]
\]
in the stated common range. The current two-construction upper is
\[
 C N^2\delta^{-2}\min\{d^2+d\log(1/\eta),\ (d^4/b)\log(d/\eta)\}.
\]
The first construction applies the all-confidence binary operator estimator at accuracy `delta/(2N)` and the hybrid inequality; it uses fresh one-call acquisition. The second is the retained cap-`b` common learner. Public parameters determine the cheaper budget. This improves the available dimension upper without identifying it with the strengthened lower or closing the joint full-body minimax problem. The common range is `d>=2`, `1<=b<=N`, `0<delta<=min(2^-13,delta_*)`, `0<eta<=1/8`.

Section 63 removes the remaining effectiveness limitation of the interior learned-word construction. It specifies a finite semialgebraic feasibility problem for a readout of the Choi records. Real quantifier elimination decides feasibility and produces algebraic POVM entries that satisfy the uniform condition for **all real effects** in the target interior. A sequential search over the number of copies terminates at the joint query order; all search occurs before device access. The proof uses the existing tomography estimator only to prove that a feasible readout exists, without assuming computable entries for its continuous measurement.

This produces a finite trusted-control learner with the same `delta,eta` guarantee and
\[
 M=O\!\left[\frac{N}{\delta^2}
       \left(d^2+d\log\frac1\eta\right)\right],\qquad
 B=\frac{d^2}{2}\log_2N+d^2\log_2(1/\delta)+O(d^2).
\]
The payload uses the retained public interior dictionary; encoding adds no device calls. At rational public tolerances, the whole specification is computable in finitely many steps. Norm-certified approximations to preparations and the final algebraic readout preserve the risk through a total-variation budget. Quantifier-elimination time, algebraic description length, quantum storage and gate count remain separate resources; no efficient synthesis theorem is asserted.

These additions are audited in `PROOF_AUDIT.md` and the theorem-specific audit files. Internal cross-reading is not independent **human** priority review. That external task remains open as **R02/P01**.
