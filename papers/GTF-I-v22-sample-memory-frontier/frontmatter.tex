\begin{abstract}
We study statistical experiments in which memory is charged throughout
acquisition, randomization and validation. For a compact, possibly
nonconvex finite-alphabet behavior image, a finite response cover admits
rational whole-schedule realizations with explicit preparation, state,
precision and calibration bounds. Absorbing comparisons give a
polynomial-horizon alternative to constant-width clocked learning.
For independent erasure--revelation experiments we determine the exact
Bayesian value under every prescribed multicut state profile, over all
stochastic machines and for arbitrary priors. The value depends on the
last revelation and each remaining memory bottleneck, yielding sharp
sample--peak tradeoffs. Occupation-weighted transition defects transfer
terminal guarantees under perturbed training laws without charging
absorbed updates as active computation. For a marked positive-noise
two-sphere collision family we retain the exact three-state decision
optimum and give three distinct whole-schedule resource regimes.
Finite-state amplification yields separate confidence guarantees.
The underlying causal realization, residual obstructions, microscopic
comparison and bounded Gaussian/entropic transport are developed with
explicit interfaces and error budgets.
\end{abstract}
