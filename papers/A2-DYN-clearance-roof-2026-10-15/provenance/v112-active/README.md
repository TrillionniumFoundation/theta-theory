standard AMS/Latin Modern LaTeX packages and Poppler installed. The script
runs both inherited diagnostics and the new exact-rational checks in
normal and optimized Python, stabilizes references and checks typesetting.

In a committed Git checkout containing the review base (fetch depth at
least 16 is sufficient for this revision), run
`python3 tools/check_source.py` for exact source and archive verification.
The dedicated v112 workflow performs both steps at its exact checkout SHA.
Build success and finite checks do not certify the continuum proof inputs
or the remaining LLT.
