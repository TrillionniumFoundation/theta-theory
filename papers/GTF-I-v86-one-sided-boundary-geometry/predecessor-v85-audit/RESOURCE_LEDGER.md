# Resource ledger — Revision 85

| Resource or convention | Precise accounting |
|---|---|
| Unknown measurement | Ordered, memoryless, consumes input, returns classical label only. External reference belongs to the tester. |
| Future loss | Unhalved final-state trace norm optimized over common adaptive controls and at most integer N calls, including bounded public stopping. |
| Smooth-curve theorem | One fixed two-sided C2 curve, H nonzero; constants/interval depend on it. First-order rank stability is not required; second-order rank opening is permitted. |
| Pair information | Base measurement, direction and target angle are known for pair discrimination. Code and Helstrom readout can depend on the known pair. This is not advice for common learning. |
| Product lower | One fixed state and one coarse-grained outcome, repeated independently. |
| Linear lower | A logical qubit, at most 2d-dimensional retained reference per call, fixed ideal CPTP recovery on the available output. Number m<=N chosen explicitly. |
| Curve remainder | L bounds the actual effect second derivatives on a fixed interval; kappa=L/2+2||Gamma||op². These constants are not computed from a first jet alone. |
| Implemented controls | Uniform diamond errors under each hypothesis; preparation/readout and cycle errors are separately charged. Angle-dependent sufficient budgets are explicit. No independence is assumed. |
| Control synthesis | No general circuit-size/runtime or physical recovery is supplied. A uniform state-test error is not a diamond certificate. |
| Exact classical input | Gaussian-rational effects and first derivative. Full PSD, normalization, support blocks, real span and Hilbert–Schmidt projection are verified. |
| Exact classical cost | Polynomial represented-input bit complexity for support/first-jet classification, covariance evaluation and affine repair only. |
| Zero first derivative | Higher-order behavior is undetermined; no stationarity claim about an unspecified curve. |
| Common learning | Existing balanced fixed-k theorem unchanged, with explicit k³ upper, fresh calls, linked binary primitive, every-record budgets and legal fallback. |
| Reusable payload | Fixed public deterministic decoder and public parameters. Target-dependent private dictionary advice would need to be charged. |
| Dictionary/readout work | Distinct from payload and queries; general efficient synthesis is not established. |
| Regression | 23 fresh normal/optimized suites; new 313 positive and 17 negative checks. No continuum proof or hardware inference from finite cases. |
| Programme/priority | Independent analytic aggregate flags and independent human priority remain uncompleted, not supplied by this resource theorem. |
