## Quantifiers to retain in every subsequent review

The constants are uniform over known calibrations and memory budgets for fixed coefficient realizations, command cubes, priors and finite block horizons. The same constants can be chosen across the finitely many schedules. A transducer's codebook can depend on calibration, budget and schedule; no jointly measurable calibration selection or effective synthesis is assumed.

The product prior is essential to the proved product-attainment statement. The theorem does not quantify over arbitrary coupled priors. Each block prior has full support and need not have a density. Strict rank does not imply uniform conditioning over all such priors.

A tensor query is revealed after the index and is actually executed using all remaining trials. Only one checkpoint query is executed per run. The common acquisition law uses independent continuous commands. Old command seeds cannot become fresh public coding coins. The lower code is an arbitrary joint code with at most M outputs; the upper representative tuple is read-only data selected by one charged index.

A completed block may be forgotten only for the specified future-only task. A retrospective payoff or an arbitrary hidden-parameter terminal loss is not included by changing notation. The older ticket, erasure, mechanical and control tasks remain distinct.

Finite rational tests, source hashes, generated page counts and passing CI are separate evidence categories. None substitutes for the analytic proofs, an exhaustive literature search or a future referee's significance judgment.
