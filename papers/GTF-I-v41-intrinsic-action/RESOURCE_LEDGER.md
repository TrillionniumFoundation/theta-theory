# Resource ledger — v41

The optimized resource is the maximum number of **available persistent labels** at the declared cuts, including the final held binary answer (two labels). Unreachable padding is allowed and counted. A converse may count fewer positive-probability labels only under its chosen test law.

The seed and each command are actual input symbols. Only the updated label persists. No private seed, previous input word, branch selector, constituent identifier or protocol transcript is a free later input. In the upper construction the branch identity is part of a disjoint label set, and reciprocal-weight amplification is included in initialization.

The external clock, known horizon, horizon-specific machine design, complete read-only row/decoder tables, their construction and lookup, real arithmetic and exact atomic sampling are free. This count is not uniform algorithmic space, total program size, circuit size, an autonomous stopping-length recognizer or finite-fair-bit workspace. Label bits are the ceiling of the base-two logarithm of the number of labels; they do not price the tables.

Only one coordinate query is supplied at the terminal time. Coordinatewise error uses the specified query basis; c_lambda records its actual norm. An orthogonal coordinate change must transform queries as well to be an equivalent experiment. A joint law of all answers, independent product outputs or repeated queries changes the task.

H is the closure of the actual command matrices. Only one dominant active irreducible type needs a positive sphere/Lebesgue action gap. No hidden register receives free access to the proof-side orbit, intertwiner, Haar covariance, conditional centroid or Gaussian smoothing variable.

All theorem constants concern the fixed representation, active seed set, positive signal, error tolerance and command law. No exact finite integer optimum, leading constant or variable-signal uniformity is inferred. Rational command matrices do not imply rational convex-decomposition rows in every construction.

The optional LPS example is conditional on LPS5 and separate from the intrinsic main theorem. The mixed SO(3) x SO(2) example has a qualitative external algebraic SO(3) gap but **no full group gap**. Its ten command matrices are rational; no finite test claims to certify the infinite-dimensional gap.
