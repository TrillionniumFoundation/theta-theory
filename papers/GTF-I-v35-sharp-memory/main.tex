\begin{abstract}
We determine the order of the least hidden-state width of a uniformly
positive binary-command rotation experiment. For every badly approximable
angle and every fixed sufficiently small uniform output error, the minimum
width is $\Theta(N^{1/3})$. The lower bound permits arbitrary stochastic
transitions, cut-dependent state spaces, unobservable hidden directions,
and a different machine for every horizon. It therefore matches the
previous resonant-polygon construction without a vector-state restriction.
The proof groups commands into independent packets whose rotation counts
are separated. Compressing one packet into $k$ labels loses a fixed
multiple of $k^{-2}$ of the conditional phase amplitude, while the packet
uses $2k-1$ commands. Multiplying these losses yields both the sharp order
and a nonuniform occupation bound. A representation-valued version gives
an orbit-quantization budget for general compact groups; for the separate
model with all $\SO(d)$ rotations available as commands it yields the
matched order $N^{(d-1)/2}$. We also bound the actual optimal terminal
simulation error, independently of cancellation in local deficiency
certificates. Throughout, width counts available persistent labels in a
clocked atomic stochastic-row model; descriptions, arithmetic and exact
real sampling are not charged. The fixed-alphabet rotation theorem and
the compact-command extension have distinct input conventions.
\end{abstract}
