\section{Actual terminal error and local diagram certificates}\label{sec:error}
For a prescribed profile $\mathbf K$, define
$\mathcal E_N(\mathbf K)$ as the minimum uniform terminal row-TV error
in Definition~\ref{def:machine}. The minimum exists: the row simplices,
initialization rows and decoder intervals form a compact set, and the
maximum of finitely many wordwise errors is continuous. Thus this is an
intrinsic final simulation objective, not a sum of intermediate defects.

For $t\ge1$ put $B_t=2K_t-1$. Call $(t-B_t,t]$ admissible when
$B_t\le t$. Let
\begin{equation}\label{eq:interval-budget}
 \mathfrak B_\alpha(\mathbf K)
 =\max_{\substack{\text{pairwise disjoint}\\\text{admissible intervals}}}
                 \sum_i s_{B_{t_i}}(\alpha)^2.
\end{equation}
This finite weighted-interval problem depends only on the profile and
angle. Empty selections give zero. If $F_0=0$, its exact recurrence is
\[
 F_t=\begin{cases}
 \max\{F_{t-1},F_{t-B_t}+s_{B_t}(\alpha)^2\},&B_t\le t,\\
 F_{t-1},&B_t>t.
 \end{cases}
 \qquad \mathfrak B_\alpha(\mathbf K)=F_N.
\]
The last chosen interval proves the recurrence. Computing the weights
requires the stated angle representation; no bit-complexity claim for
arbitrary exact real inputs is made.

\begin{theorem}[Final-error obstruction]\label{thm:final-error}
For every irrational $\alpha$ and finite profile,
\begin{equation}\label{eq:error-bound}
 \mathcal E_N(\mathbf K)\ge\frac12
       \left[\frac1{10}-\exp\{-\mathfrak B_\alpha(\mathbf K)\}\right]_+.
\end{equation}
In particular, for peak at most $K$ and $B=2K-1$,
\begin{equation}\label{eq:peak-error}
 \mathcal E_N(K)\ge\frac12
       \left[\frac1{10}-\exp\{-\lfloor N/B\rfloor s_B(\alpha)^2\}\right]_+.
\end{equation}
For a badly approximable angle, every sequence $K=o(N^{1/3})$ has
$\liminf\mathcal E_N(K)\ge1/20$.
\end{theorem}
\begin{proof}
Choose the disjoint intervals maximizing \eqref{eq:interval-budget} and
put independent separated packets on them, idle commands elsewhere.
Every machine of that profile has terminal amplitude at most
$\exp\{-\mathfrak B_\alpha(\mathbf K)\}$, by Lemma~\ref{lem:packet}
and Lemma~\ref{lem:separated}. Terminal calibration gives
$1/10-2\varepsilon\le q_N$ whenever its left side is positive.
Rearrange and then minimize over machines. Consecutive equal-length
packets prove \eqref{eq:peak-error}; the estimate
$s_B\ge b_\alpha/B$ proves the asymptotic assertion.
\end{proof}

This conclusion is about the actual terminal error, so possible
cancellation of intermediate approximation errors cannot evade it.
It does not give the exact value of $\mathcal E_N$ at every finite profile.
In particular the limiting lower constant $1/20$ is not claimed optimal.

\subsection{Transfer to executable diagrams}
For finite row-stochastic experiments $E,F$ indexed by the same finite
set of prefixes, use the classical one-sided deficiency
\begin{equation}\label{eq:deficiency}
       \delta(E,F)=\min_{T\text{ stochastic}}\max_h
                                      \TV((ET)_h,F_h).
\end{equation}
The common row $T$ cannot depend on $h$. The zero-defect case is
Blackwell garbling \cite{Blackwell,Torgersen}; composition contracts total
variation.

Let $E_t$ specify a proposed state distribution for each actual input
prefix at cut $t$. For every next command, choose a common update
approximating the corresponding child rows, and likewise choose each
terminal query decoder. Let $\epsilon_t$ be the worst row error of that
update over prefixes and commands, and $\epsilon_{\rm out}$ the worst
terminal decoder error. If the initial rows are exact, put
\[
          \mathcal D(E)=\sum_{t<N}\epsilon_t+\epsilon_{\rm out}.
\]
Minimizing each one-step error gives \eqref{eq:deficiency} at that step.
This is an \emph{accumulated local deficiency certificate}, not a
formula for the optimal final error.

\begin{corollary}[Diagram obstruction]\label{cor:diagram}
Every such diagram of profile $\mathbf K$ satisfies the right side of
\eqref{eq:error-bound} as a lower bound on $\mathcal D(E)$.
\end{corollary}
\begin{proof}
Execute the selected common kernels. At each fixed prefix, induction and
TV contraction bound the discrepancy from $E_t$ by the sum of preceding
$\epsilon_s$. Append the common terminal decoder to obtain actual row
error at most $\mathcal D(E)$. If this sum exceeds one, the trivial error
bound one suffices. Thus $\mathcal D(E)\ge\mathcal E_N(\mathbf K)$;
apply Theorem~\ref{thm:final-error}.
\end{proof}
The certificate can overestimate the achieved final error, since local
errors may cancel. The corollary does not deny cancellation, minimize
$\mathcal D$ over all diagrams, or assert equality of the two objectives.
The new lower bound already applies before any diagram is introduced.
