\section*{Scope and conventions}
This volume contains the complete additional developments accompanying
\emph{Attainable information, exponent collisions, and finite-state
realization}. References without a C prefix point to the main article;
C-prefixed statements belong to this volume. The graph experiments
charge memory at their specified vertex-block boundaries. The local
readout extension changes the query distribution explicitly. The
regenerative route and network results supply their stated finite public
descriptors and independent seed. The delayed-use example has an atomic
acquisition block and no persistent public seed. These are separate
protocols, not relaxations silently substituted into the main per-report
model. The complete statements and proofs of all of these developments
are retained below. None is needed for the exact finite-moment
common-controller theorem in the main article.
