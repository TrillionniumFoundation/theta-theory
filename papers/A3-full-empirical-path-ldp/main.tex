\begin{abstract}
We formulate collision- and physical-time path large deviations on an ordered
marked-history state. Each mark contains the complete legal billiard
excursion, and its scaled start time records chronology, so the state
determines the concatenated path. Predictable controls remain absolutely
continuous with respect to the exact history kernel. Finite-cell recovery
uses conditional reference densities and therefore has finite relative
entropy. Long excursions are retained by a recession coordinate; no lower
bound on the normalized number of returns is imposed.
\end{abstract}
