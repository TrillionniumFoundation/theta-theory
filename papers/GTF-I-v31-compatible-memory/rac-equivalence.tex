\section{Exact query synthesis and classical worst-case coding}
\label{sec:rac}
Fix a finite decoder dictionary $D=\{v_1,\ldots,v_m\}\subset\cube^n$,
with private encoder and decoder randomness and no shared seed. A
worst-case success guarantee $(1+\eta)/2$ means that for every input
$x$ there is a probability vector $E_x$ such that
\[
        x_i\sum_s E_x(s)v_{s,i}\ge\eta\quad\text{for all }i.
\]
The same $E_x$ must serve all future queries. Merely requiring average
success over queries is a different condition.

\begin{proposition}[Checkpoint exactification with no added states]
\label{prop:exactification}
For $0\le\eta\le1$ the following are equivalent for the fixed dictionary:
\begin{enumerate}
\item it achieves worst-case random-access success at least $(1+\eta)/2$;
\item $\eta\cube^n\subseteq\conv D$;
\item it exactly realizes \eqref{eq:query} after changing only the encoder.
\end{enumerate}
Thus the minimum checkpoint alphabet in the exact problem equals the
minimum alphabet in the private-randomness worst-case coding problem.
No runtime symmetrization or retained random partition is necessary.
\end{proposition}
\begin{proof}
Assume the first condition and fix $u\in\R^n$. Choose an input corner
with $x_i=\operatorname{sign}(u_i)$ when $u_i\ne0$, and let
$z_x=\sum_sE_x(s)v_s$. Then
\[
          \max_{v\in\conv D}u\cdot v\ge u\cdot z_x
                  \ge\eta\sum_i|u_i|.
\]
The right side is the support function of $\eta\cube^n$. The separating
hyperplane theorem gives the second condition. It gives an exact convex
representation of every $\eta x$ using the same dictionary, which is
the required new encoder in the third condition. The third condition
implies the first immediately.
\end{proof}

This is a translation of the geometry already present in
\cite[Theorem 14, Lemma 15 and equations (143)--(149)]{Kondo2026}, not
a new coding exponent. In their $[0,1]^n$ normalization the dictionary
is $S=(D+\1)/2$, its directed $\ell^\infty$ Hausdorff error from the
Boolean corners is $e(D)$, and the largest centered cube factor is
\[
             \eta(D)=1-2e(D),\qquad
             p_{\rm worst}(D)=1-e(D)=\frac{1+\eta(D)}2
\]
whenever the factor is nonnegative. The factor two is essential when
passing from errors to means. Their model has $m=2^k$ messages; the
proposition uses any integer $m$. Their Lemma 15 explicitly passes to
cube containment. It is therefore not appropriate to call the exact
checkpoint channel a strictly harder cardinality problem solely because
it specifies equality rather than a lower bound on success.

Exactification can change a non-affine encoder into a different
non-affine encoder. The proposition does not bound the storage needed
to compute it online. Theorem~\ref{thm:additive} supplies that missing
step for additive encoders, and Theorem~\ref{thm:all-simplices} supplies
it for every simplex dictionary. This is the precise division between
the static coding theorem and the online theorem here.

The first-order entropy rate $1-h_2((1+\eta)/2)$ and logarithmic
communication overhead are classical \cite{ANTV}. The preceding revision
proved a fully charged blockwise exact realization with logarithmic
state excess $O_\eta(\sqrt{n\log n})$, and uniform row-error results;
those proofs and statements remain in the unchanged supporting article.
Neither exactification nor the present online simplex theorem proves a
matching second-order law for that block construction. The retained
entropy theorem is not used as a new contribution of this revision.

Likewise, the optimal $(2^k-1,k)$ classical construction and its static
bound in \cite[Theorems 16--17]{Kondo2026} overlap the Hadamard/Sylvester
checkpoint case. The online synthesis applies to its simplex without
increasing the number of messages, but does not change that existing
optimality statement. Their conjecture-dependent results for other
message sizes remain conjecture-dependent; none is used to infer an
unconditional finite phase diagram here.
