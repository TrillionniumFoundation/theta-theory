## 3. Device and resource interface

The unknown device remains an ordered, memoryless, input-consuming measurement channel with classical output and no residual device system.

All operational distances use unhalved trace norm.

### 3.1 Reset protocol at one node

At a classical history `h`, the protocol may:

1. stop; or
2. reserve a positive integer `n(h)<=b`;
3. prepare a complete fresh probe–reference system `sigma_h`;
4. run a common `n(h)`-call adaptive tester on the fresh system alone;
5. deliver the complete accessible fresh output to the receiver; and
6. apply a common receiver instrument jointly to that output and all old receiver memory.

The receiver instrument may retain arbitrary quantum memory and emit a classical next history.

The crucial condition is

```text
fresh complete system  tensor  old receiver memory
```

conditional on the history, under both hypotheses. The same preparation rule is used under both hypotheses. The old conditional receiver operators may differ.

### 3.2 What is permitted

The model permits:

- arbitrary quantum dimension in receiver memory;
- arbitrary entanglement within the fresh block;
- arbitrary quantum adaptive control inside the fresh block;
- arbitrary classical feedback between blocks;
- arbitrary common receiver instruments;
- retained public randomization records;
- variable reserved block sizes;
- bounded public stopping at block boundaries; and
- arbitrary final joint processing.

### 3.3 What is forbidden

The model forbids:

- coherently sending an old receiver subsystem into a later acquisition;
- a shared quantum reference linking nominally fresh blocks;
- target-hypothesis-dependent conditional preparation rules; and
- uncharged internal calls beyond the reserved block length.

A protocol with separable probe marginals can still violate reset independence if a common quantum reference correlates complete groups.

### 3.4 Hard budgets

Every nonterminal node reserves at least one call. Unused internal slots are padded and charged. On every terminal history,

```text
sum_r n(h_r) <= N.
```

This is an every-record budget, not an expectation.

The quadratic coherent cost is

```text
Q(policy)=max_terminal_paths sum_r n(h_r)^2.
```

Since `n(h)<=b`,

```text
Q<=bN.
```

## 5. Conditional fidelity accumulation

### 5.1 Algebraic identities

For positive trace-class operators,

```text
f(R tensor rho,S tensor sigma)=f(R,S)f(rho,sigma),
f(direct_sum R_z,direct_sum S_z)=sum_z f(R_z,S_z),
f(A(R),A(S))>=f(R,S)
```

for a common channel `A`.

For normalized states,

```text
d_B^2=2(1-f),
d_B^2 <= ||R-S||_1 <= 2 sqrt(1-f^2) <= 2 d_B.
```

These conventions are internally consistent with unhalved trace norm.

### 5.2 Induction statement

At a node, suppose the fresh normalized outputs satisfy

```text
f(omega_0,omega_1)>=(1-a)_+.
```

Let `A_h<1` dominate the current plus remaining deficit on every continuation path. The append step gives

```text
f(R_0 tensor omega_0,R_1 tensor omega_1)
 >=(1-a)f(R_0,R_1).
```

Let the common receiver instrument produce subnormalized outputs `R_{i,z}` and retain `z`. Then

```text
sum_z f(R_{0,z},R_{1,z})
 >=(1-a)f(R_0,R_1).
```

Each child has remaining budget at most `A_h-a`. Applying the continuation estimate at every child and summing gives

```text
[1-(A_h-a)] sum_z f(R_{0,z},R_{1,z})
 >=[1-(A_h-a)](1-a)f(R_0,R_1)
 >=(1-A_h)f(R_0,R_1).
```

The last inequality is exact because

```text
[1-(A-a)](1-a)-(1-A)=a(A-a)>=0.
```

### 5.3 Null histories

The incoming objects are subnormalized operators. If a history is null under one hypothesis, its branch fidelity is zero. No conditional density operator is formed and no division by branch probability occurs.

### 5.4 Countable histories

The retained classical record produces a direct sum. Countably many outcomes are handled by monotone sums of nonnegative fidelities. Finite call depth prevents transfinite recursion.

### 5.5 Public randomization

A public random seed is another retained common instrument outcome. It is covered by the same direct-sum step.

### 5.6 Audit conclusion

I find the lemma correct. It avoids the invalid shortcut of asserting unconditional tensor-product outputs after feedback.

In the lineality space, all missing-support blocks vanish. The inherited canonical factors give

### 6.2 Adaptive purified telescoping

Purify the fresh initial state and every common control in the `n`-call adaptive tester. Replacing one occurrence of `W_0` by `W_s-W_0` produces a vector of norm at most `alpha s`, since every surrounding factor is an isometry. Summing the `n` slot replacements gives

```text
||psi_s-psi_0||<=alpha n s.
```

No commutation or independence between slots is assumed.

The duplicated-label environment is discarded and unavailable to the tester.

### 6.3 Actual tube member

Adaptive hybrid telescoping gives

```text
||output_F-output_G||_1<=n r s^2.
```

The Bures inequality implies

```text
d_B(output_G,output_F)<=s sqrt(rn).
```

The Bures triangle inequality then yields

```text
d_B(output_E,output_F)
 <=s(alpha n+sqrt(rn)).
```

### 6.4 Fidelity deficit

Since `n>=1`,

```text
alpha n+sqrt(rn)
 <=(alpha+sqrt r)n.
```

Thus

```text
1-f<=gamma n^2s^2,
gamma=(alpha+sqrt r)^2/2.
```

This majorant is uniform over the fresh input, reference, adaptive controls and allowed tube remainder.

### 6.5 Horizontal versus canonical factors

## 7. Reset-width interpolation

### 7.1 Coherent tangential upper

For one policy,

```text
Q=max_paths sum n(h)^2.
```

The node deficits are

```text
a_h=gamma n(h)^2s^2.
```

Conditional fidelity gives

```text
f_out>=(1-gamma Qs^2)_+.
```

When `x=gamma Qs^2<=1`,

```text
||rho_E-rho_F||_1
 <=2 sqrt(1-(1-x)^2)
 <=2 sqrt(2x)
 =2(alpha+sqrt r)s sqrt(Q).
```

When `x>1`, the trace cap two applies. Therefore

```text
D(policy;E,F)
 <=min{2,2(alpha+sqrt r)s sqrt(Q)}
 <=min{2,2(alpha+sqrt r)s sqrt(bN)}.
```

### 7.2 Coherent tangential lower

The v87 lower uses independent parallel GHZ blocks and a fixed binary readout. This is a reset protocol with no inter-block feedback. Its encoding, recovery and event depend on the fixed base/direction and public `N,b,s`, but not on the unknown quadratic remainder.

The one-block error `m kappa s^2` is paid before Bernoulli amplification. The two integer cases `m=b` and `m<b` remain necessary for uniformity in growing `b`.

Thus the lower has order

```text
min{1,sqrt(Nb)s}.
```

### 7.3 Regular row

The independent product lower belongs to the reset class. The reset class is contained in the unrestricted adaptive class. The inherited horizontal upper is

```text
2 beta_h sqrt(N)s +(Lambda+K_h)Ns^2,
```

capped at two. For `sqrt(N)s<=1`, the quadratic term is absorbed into the square-root scale; otherwise use the cap.

Therefore the regular reset order is

```text
min{1,sqrt(N)s}.
```

### 7.4 Support-opening row

A fixed vector in one missing support and one impossible label give the exact occurrence lower. No entanglement or feedback is required. The elementary adaptive hybrid upper is linear. Hence

```text
min{1,Ns}.
```

### 7.5 Disjointness and exhaustion

The one-sided cone gives `J_j>=0`. The complete covariance-range theorem states

```text
H in Ran(C_E)
 iff J_j=0 for all j and Gamma_E(H) in W_E.
```

Thus every nonzero feasible direction is exactly one of:

1. regular tangent;
2. coherent tangent; or
3. support opening.

### 7.6 Endpoint classes

At `b=N`, one fresh adaptive block realizes the unrestricted adaptive class exactly.

At `b=1`, the receiver may retain quantum memory and use classical feedback, but no old quantum system may coherently enter a fresh call. The coherent tangent therefore remains at square-root order.

I find the theorem and corollary correct under the stated interface.
