# Revision 73 resource and error ledger

| Item | Convention |
|---|---|
| Encoded target | An ordered equatorial angle, optionally two supplied conditional state matrices. |
| Public parameters | N>=1, visibility lambda in [0,1], tolerance delta, fixed dimensions and conditional rank bounds. lambda can vary with N but is not itself encoded/learned. |
| Charged reusable payload | Circle chart sign/index and the inherited conditional-state factor digits/pivot masks. Fixed alphabet unused slots cost only a bounded overhead. |
| Error | Unhalved final joint trace distance maximized over one common adaptive tester, with quantum memory, entangled reference and public stopping bounded by N. |
| New matching range | Circle 0<delta<=2^-10; joint conditional states a fixed small cap. Upper encoders also accept larger positive tolerances below two, without advertising a matching theorem there. |
| Centre classes | Lower: arbitrary legal memoryless instruments. Upper: exact circle family, rational at rational lambda, with legal singular state factors. |
| Completely erased angle | At lambda=0 the angular payload is exactly zero; optional conditional states still need their own payload. |
| Rank guarantee | Exact effect eigenvalues (1±lambda)/2; encoded conditional state ranks never increase. Not a claim about rank-preserving retraction of arbitrary centres. |
| Decoded representation | Input-first unnormalized Choi blocks E_y^T tensor rho_y, expanded rational matrices with lcm denominator. |
| JSON | Canonical transport and target-bound certificate envelope; not the fixed-length payload count. |
| Arithmetic | Integer/Fraction arithmetic, exact integer square-root comparisons. No floating-point correctness decision. |
| Encoder workspace/runtime | Separate from payload; no optimality claim. Reading supplied input coefficients is not free learning of a device. |
| Programme states/GHZ inputs | Quantum proof/test resources, not finite-classical physical simulation hardware or an implementation-cost claim. |
| Structural companion | Fresh repeatable classical probes; its TV convention and hypotheses remain independent. |
| Analytic flags | historical_A2_replacement, B4_aggregate, C2_aggregate, eleven_paper_aggregate, whole_Theta_program all false. |
