\section{Attainable instruments and their failure records}\label{sec:attainability}
Fix $0<\eta<1/2$. A gate is a Borel function $g:X\to[\eta,1-\eta]$.
After a raw readout $x$, the prepared comparator variable $W$ accepts exactly
when $W\le g(x)$. The controller sees $x$ on acceptance and a censoring
symbol $\dagger$ otherwise. In particular, $\partial$ means unsuccessful
placement and $\dagger$ means a censored raw record; these are distinct.
No rejected raw coordinate is retained in controller memory. Let
$Z=X\sqcup\{\dagger\}$ and $\mu=\nu+\delta_\dagger$.

\begin{theorem}[Exact family realizability and adaptive pasting]\label{thm:attainable}
For a fixed mode $a$, the attainable one-cartridge instruments in this
comparator class are exactly
\begin{equation}
 K_R^{a,g}(dx)=g(x)k_R^a(x)\nu(dx),\qquad
 K_R^{a,g}(\{\dagger\})=f_R^{a,g}:=\int_X(1-g)k_R^a\,d\nu.
 \label{eq:gated-kernel}
\end{equation}
Equivalently, a proposed family with accepted densities $\ell_R(x)$ is
attainable if and only if, up to a common $\nu$-null set, there is one
radius-independent $g\in[\eta,1-\eta]$ such that
$\ell_R=gk_R^a$ for every $R$, and its failure mass is the complement.
All these instruments have densities at least
$\kappa_o=\min\{\eta\kappa,\eta\}>0$ with respect to $\mu$.
A Borel choice of mode and gate from the observed past can be pasted for
any finite budget using precisely the prepared cartridges. Every cartridge,
including either kind of failure, costs one unit.
\end{theorem}
\begin{proof}
Condition on the raw record. Independence and uniformity of $W$ give
$\Pr(W\le g(x)\mid x)=g(x)$, proving \eqref{eq:gated-kernel}.
Conversely the comparator uses one specified function of the observed raw
record, not of $R$. Its accepted sublaw must therefore have that density;
using a different gate for each unknown radius would not implement the
proposed family. The same comparator proves sufficiency. Positivity follows
from $g\ge\eta$, $k\ge\kappa$, and
$f=\int(1-g)k\ge\eta$. Normalization includes the failure atom.

Let $h$ denote the observed history. If $(a_h,g_h)$ is Borel, the deterministic
map from $(h,q,\vartheta,U,W)$ to its next report is Borel, after any fixed
choice on null boundaries. The unused cartridge coordinates have their
original product law conditional on $h$, since $h$ depends only on earlier
cartridges. Integrating the next coordinates gives
$K_R^{a_h,g_h}$. Induction proves the chronological product law. No Markov or
mixing assertion about successive collisions of a single billiard is used.
\end{proof}

\paragraph{What ``implementation'' means here.}
The exact class in this theorem is the ideal classical measurable-comparator
class: a command supplies $g$, and the comparator evaluates it on its raw
input. It is not a theorem that an arbitrary Borel function has a finite
smooth Hamiltonian circuit. This distinction has a positive implementation
counterpart: Section~\ref{sec:control} proves that finite piecewise-constant
gates and a finite command menu approach the exact optimal value uniformly
on the finite-budget state space. Those gates need only a finite interval
lookup and a prepared uniform comparator. Neither description asserts a
universal work or circuit-complexity price. The mechanical insertion and
coordinate detector preceding the comparator are the same in both classes.

\subsection{The four moments that determine a censored likelihood}
Put $b=2T$ and define
\[
 v_a(x)=\bigl(\one_{\partial},\one_{\{h=0\}},
                  \one_{\{h=1\}},\one_{\{h=1\}}\cos(y-\theta)\bigr).
\]
For $m=\int g v_a\,d\nu=(m_\partial,m_0,m_1,m_2)$, the failure numerator is
\begin{align}
 H_\dagger(R;m)
 &=\pi R^2(1-m_\partial)+(A(R)-bR)(1-m_0)\notag\\
 &\quad+bR(1-m_1)-b\epsilon R^3m_2.
 \label{eq:failure-poly}
\end{align}
This is simply $\int(1-g)H_a\,d\nu$, and is positive although its power
coefficients need not all be positive. The first three moments lie in
$[\eta,1-\eta]$. They and $m_2$ cannot be selected independently: their exact
joint feasible set is a moment body, characterized in Section~\ref{sec:control}.
A censored observation multiplies the radius likelihood by
$H_\dagger(R;m)$, not by a radius-independent constant. For example, a gate
that takes different constant values on placement failure and successful
placement produces a nonconstant quadratic failure likelihood.

\subsection{A simultaneously realizable tilted family}
For completeness, fix a bounded measurable source $V$ on $X$. The same
gate $g=c e^V$ realizes the conditional accepted law
\[
 Q_R(dx)=\frac{e^{V(x)}k_R^a(x)\nu(dx)}{\int e^Vk_R^a\,d\nu}
\]
for every radius whenever
\[
 \eta e^{-\inf V}\le c\le(1-\eta)e^{-\sup V}.
\]
The interval is nonempty exactly when
$e^{\osc V}\le(1-\eta)/\eta$. The statement follows by substitution in
\eqref{eq:gated-kernel}; essential bounds suffice. Repeating this fixed mode
and gate until acceptance or a cap $B$ consumes at most $B$ cartridges.
If $f_R$ is its one-cartridge censoring probability, the capped failure mass
is $f_R^B$, the expected consumption is
$(1-f_R^B)/(1-f_R)$, and, conditional on some acceptance, the accepted raw
output has law $Q_R$. Indeed the accepted sublaw is
$\sum_{j=0}^{B-1}f_R^j gk_R^a\nu$. A placement-failure record can itself be
accepted in this formula: selection is not silently conditioned on a
successful physical insertion.
