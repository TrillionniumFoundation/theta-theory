# v9 homological-pressure candidate

The v9 candidate is carried on this branch as a complete reproducible source bundle at:

```text
review/v9-homological-pressure/theta_v9_source_only.tar.gz
```

Its SHA-256 and full file manifest are stored beside the archive. The expanded local external-review package contains the five built PDFs and verification receipts. The existing expanded `papers/` tree on this branch remains the preserved v8 base and is not the controlling v9 source.

This packaging choice is explicit to avoid misrepresenting v8 files as v9 manuscripts. Independent line-by-line mathematical review remains pending.
