## New mathematical tools created in round six

1. **Full-port work-layer suspension:** branch work is accumulated before any
   recutting, on four disjoint port components, so it equals the current on the
   full regular Liouville section.
2. **Ambient trace-jet field:** all singular labels live in one fixed space;
   geometric births and deaths are encoded by vanishing realization
   amplitudes rather than zero/nonzero Banach-space isomorphisms.
3. **Recession-defect path state:** a finite measure on compact normalized
   excursion profiles records collision-clock mass which escapes to return
   level infinity.
4. **Transmission-zero memory realization:** compressed-resolvent zeros are
   promoted to finite auxiliary modes; only the remaining minimum-phase memory
   is exponentially decaying.
5. **Compound-Poisson finite-saddle smoothing:** mixed shell Fourier decay is
   obtained from exact convolution powers of the singleton exponent, not from
   fictitious connected blocks.
6. **Trace-class actual-contact ledger:** contact moments are controlled by
   incoming flux traces of the actual initial/tilted hierarchy, avoiding the
   arbitrary-`L1` boundary-layer counterexample.
7. **Root-inclusive genealogical Gramian:** root translations, root velocities,
   and creation variables give a quantitative transverse observability
   inequality without a uniform analytic-sublevel assumption.
8. **Two-domain cotangent duality:** local exponential charts serve analytic
   response; the union of all bounded global source balls serves scalable
   Fenchel duality and singular-current detection.
9. **Localized cumulant process method:** exact finite-centred Gaussian
   tightness is obtained from conditional block cumulants, without postulating
   a Poisson contact compensator.
10. **Projective steep-pressure theorem:** full LDP lower bounds are derived in
    every finite projection and passed to the path space, removing the circular
    exposed-density hypothesis.
