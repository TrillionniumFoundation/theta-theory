# Frozen θ-Theory research archive

This branch preserves the complete pre-governance repository tree at source commit
`bf88e63b9cb75709a42075d0d5e0fc54299c0661`.

## Purpose

It retains the historical monograph, old paper stacks, cumulative canonical volumes,
CM2 evidence and status history, provenance manifests, legacy verification programs,
and all v4 manuscript source variants that existed before active-tree cleanup.

## Authority rule

Files on this branch are research provenance and proof archaeology. They are not,
solely by being present here, current theorem authority or controlling submission
sources. Current manuscripts and registries must live on the active development
branch and identify this branch only by immutable commit or branch reference.

## Preservation rule

Do not delete or rewrite historical assets on this branch. Corrections should be
recorded as new notes that preserve the original bytes and state the superseding
scope explicitly.
