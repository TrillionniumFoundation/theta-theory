332,016 Round279 canonical atoms as 332,016 pairwise-distinct formal Round294
occurrence targets:

- 295,336 promoted Round288 canonical-atom occurrence IDs;
- 36,680 preserved aliases to existing Round266 occurrence IDs; and
- no new ID, identity alias, or representation alias introduced in Round297.

identity-collapse, alias, new-ID, seam, Jx/Jy, component-union, DSU-rank,
maximality, fibre, and global-disposition credits are all zero.

## Independent verification

The cacheless verifier reconstructs the expected rows, deterministic GZIP
ledger bytes, and canonical result JSON in a private directory before reading
any candidate artifact.  It never imports or executes the producer.  Candidate
JSON is duplicate-key-free, UTF-8, integer-only, canonical, and free of
trailing data; the GZIP ledger is required to match the independently rebuilt
bytes exactly.  HERE-only single-link regular-file confinement rejects lexical
traversal, symlinks, and hardlinks.

forgeries, registry/frontier omissions, occurrence or root-pair collapse,
source/key/signature/leaf/atom/corridor provenance changes, face-as-identity

filesystem path substitutions.
