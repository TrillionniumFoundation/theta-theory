## The physical quotient is a cylinder, not an unconditional torus

The pinned centered-jet initial map is

```text
A   = asin(t_star) + delta_x/(R_W sqrt(17))
Phi = asin(P_star) + 4 delta_x/sqrt(17) + delta_beta
R_W = 4/25
p   = sin(Phi)
radial = sqrt(1-p^2) = |cos(Phi)|.
```

The absolute value in the radial velocity identifies `Phi` with
`pi-Phi`.  The physical initial-parameter quotient is therefore naturally

```text
S^1_A x [-1,1]_p,
```

with `p=+/-1` as source-grazing strata.  Calling the lifted `(A,Phi)`
parameter space a torus without performing this fold would retain duplicate
physical sheets.

The exact lift lattice before the fold is generated by

```text

L_Phi = (0, 2 pi).
```

Thus the unbounded h-unit coordinate `u=abs(delta_x)/h` contains infinitely
many copies of a compact physical parameter domain.  A finite lifted chart
face is not a terminal exit merely because it ends one local chart.

## Four rational source charts

Let

```text
kappa = sqrt(2)-1,
theta_E = 0,
theta_N = pi/2,
theta_W = pi,
theta_S = -pi/2,
z = tan((A-theta_C)/2) in [-kappa,kappa],
q = tan(Phi/2) in [-1,1].
```

For the axial unit vector `e_C` and its counterclockwise quarter turn `J e_C`,
the physical state is given without inverse trigonometric or square-root
dependency by

```text
n      = ((1-z^2)e_C + 2z J e_C)/(1+z^2)
p      = 2q/(1+q^2)
radial = (1-q^2)/(1+q^2)
v      = radial n + p Jn.
```

Both denominators are at least one.  The four cyclic source-chart gluings are

```text
E,+kappa <-> N,-kappa
N,+kappa <-> W,-kappa
W,+kappa <-> S,-kappa
S,+kappa <-> E,-kappa.
```

Using `kappa^2+2kappa-1=0`, the two rational formulae on every shared face
give the same `n`, `Jn`, position and velocity.  The global exterior registry
must include a face/corner ledger; an area or box-count total is not a
substitute for these exact gluings.
