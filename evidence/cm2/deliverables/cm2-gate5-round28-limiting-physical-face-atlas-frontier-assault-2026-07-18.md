## 2. Exhaustive R1 terminal-core-preimage family seeds

Every one of the 24 source cores has one strict regular first-collision branch

```text

  = 1,152 candidate physical preimage families.
```

For a lower destination face the inward level function is typed as

```text
F_s(x) = coordinate(T_s x) - boundary_value,
```

and for an upper face as

```text
F_s(x) = boundary_value - coordinate(T_s x).
```

Each family has:

- one immutable family ID;
- an immutable inside/hit trace-family ID;
- an immutable outside/miss trace-family ID;
- the symbolic signed parameter current
  `partial_s(F_s) delta_0(F_s) dmu_collision`;
- the positive coarea-density type
  `abs(partial_s F_s)/norm(grad_collision F_s)` relative to collision-line
  trace.

The regular gradient is nonzero wherever the level set is present, because a
nonzero destination coordinate covector is composed with an invertible
regular billiard derivative.

This is deliberately a family registry.  A family can be empty, and clipping
by a source core can leave more than one connected piece.  The leaf does not
claim a component count, a nonempty incidence, a common subdivision, or a
numeric coarea/trace bound.  Instantiated connected face-component IDs remain

## 6. R2 and arbitrary-n fail-closed carrier-family grammar

The limiting physical R2/Q2 partition is certified modulo collision-null,
and the arbitrary-n regular connected-component schema exists
nonconstructively.  Five physical boundary **carrier-family** kinds are

1. source-core clipping carriers;
2. intermediate core-avoidance preimage carriers;
3. terminal core-preimage carriers;
4. collision singularity/owner-change carriers;
5. moving occurrence-face pullback carriers.

The same component may meet any one of these carriers in several disconnected
one-dimensional pieces.  Therefore all five hypothetical instance grammars,
not only the moving-occurrence grammar, now have the common form

```text
face:(component_id,time_j,carrier_family_or_seed_id,connected_rank)
```

and all five trace grammars have the form

```text

```

Here `side_label` is kind-specific: inside/outside, avoid/enter,
return/survive, left-owner/right-owner/cemetery, or hit/miss.  Source clipping
uses `time_j=0`; intermediate faces use `1<=time_j<n`; terminal faces use
`time_j=n`; collision and occurrence carriers use `1<=time_j<=n`.

For the fifth kind the global occurrence seed remains separately frozen as


The intended connected-rank rule is also frozen uniformly:


However, canonical one-dimensional parameterisations and the connected piece

The verdict is therefore deliberately downgraded to
