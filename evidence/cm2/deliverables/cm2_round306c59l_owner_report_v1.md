## Exact C50a API gap

The frozen generic C50a capability accepts only a finite history of Kraft-one
replacement transactions.  Each transaction selects one representative /
reflected C41 predecessor pair with a common task root, partitions both exact
predecessor boxes, and computes owners only on the resulting target
replacement boundaries.

The C59 query instead names two adjacent existing C32 endpoint cells with two
independent C38-C41 lineage sets.  C50a has no static-existing-edge operation
and its opaque `source_evidence` is checked only for zero credit; it does not
semantically validate C35 occurrence-1 or cross-endpoint lineage
compatibility.  Consequently even the 973 rational same-chart face requests
remain structurally unconsumable.

There are two additional exact-domain gaps:

- 69 edges touch at least one algebraic endpoint, while C50a `exact_box` is
  rational-only;
- the 16 source seams need a cross-chart entity and exact glue map, while C50a
  face entities are single-chart.

The API audit binds the source hashes and AST/source slices for `interval`,
`exact_box`, `request_check`, `validate_split_tree`, `locate_predecessor`,
`apply_history`, `target_faces`, and `build`.  No pair1 result is used as a
global authority.
