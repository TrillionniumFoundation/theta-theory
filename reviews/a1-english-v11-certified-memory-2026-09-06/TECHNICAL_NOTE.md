## 2. An exact covering-order witness

Consider the one-step system

\[
 U=[1/4,3/4],\quad s_0=1/2,\quad T(s,u)=(s+u)/2,\quad Q(s)=s.
\]

Its reachable set is the interval S=[3/8,5/8] of length 1/4. A union of M radius-e intervals has total length at most 2Me, so covering S requires e≥1/(8M). M equally spaced interval midpoints attain this value. Therefore the unrestricted-centre radius is exactly

\[
 e_S(M)=1/(8M).
\]

Use a rational grid containing both command endpoints and the author's deterministic indexing, so the first selected representative is 3/8. The exact dyadic output at that representative is 3/8. If all transitions go to index zero, then the command 3/4 produces true output 5/8 but stored output 3/8. Thus

\[
 \sup_{u\in U}|\widehat Q-Q(T(s_0,u))|=1/4,
 \qquad (1/4)/e_S(M)=2M.
\]

The squared error is 1/16 and its ratio to e_S(M)^2 is 4M^2. A collapsed program therefore cannot satisfy the covering-order conclusion with a constant independent of M. This is an exact statement about the mutated algorithm, not the original construction.

The independently written diagnostic chooses a grid with 8M segments, whose covering radius in command space is 1/(32M). All state values used in this test are exact dyadic rationals. For M=1,2,4,8,16,32, it checks each original transition against a separately computed nearest-centre target. It finds maximum grid error at most 2e_S(M) for the unmodified compiler, whereas the collapsed maximum error remains exactly 1/4. A finite grid check alone is not a continuum proof; the displayed interval argument is what establishes the continuum radius and the endpoint counterexample to the mutated procedure.

## 3. Why a valid residual certificate is not an optimality test

For a table j, the manuscript defines

\[
 d_n(j)=\max\|\widetilde T(c_{n,i},\bar u)
              -\widetilde c_{n+1,j(n,i,u,x)}\|+2\tau.
\]

Changing j changes d_n. The residual proposition is deliberately valid for arbitrary j, with an error allowance propagated from this measured residual. Consequently it is entirely consistent for a poor table to have a valid, larger residual certificate. Comparing the actual error of that table against its newly enlarged allowance does not check the nearest-centre construction or the rate O(e(M)). No unsoundness of the proposition follows from the mutation's survival.

An independent construction contract should instead reevaluate the approximate target and the same selected approximate centre list, then verify that the stored target attains the finite minimum (with the documented tie rule), or satisfies the exact inequality used in the proof. A separate test should check a residual bound tied to an independently known covering scale. These tests ask different questions and should not be conflated. The reproduction script demonstrates the nearest-centre contract on the interval fixture; it does not modify the author's suite to conceal its present result.

## 4. Exact bit lengths versus sufficient rounded precision

For b≥1 and a fixed integer N≥2, set

\[
 x_b=\frac{2^b-1}{2^b}.
\]

The numerator is odd, so the reduced denominator of x_b^N is exactly 2^(Nb). Exact multiplication consequently needs Nb fractional binary places to represent this number. It cannot in general be represented exactly with b plus a constant depending only on N. This elementary distinction is checked using `Fraction` for b=4,8,16,32 and N=2,3,5.

There is no conflict with a sufficient input/output **accuracy** of b+O(1). For fixed horizon, the number of operations per finite moment evaluation and the coefficient/evidence bounds are fixed. If products, sums and division are rounded in an explicitly specified way, a forward error argument can make the total evaluation error at most C 2^(−b). Such an argument must include positive-denominator preservation. It establishes an approximate-arithmetic implementation, not an exact representation theorem.

The simplest accurate statement for the implementation supplied in v11 is: the numerical advice and dyadic outputs have the proved precision; the displayed exact rational evaluator has O_N(b)-bit intermediates, with constants also depending on the fixed finite input format. The paper already counts rational operations and excludes arbitrary oracle time. Nothing in this correction requires withdrawing the persistent-memory rate or its sufficient input/output precision.
