\section{Provenance, reproducibility, and manuscript status}\label{app:verification}
\subsection{Relation to the previous A1}
This English edition is a substantive replacement rather than a literal translation. It retains and re-proves the finite-time experiment construction, source/projection identities, finite predictive states, response calculus, and prepared Lorentz event. It adds restricted realizability and density caps, explicit apparatus back-action, response-qualified and continuous experiment-family states, residual-resource dynamic programming, observable-specific error norms, direct binary identification, and the whole-preparation short-time collision assembly.

The previous local event theorem is not relabeled as a global long-time theorem. The new full-preparation result instead has its own exact flux identity and a distinct, explicitly short physical horizon. General multi-collision long-time response remains a separate theorem to be established. No external journal acceptance, formal proof-assistant certification, or automatic closure of the other ten papers is claimed.

Such records establish what was executed, not that every written theorem is correct.

\subsection{Reproduction commands}
From the package directory run:
\begin{verbatim}
python3 -m unittest discover -s tests -v
python3 tools/build_and_verify.py
\end{verbatim}
The build uses ordinary pdfLaTeX without shell escape and performs repeated passes for references. The single-file source contains the same text with section inputs inlined and can be compiled independently. No font files are distributed. Mathematical tests use the Python standard library, NumPy, SciPy, and SymPy as identified in the environment receipt; exact rational identities are distinguished from floating tolerances.
