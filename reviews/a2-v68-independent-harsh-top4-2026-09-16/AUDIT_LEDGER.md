## 6. Reproduction

Use Python 3 with SymPy, mpmath and PyMuPDF, plus a working TeX installation providing `latexmk` and the manuscript's required packages. Extract workflow artifact 10442234606 into `WORK/artifact/`, and its `native-source.zip` into `WORK/source/`. The source structure is `WORK/source/SOURCE_MANIFEST.json` and `WORK/source/source/`. Keep the baseline artifact 10437417575 as `BASELINE.zip`.

Run from the review directory, starting without an existing `WORK/rebuild/`:

```sh
python verify_delivery.py WORK
python compare_baseline.py BASELINE.zip WORK
python verify_delivery.py WORK --build two_collision
python verify_delivery.py WORK --build main
python verify_delivery.py WORK --build rigidity
python verify_delivery.py WORK --compare
python independent_checks.py > independent-normal.json
python -O independent_checks.py > independent-optimized.json
cmp independent-normal.json independent-optimized.json
```

The comparator reports the raw ZIP mode caveat without suppressing byte-integrity failures. The scripts write `REPRODUCTION_RESULTS.json`, `SOURCE_DIFF.json` and retained build outputs under `WORK`; the mathematical program emits its complete JSON to standard output. Floating-point hashes and rebuilt PDF hashes can vary across environments; they are not mathematical invariants. None of these programs downloads a moving branch.
